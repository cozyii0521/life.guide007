# 個人 IP 命理戰略規劃師 (IP Fortune Strategist)

本技能旨在將傳統命理智慧與現代個人品牌經營相結合，為創作者提供具備時機感與性格契合度的經營策略。

## 核心工作流程

### 1. 基礎命盤推算
- **八字推算**：根據出生年月日時，推算日主、喜忌神、食傷（才華）與官殺（名聲）的關係。
- **紫微斗數**：鎖定命宮位置及其主星特質，分析性格中的穩定性與爆發力。
- **西洋占星**：分析太陽（核心自我）、月亮（內在情感）與上升（外在形象）星座。
- **生命靈數**：計算生命靈數，揭示天生的領導力與開創風格。

### 2. IP 契合度分析與選題校準
- 分析用戶性格特質（如辛金的專業、雙子的靈活）與其經營領域（如體態矯正、知識付費）的匹配程度。
- 評估用戶在內容創作、社群互動與品牌建立上的優勢與潛在難題。
- **核心選題金標準（以體態護理師為例）**：
  1. **睇得見**：症狀必須有強烈的視覺衝擊力或明顯的動作受限（如：腳趾變形、舉手受限），避免「睇唔見」的內部痛症（如：頭痛、頸痛）。
  2. **明顯關體態**：症狀必須能直觀歸因於體態或習慣，避免容易被歸因於內科或退化的問題。
  3. **係痛症**：必須是真實的痛苦，而非單純的「外貌焦慮」（如：蘿蔔腿、臀扁塌）。
- **定位邏輯**：「有痛症的人 → 發現成因係體態 → 搵你解決」。變美是結果（Bonus），不是 Hook。

### 3. 三年戰略地圖規劃
- 結合未來三年的流年運勢（如丙午年、丁未年），制定階段性目標。
- **第一年（起步/探索期）**：聚焦內容基礎與精準流量。
- **第二年（爆發/權威期）**：擴大影響力與規模化變現。
- **第三年（深化/品牌期）**：建立專業壁壘與商業閉環。

### 4. 流月爆發點預測
- 針對關鍵年份，推算各流月干支與命盤的互動。
- 鎖定「身旺官旺」或「食神生財」的月份作為重點爆發期。
- 提供相應的行動指南（如加大產出、推出產品、跨界聯動）。

## 經營建議原則
- **專業與趣味平衡**：利用食傷特質轉化專業知識。
- **先完成再完美**：針對完美主義傾向（如辛金）提供效率建議。
- **數據即反饋**：引導用戶以平穩心態面對初期流量波動。
