## 一、爆紅 Reels 的成功 DNA（足弓重建 31.8K 案例）

### 爆紅的五個核心要素

| 要素 | 具體表現 | 底層邏輯 |
|------|---------|---------|
| **視覺衝擊 Hook** | 封面紅圈標註痛點 + 痛苦表情特寫 | 0.5 秒內製造情緒反應 |
| **反直覺開場** | 「腳板痛唔係老咗——係你嘅足弓塌咗」 | 打破常識 → 好奇心缺口 |
| **低認知負荷** | 一句話直擊痛點，無需思考 | 大腦不需要額外處理時間 |
| **即時獲得感** | 「腳趾抓地」動作，觀眾馬上可以做 | 收藏率 = 「我要留返嚟用」 |
| **精準 CTA 誘餌** | 「留言 foot 送 10 秒足弓自測法」| 低門檻 + 高價值 = 高留言率 |

### 爆紅公式
```
強視覺 Hook（0.5秒）
+ 反直覺觀點（3秒內）
+ 即時可做的動作（15秒內）
+ 精準 CTA 誘餌（結尾）
= 高完播率 + 高收藏率 + 高留言率 → 演算法推流
```

## 二、失敗 Reels 的致命錯誤模式

### 模式一：Hook 認知負荷過高（痛症類）

**案例：** 「行街腳痛到腰都痛埋？真兇係你對腳」（Views ~500）

**問題：** Hook 建立了「腳痛 → 腰痛」的因果鏈條，需要觀眾思考才能理解。

**原則：** 在 Reels 中，**「簡單」和「直接」往往比「正確」更能抓住觀眾**。

**修正：** 「行 10 分鐘街就腰痛？唔係你老，係你對腳廢咗！」（直接衝擊，無需因果推導）

---

### 模式二：心態類內容受眾預期偏差

**案例：** 「追目標仲靠意志力？」（13 讚，3 留言）

**問題：**
- 受眾因爆紅痛症片建立了「體態專家」標籤，期待實用乾貨
- 「意志力」是抽象詞彙，視覺無法呈現
- CTA「留言同我講你靠意志力撐」= 要求自我揭露，心理門檻高

**修正策略：「特洛伊木馬法」**
> 用體態問題作切入，包裝心態內容
> 例：「點解你練咗一個月體態都無進步？唔係你懶，係你個系統出咗事！」

**心態類內容 CTA 原則：** 必須提供「可獲取的工具」而非「自我揭露」
> ✅ 「留言 system 送 3 步建立自律系統清單」
> ❌ 「留言同我講你係咪靠意志力撐」

---

### 模式三：視覺與文案割裂（留存率斷崖）

**案例：** 高踭鞋腳痛片（第 5 秒留存率從 80% 暴跌至 35%）

**問題：** 口播說「腳喺度求救緊」，但畫面是「歲月靜好的泡腳場景」→ 視覺與聽覺不一致，大腦產生混亂。

**鐵則：每一句口播，旁邊必須標註「這句話對應的畫面是什麼」。**
> 如果畫面不能強化這句話的情緒（痛、爽、驚訝），這句話或這個畫面需要修改。

**修正：**
- Hook「腳求救緊」→ 畫面必須是：紅腫腳趾特寫 / 痛苦揉腳掌 / 地鐵脫鞋狼狽場景
- 講解「小腿是元兇」→ 畫面必須配解剖圖或紅線標註

---

### 模式四：邏輯鏈條太長，缺乏即時衝擊

**問題：** 詳細解釋「足弓塌陷 → 腳底痛 → 步姿調整 → 腰要出力 → 腰痛」的完整邏輯鏈

**原則：** 這種邏輯更適合 Carousel（圖文），不適合 Reels。

**Reels 結構原則：「先給藥，再解釋病理」**
```
前 5 秒：展示痛點（痛苦畫面）
5-15 秒：立即展示解決動作（即時希望）
15 秒後：簡要解釋原理 或 引導至私訊獲取
```

---

### 模式五：視覺審美疲勞（演算法冷卻期加速器）

**問題：** 連續多條片的字幕風格、拍攝背景、表現形式高度雷同 → 觀眾「這跟我看過的差不多」→ 演算法判斷為低質量內容

**修正：**
- 定期更換拍攝背景（戶外、診所感、純色背景）
- 嘗試不同字幕風格和動態效果
- 前 1 秒加入強視覺元素：紅圈標註、Before/After 對比、特寫鏡頭

---

### 模式六：CTA 誘餌重疊（互動率下降）

**問題：** 「留言 both 送腰腳痛自測法」與之前「留言 foot 送足弓自測法」在受眾感知上重疊

**原則：** 每個 CTA 誘餌必須是**獨特的、高價值的**，與之前所有內容不重疊。

**CTA 設計清單（已用過的誘餌）：**
- foot → 足弓自測法 ✅ 已用
- EY → 枕下肌群眼睛乾澀自測 ✅ 已用
- chain → 姿勢崩潰鏈自測 ✅ 已用
- 頭痛 → 枕下肌群頭痛自測 ✅ 已用

## 三、演算法冷卻期診斷與應對

### 冷卻期觸發條件
連續 2-3 條片的互動率和完播率低於帳號平均值 → 演算法降低新內容初始曝光

### 冷卻期應對策略（優先順序）

1. **爆款複製法（最快）：** 製作之前爆款的變體內容（如「足弓重建」系列第二集），快速提升互動率
2. **視覺大反差法：** 拍一條與以往風格截然不同的片，吸引演算法重新關注
3. **話題大眾化法：** 發布更具普適性的話題，擴大觸達範圍

## 四、泛人群 vs 泛垂直 Reels 深度對比

| 維度 | 泛人群 | 泛垂直 |
|------|--------|--------|
| **受眾範圍** | 最廣（所有人都可能有興趣）| 有特定場景但非精準受眾 |
| **Hook 設計** | 身份代入 + 普遍痛苦場景 | 特定症狀 + 反直覺觀點 |
| **內容深度** | 淺，共鳴為主 | 中，有一定專業性 |
| **CTA 設計** | 分享/收藏誘餌 | 留言互動誘餌 |
| **爆紅難度** | 較易（受眾基數大）| 中等（需精準 Hook）|
| **Cathyii 案例** | 姿勢崩潰鏈系列 | 枕下肌群眼睛乾澀 |

**泛垂直失敗的核心原因（67.6% 略過率案例）：**
1. 視覺平淡化：開頭畫面太「正常」，0.5 秒內無法製造視覺衝擊
2. Hook 過早給出暗示：「唔係眼睛出問題」→ 好奇心缺口太小
3. 反直覺概念缺乏圖解：「頸部影響眼睛」必須配解剖圖或紅線標註

## 五、高互動低播放診斷

**現象：** 讚、留言、收藏率高，但播放量低

**原因：** 演算法判斷這條片只對「現有粉絲」有吸引力，但對「新觀眾」的 Hook 力不足 → 不推公域流量

**診斷問題：**
- Hook 是否只有「已了解你的粉絲」才能理解？
- 封面/前 3 秒對完全不認識你的人是否有吸引力？
- 這條片是「粉絲片」還是「引流片」？

**修正：** 引流片的 Hook 必須對「從未見過你」的人也有即時吸引力。

## 六、IG Stories 完整攻略（3.4.mp4）

### Stories 高流量公式
**高互動率 × 高停留率 = 高流量**

### Stories 觀看率健康指標
- 非常優秀：20% 以上
- 健康良好：10%-15%
- 有待加強：5% 以下

### 影響流量的關鍵動作（重要性排序）
1. 私訊（DM）— 最高權重
2. 貼紙互動（投票、問答、滑桿）
3. 完整觀看
4. 截圖/分享

### 高流量 Stories 三大心法
1. **視覺吸引力：** 人臉 + 動態影片 > 靜態圖片
2. **提供價值：** 知識/娛樂/情感三選一
3. **未完待續感：** 一個故事拆成 3-5 則，每則結尾製造懸念

### Stories 三大內容公式
1. **故事敘述公式：** 情境引入 → 衝突/困境 → 轉折/領悟 → 價值提煉 → 互動
2. **紀錄式內容公式：** 成果預告 → 過程展示 → 困難/意外 → 衝刺完成 → 感悟 → 互動
3. **觀點表達公式：** 拋出議題 → 亮出觀點 → 互動貼紙

### Stories 轉化 4 步公式
1. 鋪墊需求，引發共鳴（只談痛點，不提產品）
2. 提出解方，展現價值（學員見證 + 成果展示）
3. 設計無法抗拒的 CTA（私訊關鍵字 / 投票引導 / 問答貼紙）
4. 補充限時感與稀缺性（數量限制 + 時間限制）

### Stories 5 大扼殺流量的錯誤
1. 單向輸出，零互動貼紙
2. 資訊過載，排版混亂
3. 影片沒字幕（大部分用戶靜音觀看）
4. 內容無關聯，隨意拼湊
5. 過度銷售，缺乏溫度

## 七、爆款元素系統（211.mp4）

### 三大爆款元素

**1. 盲盒元素（Blind Box）**
- 定義：結果未知、充滿懸念、帶來驚喜
- 底層邏輯：滿足對未知的「好奇」，對驚喜的「渴望」
- Cathyii 應用：「我用這個動作做了 30 天，最後的結果是...」

**2. 驗證/解密元素（Verification）**
- 定義：求真、實測、揭秘、闢謠
- 底層邏輯：滿足好奇，提供真相，建立信任
- Cathyii 應用：「網傳『每天拉筋 10 分鐘』真的有效嗎？我連續 30 天實測」

**3. 意外元素（Unexpected）**
- 定義：出乎意料、劇情反轉、預期落差
- 底層邏輯：創造「意料之外，情理之中」的瞬間
- Cathyii 應用：「本來想示範正確坐姿，結果發現自己也坐錯了...」

## 八、數據診斷優先框架（1.6.2026 新增）

> 來源：2026年6月1日 AI 對話診斷記錄
> 核心原則：**先診斷病因，再決定解法。「數據差」不等於「Hook 差」。**

### 8.1 三層數據診斷法（必須按順序）

| 診斷層 | 關鍵指標 | 正常值 | 如果差 = 病根在哪 | 解法方向 |
|--------|---------|--------|-----------------|----------|
| **第一層：播放量 / Reach** | 播放量 | 新號 200-500 屬正常 | 演算法未推（帳號年齡問題）| 穩定出片、累積帳號權重，**唔好改 Hook** |
| **第二層：略過率** | 前 3 秒略過率 | <50% 健康 | 開場畫面問題（唔係文字問題）| 改**畫面 Hook**，唔係文字 |
| **第三層：完播率 / 平均觀看時長** | 完播率 | >30% 健康 | 中段節奏問題 | 改節奏 / 壓縮鋪墊 |

**鐵則：略過率 >60% = 死因 100% 在前 3 秒畫面，唔係文字。**

### 8.2 盲目歸因陷阱（最常見錯誤）

**錯誤循環：**
```
數據差 → 假設係 Hook 問題 → 不停改文字 Hook → 改極都冇信心
```

**正確循環：**
```
數據差 → 先睇三層數字 → 確認病根 → 針對性改一個變量
```

**Cathyii 真實案例（2026.6.1）：**
- 略過率 66.3%、平均觀看 12 秒、留存率 35%
- 診斷：死因在前 3 秒畫面（「真人望鏡頭準備講嘢」開場）
- 錯誤做法：不停改文字 Hook
- 正確做法：改開場畫面（物件特寫 / 動作懸念 / 對比畫面）

## 九、視覺 Hook vs 文字 Hook 分離原則（1.6.2026 新增）

### 9.1 核心原則

> **Reels 前 1 秒，觀眾看的是畫面，不是字。文字 Hook 再準，畫面 Hook 太弱，觀眾在第一幀就走了。**

### 9.2 「真人望鏡頭」開場的致命問題

觀眾每日刷到 100 個「真人望鏡頭準備講嘢」的片，這是 IG 上**最容易被滑走的開場類型**，因為：
- 觀眾的拇指在 0.5 秒內已做決定：滑走
- 即使文字 Hook 寫得好，觀眾根本未看到第二秒就已離開
- 等於「裝修一間冇人入到去的舖頭」

### 9.3 高效畫面 Hook 選項（按執行難度排序）

| 選項 | 畫面描述 | 適用場景 |
|------|---------|----------|
| **物件特寫** | 止痛藥被啪空、首飾箱 vs 藥箱 | 有道具的痛症片 |
| **動作懸念** | 手按後尾枕、面部猙獰特寫（唔望鏡頭）| 按壓動作類 |
| **對比畫面** | Before/After 並排、縮頸 vs 天鵝頸 | 體態改善類 |
| **timelapse 過程** | 斜方肌慢動作隆起過程 | 機制解釋類 |

## 十、爆款複製法：先拆解自己的成功片（1.6.2026 新增）

> **你手上已經有答案，你只係未去分析佢。**

### 10.1 核心邏輯

當帳號有過爆款（4萬/8萬 views），而近期片死，**問題唔係「點樣由零開始」，而係「點樣 replicate 自己的成功」。**

停止問「下條 Hook 點寫」，先去解剖自己的爆款。

### 10.2 爆款拆解清單（必做）

| 拆解項目 | 要記錄什麼 |
|---------|----------|
| **題材** | 講哪個身體部位 / 哪個痛症？ |
| **開場畫面（第 1 幀）** | 係真人臉？物件？動作？文字？ |
| **文字 Hook** | 一字不漏抄低 |
| **入口角度** | 痛症入口？情緒入口？場景入口？ |
| **片長** | 幾多秒？ |
| **節奏** | 幾耐入正題？ |
| **CTA** | 點收尾？ |
| **發布時間** | 星期幾、幾點 |
| **留存率 / 完播** | 後台數字 |

### 10.3 爆款 vs 死片對比分析

把爆款 vs 最近死片擺在一起，找**差異點**。差異通常集中在：
- 開場畫面類型（爆款可能唔係真人臉開場）
- 題材（爆款可能講咗更廣泛 / 更有共鳴的痛症）
- 入口角度（爆款可能用咗唔同的切入點）

### 10.4 Cathyii 爆款公式（已驗證）

```
【具體痛症 + 感官比喻】+【推翻觀眾花緊錢/力氣的方案】+【反轉金句 / 簡單自救承諾】
```

**已驗證案例：**
- 4萬片（拇趾外翻）：「以為帶矯正器有用 → 其實係叫隻腳放棄自救」
- 8萬片（扁平足）：「以為矯正鞋墊有用 → 其實係叫腳放棄自救」
- 天鵝頸稿：「以為斜方肌要拉鬆 → 其實愈拉愈緊，要『關掉』佢」

## 十一、發布前完整自我檢查清單

### Hook 層（3 問）
- [ ] 我的前 3 秒畫面，看起來像不像一個無聊的廣告？（如果是，重拍）
- [ ] 我的 Hook 有沒有讓觀眾在心裡驚呼「吓？點解嘅？」（如果沒有，重寫）
- [ ] 我的 Hook 對「從未見過我」的人是否也有即時吸引力？

### 視覺層（3 問）
- [ ] 每一句口播，對應的畫面能否強化那句話的情緒？
- [ ] 我解釋反直覺概念時，有沒有用圖解來證明？
- [ ] 這條片的視覺風格與上一條片是否過於相似？

### 結構層（4 問）
- [ ] 我有沒有在 15 秒內給出「即時可做的東西」？
- [ ] 邏輯鏈條是否超過 3 層？（超過就壓縮）
- [ ] CTA 誘餌是否與之前所有片的誘餌不重疊？
- [ ] 如果是心態類內容，有沒有用體態問題作包裝入口？

### 演算法層（2 問）
- [ ] 這條片是「引流片」還是「粉絲片」？（引流片需要更強的公域 Hook）
- [ ] 帳號最近 2-3 條片的互動率如何？是否需要先發一條爆款複製片？

## 十二、「分級自測」類內容的特殊指標邏輯（2026.6.13 新增）

> 來源：EP2 拇趾外翻分級片真實數據診斷（2026年6月）
> 核心洞察：**分級自測是知識型體態帳號的殺手鐧內容類型，但其數據特徵與一般教學類不同，不能用同一套標準評估。**

### 12.1 EP2 真實數據（拇趾外翻分級自測片）

| 指標 | 數值 | 解讀 |
|------|------|------|
| Views | 8,717 | 演算法有推，非粉絲觸及94.8% |
| Likes | 82 | 低，但屬分級自測類天然特徵 |
| Comments | 236 | **極高**，觀眾自發留言Stage索取自測法 |
| Comments/Likes比 | 2.88 | 正常值<0.5，此數字代表內容精準命中受眾 |
| Saves | 136（Saves率2.0%）| 高，觀眾儲起備用 |
| Shares | 64 | 健康 |
| 完播率 | 13% | 問題所在 |
| 前3秒流失 | 33% | 視覺Hook缺位 |
| 新增粉絲 | 63人 | 轉粉率0.72%，中上水準 |

**診斷結論：內容本身有爆款內核，問題只在開場視覺Hook缺位。不需要重做內容，只需改包裝。**

### 12.2 分級自測類的天然數據特徵

「分級自測」類內容的數據特徵與一般教學類截然不同：

- **天然低Likes、高Saves**：觀眾儲起來備用，但不一定按讚（無情感爆發點）
- **天然高Comments**：觀眾想留言對號入座（「我係中度！」「我係重度點算？」）
- **評估標準應以Saves + Comments為主**，而非Likes
- **Comments內容幾乎全是留Stage + 索取自測法**，代表受眾精準，需求真實

**錯誤評估方式：** 「Likes只有82，這條片失敗了。」
**正確評估方式：** 「Saves率2.0%、Comments/Likes=2.88，內容有效，包裝需改善。」

### 12.3 分級自測類的「被低估的健康乾貨」識別法

當一條片出現以下數據組合時，代表**內容有爆款內核，但包裝不足**，不需要重做，只需改包裝：

- Comments/Likes比 > 1（觀眾有話說但無情感共鳴到按讚）
- Saves率 ≥ 1.5%（觀眾覺得有用，儲起來）
- 但完播率 < 15%（大量人在中途流失）

**診斷結論：「進門難，進來就不想走」——Hook問題，非內容問題。**

### 12.4 分級自測類的最佳開場結構

**舊的開場邏輯（問題所在）：**
人臉出現 → 開口說話 → 字幕跟上

**新的開場邏輯（改後）：**
身體部位特寫（填滿螢幕）→ 大字幕先出現 → 人臉才出現

具體操作：
- 第1秒：**只拍腳趾**，用手做「扳」的動作，填滿整個螢幕
- 同時出現大字幕（字體佔螢幕至少50%）：「去扳返你隻腳趾公」
- 第2-3秒：才切到人臉，說出第一句話

**原理：** 身體部位特寫在Reels feed裡是「異常視覺」，觀眾的眼睛會本能停下來。這是Pattern Interrupt——打斷滑動慣性。Talking head（人臉直接出現）是最常見的形式，在feed裡沒有視覺差異化，應避免作為第一幀。

### 12.5 分級自測類的片長控制

| 片長 | 預期完播率 | 建議 |
|------|----------|------|
| 30-45秒 | 25-40% | **推薦**：每個等級只說一句，不解釋原因 |
| 45-60秒 | 15-25% | 可接受，但需要高密度節奏 |
| 60秒以上 | <15% | 避免，除非有強視覺Hook支撐 |

**實操原則：** 同樣的分級內容，壓縮版（40秒）的完播率通常是完整版（60秒+）的2-3倍。每個等級只說一句，不解釋原因——解釋原因是下一條片的內容。

### 12.6 分級自測類的CTA設計

**固定CTA模板：**
> 「留言你係邊一種（輕/中/重），我DM你對應嘅動作包」

**三重目的：**
1. 推高Comments（演算法訊號）
2. 建立私域連接（DM引流到WhatsApp社群）
3. 篩選高意願受眾（願意留言的人才是真正想改善的人）

**注意：** 當每條片有200+個DM需要回覆時，必須考慮ManyChat自動化，否則人手回覆會成為增長瓶頸。

### 12.7 分級自測類的情感落點（補充Likes）

分級自測類天然Likes率低，可在片尾加一句情感落點來補充Likes的情感觸發：

> 「唔論你係邊一種，都係有得改善——最怕係唔知自己係哪一種。」

這句話做了兩件事：給希望（有得改善）+ 製造緊迫感（最怕唔知）。

### 12.8 更新發布前自我檢查清單（分級自測類專用補充）

- [ ] 開場第1秒是否為身體部位特寫，而非人臉？
- [ ] 大字幕是否佔螢幕至少50%，且在人臉出現前先出現？
- [ ] 片長是否控制在45秒以內？
- [ ] 每個等級是否只說一句，沒有解釋原因？
- [ ] CTA是否引導觀眾留言Stage（輕/中/重）？
- [ ] 片尾是否有情感落點（給希望 + 製造緊迫感）？
- [ ] 是否已準備好ManyChat自動回覆，或有人手回覆的時間預算？

## 十三、帳號整體策略升級（2026年6月複盤 + Jacky Q&A整合）

> 來源：2026年6月14日複盤，整合 Jacky Q&A 老師指引、EP2 數據分析、產品路線圖及帳號現況觀察

### 13.1 帳號現況快照（2026年6月14日）

帳號 @life.guide007 粉絲 972，接近起號期門檻（1,000）。31 條貼文幾乎全部為 Reels，**Carousel 完全缺席**。主題分佈：腳部（拇趾外翻、足底筋膜炎）約 40%，頸/眼/腰 約 30%，個人成長/意志力 約 20%，人設介紹 約 10%。

**核心問題診斷：**

第一，Carousel 完全缺席。Carousel 的 Saves 率通常是 Reels 的 2-3 倍，是建立「被收藏的教育資源」最有效的格式，也是演算法長尾流量的來源。帳號目前完全依賴 Reels，失去了 Saves 最高的內容格式。

第二，主題稀釋帳號定位。眼睛/乾眼症、個人成長/意志力等主題偏離老師建議的「腳、腰、頸」流量池，令演算法難以精準推送。

第三，缺乏系列感。除拇趾外翻系列外，其他主題各自獨立，觀眾看完一條片後沒有明確理由追蹤帳號等待下集。

### 13.2 Jacky Q&A 老師核心指引（2026年5月-6月）

以下是老師在 Zoom Q&A 中針對 Cathy 帳號的具體指引，應作為所有內容決策的最高優先原則：

**流量池優先順序：** 腳部 > 腰部 > 頸部。這三個部位是主要流量池，其他部位（眼睛、手肘等）屬於次要，在帳號定位穩固前不建議發布。

**題材選擇標準：** 優先選「可見、具體、生活受影響」的痛症。拇趾外翻（可見變形）比頭痛（抽象）更有流量潛力，因為觀眾能直觀理解問題所在。

**Hook 評估標準：** 「如果人地聽完係問點解既＝好 hook；如果人地係話跟住呢＝not good」。好的 Hook 製造好奇心缺口，讓觀眾想知道原因；壞的 Hook 直接給答案，讓觀眾覺得「知道了，不用看完」。

**渠道角色分工：** Reels 是吸引陌生人的工具，Story 才是轉化工具。不要用 Reels 推付費產品，諮詢引導只在 Story 和 DM 中進行。

**Story 運營策略：** 靠 Story 培養信任。具體做法：截圖留言製造真實互動感、拍「我以前都 xxx，以為 yyy 幫到，但原來 zzz 先有用」的對比故事、如果解決唔到都可以 DM 我。

**分享率基準：** 分享率 3% 以上視為值得繼續推的方向。

### 13.3 Reels 製作升級標準（整合 EP2 複盤）

基於 EP2 拇趾外翻分級片（8,717 views / 完播率 13% / 略過率 37.3%）的診斷，以下是每條 Reels 發布前的強制自我檢查清單：

| 項目 | 標準 | 原因 |
|---|---|---|
| 開場第1秒 | 身體部位特寫或大字幕，非人臉開場 | 人臉開場是 feed 裡最容易被滑走的形式 |
| 大字幕 | 佔螢幕 50% 以上，關鍵字放大或變色 | 三維 Hook 齊備（視覺 + 大字幕 + 口播）|
| 片長 | 30-45 秒為目標，最長不超過 60 秒 | 同樣內容壓縮版完播率是完整版的 2-3 倍 |
| Hook 類型 | 聽完係「問點解」，而非「跟住做」| Jacky 老師核心標準 |
| 反轉金句 | 有「你以為係A，其實係B」的結構 | 製造認知衝突，推高分享率 |
| 情感落點 | 片尾有一句讓觀眾感同身受的話 | 補充 Likes 率（分級自測類天然 Likes 率低）|
| CTA 關鍵字 | 明確、簡短（一個英文字），與 DM 自動化對應 | 降低行動門檻，推高 Comments |
| 無 Dead Air | 全片沒有超過 1 秒的停頓或空白 | 維持節奏，降低略過率 |

### 13.4 Carousel 貼文策略（新增）

Carousel 是目前帳號最大的結構性缺口，應立即補入。以下是 Carousel 的最佳實踐：

**封面設計原則：** 封面必須在 feed 中作為靜態圖片吸引點擊，應包含「你以為係A，其實係B」的反轉金句或具體數字（如「3個動作」「5個誤解」）。

**內容結構：** 第1頁封面（Hook）→ 第2-5頁核心內容（每頁一個重點）→ 最後一頁 CTA（收藏 + 分享）。每頁文字不超過 20 字，配合圖解。

**發布頻率：** 每週一條 Reels + 隔週一條 Carousel。Carousel 不需要每週發，但必須定期出現。

**最佳 Carousel 主題類型：** 懶人包（「X個你以為對但其實錯的習慣」）、自測清單（「X個動作自測你的XXX」）、機制拆解（「為什麼你的XXX會痛：一條線的連鎖反應」）。

### 13.5 Story 運營策略（新增）

Story 是轉化工具，以下是三種高效 Story 類型：

**類型一：留言截圖 Story（每條 Reels 發布後 24-48 小時）**
截取觀眾的精彩留言（如「我係中度，點算好？」），加上回應，製造真實互動感，同時引導其他粉絲 DM。

**類型二：問答/投票 Story（每週一次）**
問題範例：「你最近最困擾你的係腰痛、頸痛定係腳痛？」這類 Story 同時收集選題方向，又讓粉絲感到被重視。

**類型三：1v1 諮詢引導 Story（每月 1-2 次，不要太頻繁）**
只在已有 2-3 條高互動 Reels 後才發。格式：「最近收到好多問我可唔可以幫佢睇體態，我係咁回應嘅⋯⋯」+ 連結到 Google Form。不要直接說「我有諮詢，快來報名」。

### 13.6 現階段禁止事項

以下行動在起號期（粉絲 400-1,000）是錯誤時機，應嚴格避免：

在 Reels 直接推諮詢或課程（Reels 的唯一任務是吸引陌生人、建立信任，不是銷售）；發布眼睛/乾眼症/意志力等偏離主題的內容（稀釋帳號標籤）；每天發帖（演算法看互動率，不是發帖頻率）；公開個人 WhatsApp 號碼（用 Google Form + WhatsApp 社群作緩衝）。
