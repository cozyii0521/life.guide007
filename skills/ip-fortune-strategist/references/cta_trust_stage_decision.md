# CTA Trust-Stage Decision Framework（Version A vs B）
**版本：** 1.0 | **建立日期：** 2026-07-15
**觸發來源：** 15.7.2025ai.docx 對話分析——另一個 AI 對「三層體態自測」CTA 兩個版本的決策邏輯提取

---

## 一、這個框架解決什麼問題

現有 `cta_single_exit_principle.md` 已建立「一條片一個主要 CTA 動作」的鐵律，並定義了 Version A（養信任型）和 Version B（篩選變現型）的基本區別。但沒有回答一個關鍵問題：

> **「我現在應該用 Version A 還是 Version B？」**

這個框架提供具體的決策標準，讓 Cathy 在每條片出街前，能夠根據帳號當前狀態做出正確選擇。

## 二、兩個版本的核心差異

### Version A：養信任型（低門檻互動，慢火育客）

**口播結構：**
```
「而家做一件事——留言話我知：你係第一層、第二層、第三層有問題，定係全部正常。
我 DM 你一份『由下而上改善清單』，根據你嘅結果，畀返對應嘅動作你自己做。

但我老實講——如果你三層都有問題，靠清單自己執好難搞得掂，因為你根本分唔清邊層先係帶頭嗰個源頭，做錯方向仲越矯越傷。
呢種情況，你需要嘅係一次一對一評估，我幫你搵出源頭嗰層，即場設計你專屬嘅動作。
有需要，喺留言打『評估』，我同你講。」
```

**轉化機制：**
```
免費清單降低門檻 → 拉 engagement
↓
「三層都有問題」的人自然對號入座
↓
「清單搞唔掂」畫出界線
↓
付費評估變成觀眾自己判斷「我係嗰種需要的人」
```

**特點：**
- 主要動作：留言拎免費清單
- 付費評估是「次要出口」（有需要才打「評估」）
- 壓力低，但轉化慢
- 適合建立長期關係

---

### Version B：篩選變現型（直接引導高意向，快火收單）

**口播結構：**
```
「而家做件事：對住鏡再企一次，數下你有幾多層歪咗。

一層歪，你自己執有得救——留言打『1』，我 DM 你嗰一層嘅針對動作。

但如果你兩層或以上都歪，聽好——你唔係靠一兩個動作救得返，因為你根本分唔清邊層帶頭歪，做錯方向只會越矯越傷。
physio 可以幫你止嗰陣痛，但佢唔會幫你重排成條力鏈，所以你痛極都斷唔到尾。
呢個正正係我做嘅嘢：一次一對一評估，我幫你揾出源頭嗰層，即場設計你專屬嘅矯正動作，由個根度斷尾。
名額有限，想約留言打『評估』。」
```

**轉化機制：**
```
「數下歪幾多層」逼觀眾即場自我診斷
↓
「一層 vs 兩層以上」自動分流
↓
對「兩層以上」明講「physio 止痛 ≠ 重排力鏈」
↓
付費評估定位成 physio 做唔到的事
↓
「名額有限」加輕微稀缺感
```

**特點：**
- 主要動作：自我分流 + 直接約評估
- 壓力較高，但轉化快
- 來的客更精準（已自我篩選為「兩層以上」）
- 適合已有熟客、準備收單

## 三、決策框架：我現在應該用哪個版本？

### 3.1 五個決策維度

| 決策維度 | Version A 的信號 | Version B 的信號 |
|---------|----------------|----------------|
| **帳號粉絲量** | < 1,000 粉絲 | > 1,000 粉絲，且有穩定互動 |
| **互動質量** | 留言多是「好有用」「謝謝」（淺層互動） | 留言多是「我有呢個問題」「我係咁」（深層代入） |
| **信任指標** | 觀眾還在「認識你」階段 | 觀眾已經「信任你的判斷」 |
| **收單準備度** | 評估流程未完善，未準備好接單 | 評估流程完善，有時間接單 |
| **帳號歷史** | 第 1-5 條片 | 已出 5+ 條片，有穩定受眾 |

### 3.2 決策樹

```
你現在有穩定互動的熟客嗎？
├── 否 → 用 Version A（先養信任）
└── 是
    ↓
    你的評估流程完善、有時間接單嗎？
    ├── 否 → 用 Version A（先完善流程）
    └── 是
        ↓
        你的留言中有多少人主動說「我有這個問題」？
        ├── 少於 10% → 用 Version A（信任未夠厚）
        └── 超過 10% → 可以試 Version B（篩選變現）
```

### 3.3 Cathy 當前建議

**現階段（帳號建立初期）：用 Version A。**

理由：
1. 帳號信任基礎可能未夠打 Version B
2. Version B 的「名額有限」在信任未建立時會顯得 hard sell
3. 先出 3-5 條片用 Version A 養住，觀察留言打「評估」的人多不多
4. 夠的話再切 Version B 收單，不要一步跳去 B

## 四、Version A 的進階策略：如何「慢火育客」

### 4.1 三個轉化節點

**節點 1：留言互動（第一次觸達）**
- 觀眾留言自測結果（第一層/第二層/第三層/全部正常）
- 你 DM 對應的改善清單
- 目的：建立「你真的幫到我」的第一次體驗

**節點 2：清單跟進（第二次觸達）**
- 觀眾收到清單後，自己做動作
- 有些人會有改善，有些人「三層都有問題」做不好
- 目的：讓觀眾自己發現「我需要更多幫助」

**節點 3：評估邀請（第三次觸達）**
- 對「三層都有問題」的人，主動跟進：「你試咗清單嘅動作，有冇感覺好咗？」
- 如果沒有明顯改善，自然引導到一對一評估
- 目的：讓付費評估成為觀眾「自己想要」的下一步

### 4.2 DM 清單的設計原則

**清單必須：**
- 針對每一層有具體動作（不是泛泛的「做運動」）
- 有「你可以自己做」的部分（降低門檻）
- 有「如果三層都有問題」的說明（為評估鋪路）

**清單不能：**
- 把所有動作全部給出（觀眾做完就沒有理由找你）
- 完全解決問題（否則沒有理由付費評估）
- 太複雜（觀眾做不到會放棄，不會找你）

## 五、Version B 的使用注意事項

### 5.1 「名額有限」的使用原則

**什麼時候可以用：**
- 你真的有名額限制（每週只能接 X 個評估）
- 你有具體的截止日期（例如「本月只剩 3 個名額」）

**什麼時候不能用：**
- 純粹為了製造稀缺感，但實際上沒有限制
- 觀眾如果發現是假的，信任會崩塌

### 5.2 「physio 止痛 ≠ 重排力鏈」的使用原則

**這句話的功能：**
- 把付費評估定位成 physio 做不到的事
- 讓觀眾明白「去 physio 解決不了根本問題」

**使用禁忌：**
- 不要說 physio 「沒用」或「不好」（這是攻擊，會引發爭議）
- 只說「physio 止痛，我重排力鏈」（這是區隔，不是攻擊）
- 每條片都要出現這句話，養成觀眾對你的認知標籤
