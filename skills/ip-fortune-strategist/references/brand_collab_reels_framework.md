# 品牌合作 Reels 植入框架
# Brand Collab Reels Integration Framework

**來源：** 2026-07-11 附件分析（Legacy 鞋墊合作 + 吸塵機 KOL 對比）
**核心洞察：** 品牌合作 Reels 的最大陷阱是「整條片講產品」，正確做法是「解決問題時順帶出現的工具」。

---

## 一、兩種合作片的根本差異

| 維度 | 產品導向（陷阱）| 方案導向（正路）|
|------|--------------|--------------|
| 觀眾睇完覺得 | 「佢賣緊嘢」| 「佢真係想幫我」|
| 產品角色 | 主角（成條片講佢）| 配角（解決方案之一）|
| 觀眾信任 | 「又係恰廣告」| 「佢係專家，順手推薦」|
| Cathy 定位 | 帶貨 KOL | 痛症專家 |
| 長期效果 | 一次性流量 | 持續信任積累 |

**IP 老師原則：** 條片幫觀眾解決問題時順便分享的「解決方法」——並不是「成條片講產品」。

---

## 二、品牌植入的黃金公式

```
痛症直擊（Hook）
    ↓
反常識歸因（唔係你以為嗰個原因）
    ↓
教 1 個真正有用的動作（免費乾貨，建立信任）
    ↓
點出「動作的限制」（主動有極限）
    ↓
自然帶出產品（被動防線 / 日常支援）
    ↓
真實體感描述（唔係報規格）
    ↓
CTA（方案包裹 link，或分類留言）
```

**關鍵心法：** 先俾足乾貨（教動作），觀眾感受到你真心，然後你講「動作係主動叫醒肌肉，但你返工企成日、行成日，隻腳需要一個被動嘅支撐去接住你」——產品就係嗰個「日常被動防線」。

---

## 三、「主動 + 被動雙防線」框架

這是 Cathy 品牌合作的核心差異化角度，適用於所有足部/體態相關產品合作。

### 3.1 框架定義

| 防線 | 定義 | 例子 |
|------|------|------|
| **主動防線** | 你教的動作，叫醒目標肌肉 | 脛後肌訓練、足弓拱起、腳趾抓地 |
| **被動防線** | 日常使用的外部支撐，在你不運動的 16 個鐘頂住 | 醫學鞋墊、足弓支撐器 |

### 3.2 核心論點（差異化 Angle）

> 「做足弓運動，係主動叫醒條肌肉。
> 但你每日做運動嗰 10 分鐘 vs 你返工站立、行走嗰 16 個鐘——
> 你叫醒咗佢，但冇嘢頂住佢，佢企唔到成日，一到下晝又塌返、又痛返。
> 真正嘅完整方案係兩條防線：主動叫醒 + 被動支撐。」

### 3.3 點解呢個 Angle 係神級破局

1. **完美差異化**：市場上所有「教動作」的片都停在主動防線，你係第一個講「動作的限制 + 點樣補足」
2. **唔撞「唔使買鞋墊」**：你唔係話「買鞋墊代替動作」，你係話「動作 + 鞋墊一齊做先完整」——反而 higher level，顯得更專業
3. **產品出場超自然**：產品唔係「廣告」，係你「主動+被動」專業框架裡面的「被動防線」——完全符合 IP 老師要求
4. **真實體感支撐**：你講嘅「lifting up、cushion 緩衝感」= 正正係「被動頂住足弓」的感覺，講起上嚟真實可信

## 四、產品出場時機法則

> **黃金法則：產品必須在全片至少 70% 位置之後才出場。**

| 時機 | 效果 |
|------|------|
| 全片 30% 出場 | 觀眾覺得「整條片都係廣告」|
| 全片 50% 出場 | 勉強可接受，但信任未建立足夠 |
| 全片 70% 出場 | ✅ 觀眾已接收足夠乾貨，信任建立，接受推薦 |
| 全片 75%+ 出場 | ✅✅ 最佳，觀眾完全進入「想解決問題」狀態 |

## 五、體感描述法則（唔好報規格）

**錯誤做法（報規格）：**
> 「30,000% 超強吸力、100 度熱水清洗、6 厘米越障功能」

**正確做法（講體感）：**
> 「一著上去，即刻 feel 到足弓被輕輕托起嗰種 lifting 感，行成日都有個 cushion 幫你緩衝，隻腳冇咁快攰。」

**原則：** 體感描述必須是你親身試用後的真實感受，愈具體愈有說服力。規格是廠商的語言，體感是用家的語言。

## 六、分潤 CTA 三個版本

### 版本 A：方案包裹 link（最推薦，最保信任）

```
「你係『做過動作又痛返』，定係『從來未郁過』？
留言話我知你嘅情況，我 DM 你一份完整嘅『主動+被動足弓修復方案』——
入面有埋我用緊嗰對 [產品名] 嘅獨家優惠連結，
原價 XXX，用我條 link 而家減到 XXX，仲免費送貨。
想要方案同優惠，留言『[關鍵詞]』俾我。」
```

**優點：** 方案行先，link 係「入面包埋」——保住專業感，同時導向購買。

### 版本 B：分類留言（留言率最高）

```
「你係邊種？
① 做過動作又痛返 ② 從來未郁過 ③ 想直接試對鞋墊
留言你嘅號碼——
揀①②我 DM 你修復方案，揀③我直接 send 你 [產品名] 嘅獨家優惠連結（減到 XXX+免運）。」
```

**優點：** 留言率最高（分類法），高意向買家（揀③）直接收割，唔想買的（①②）都留言推互動數據。

### 版本 C：直接帶貨（適合高信任帳號）

```
「想要嗰對幫我頂住足弓嘅 [產品名]？
我幫大家問到一個獨家優惠——原價 XXX，經我條 link 減到 XXX，仲免費送貨。
留言『[關鍵詞]』，我即刻 DM 你優惠連結，同埋一份足弓自測方法俾你。」
```

**適用條件：** 帳號已有足夠信任積累，觀眾認識你的專業定位。

## 七、合規提醒

1. **利益披露**：收佣的合作最好標明（hashtag 加 `#廣告` 或 `#合作`，或口播/caption 提一句「同 [品牌] 合作」）。坦白反而增加信任，不會影響銷售。
2. **價錢一致性**：確保口播講的優惠價 = 你條 link 入面的實際價，不一致會令觀眾流失。
3. **真實試用**：體感描述必須是真實試用後的感受，不能虛構。

## 八、品牌合作選題優先級（以足部/體態產品為例）

| 選題 | 與產品貼合度 | 推薦度 | 原因 |
|------|------------|--------|------|
| 足底筋膜炎 | ⭐⭐⭐⭐⭐ | 🥇 首選 | 足弓支撐 = 鞋墊核心賣點，帶出最自然 |
| 膝痛（足弓上游）| ⭐⭐⭐⭐ | 🥈 次選 | 可承接膝痛系列，鞋墊做「頂住足弓、減膝頭壓力」的日常支援 |
| 拗柴 / 腳踝不穩 | ⭐⭐⭐⭐ | 🥈 次選 | 足弓支撐直接減少腳踝代償，帶出合理 |
| 運動後腳板痛 | ⭐⭐⭐ | 🥉 第三 | 適合推 Sports 版鞋墊，但偏離久坐 OL 核心受眾 |
