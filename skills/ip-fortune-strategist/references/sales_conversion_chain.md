# 5 段成交鏈 (Sales Conversion Chain)

這份筆記的核心思想是：一個陌生人從刷到你的 Reels，到最後願意付錢給你，中間至少隔著五個環節。不是單靠一條爆款內容就能直接成交，而是要逐環推進。

## 原則：注意力值錢，但接不住就一文不值
許多人只重視「爆」，即搶眼球，但忽略了爆之後觀眾會去哪裡。若內容只能讓人停下來，但沒有設計後續步驟，那麼注意力無法轉成資產，也無法變成成交。

## 五段成交鏈模型
從被看見到被購買，共有五環：

| 環節 | 關鍵任務 | 觀眾內心 OS |
|---|---|---|
| **注意力 (Attention)** | 讓人停下來 | 「等等，這是什麼？」 |
| **影響力 (Influence)** | 讓觀眾開始認定你的路線與主張 | 「這個人，不一樣。」 |
| **關係 (Relationship)** | 讓他願意再回來、持續互動 | 「我想繼續看下去。」 |
| **信任 (Trust)** | 讓他相信你是真的、有料的 | 「這不是套路。」 |
| **成交 (Conversion)** | 讓他願意採取付費或下一步行動 | 「我要，怎麼找你？」 |

## Instagram 應用拆解 (前四環)

### 1. 注意力：Reels / 公域
目的不是教育，而是讓對方停下來。關鍵點：
1. 爆點要設計在前 1–2 秒，靠的是反差、問題、熟悉感或情緒。
2. 別把內容做成「教學 + 摘要」，而要先做成「讓人停下來的片頭」。
3. 標題或第一句必須讓人知道「這條片會替我做什麼」。

### 2. 影響力：內容 + 主張
目的不是單條片有用，而是讓人記住你代表什麼。關鍵點：
1. 每條片只講一個觀點。
2. 主張要一致，讓觀眾逐步建立你是某一類型的人。
3. 內容系列化，讓他人進來後，接連看多幾條都在加深同一印象。

### 3. 關係：Story + 留言區
目的不是曝光，而是把看過你的人變成會回來的人。關鍵點：
1. Story 每日或固定節奏出現，用投票、問答箱、幕後、導流建立陪伴感。
2. 留言區不是完結，而是下一條內容的資料庫。
3. 設計「留言關鍵詞 → 私訊」這個橋樑，讓互動者走向更深層接觸。

### 4. 信任：引流品 + 私域
目的不是送東西，而是讓人感覺你真誠、實在、交得出成果。關鍵點：
1. 引流品要讓人覺得實用，而非敷衍。
2. 私訊和 WhatsApp 才是慢慢建立真信任的地方。
3. 真實案例、學員故事、日常紀錄都能提高信任。

## Cathy 當前卡點與應用
你目前最明顯的卡點，不在「注意力」本身，而在後三環。有部分 Reels 能吸引留言和流量，但沒有清楚往下走的結構。留言拿引流品後，沒有自然延伸成更深的對話或需求辨識。缺少真實見證，所以信任環節薄弱，成交難以發生。

這表示你目前不是內容完全無效，而是成交鏈中段和後段尚未搭好。你需要：
- **設計「引導私訊」的機制**：在 Reels 留言區主動製造對話，問深度問題，邀請 DM。
- **在 Story 中設計「跟進」**：Reels 發佈後，用 Story 做 3–5 天的跟進，將「看過 Reels」轉化成「持續互動」。
- **在 WhatsApp 社群中設計「見證分享」**：將「個別 DM」轉化成「社群見證」。

這些是打通「關係環節」的關鍵步驟。
