# 系列 CTA 遞進設計框架 + 護理師身份差異化武器
**版本：** 1.0 | **建立日期：** 2026-06-29 | **觸發來源：** 足底筋膜炎 EP3 口播稿分析

## 一、這個框架解決什麼問題

現有 `viral_copywriting_engine.md` 已有「每集 DM 誘餌設計」和「分級類 DM 包」的框架，但缺少以下三個維度：

1. **系列 CTA 的「遞進邏輯」**：每集誘餌不只是「不撞」，而是要按「認知深度遞進」設計，讓每集的誘餌都是下一集的鋪墊
2. **護理師身份的「紅旗清單」作為差異化武器**：「幾時要搵專業」這個問題，是普通 KOL 不敢答、也答不了的問題——這正是護理師身份最值錢的地方
3. **「自我分級 + 紅旗清單」的具體設計規格**：如何設計一份讓觀眾「即刻知道自己幾嚴重」且「知道幾時要搵人」的 DM 資源

## 二、系列 CTA 遞進設計原則

### 2.1 三層遞進結構

系列片的 CTA 誘餌應按「認知深度」遞進，而不是平行排列：

```
第一層（入門）：「我有冇這個問題？」→ 自測工具
第二層（診斷）：「我的問題有幾嚴重？」→ 分級清單
第三層（行動）：「我應該怎麼做？幾時要搵人？」→ 紅旗清單 + 轉介訊號
```

**關鍵原則：每一層的誘餌，都要預設觀眾已經「通過」了上一層的認知。**

| 集數 | 認知層次 | 誘餌類型 | 設計邏輯 |
|------|---------|---------|---------|
| EP1（入門） | 「我有冇這個問題？」 | 自測工具（10 秒自測法）| 降低門檻，讓觀眾確認自己是 TA |
| EP2（診斷） | 「我的問題源頭在哪？」 | 診斷工具（鞋磨損對應指引）| 從外部可見的線索確認根源 |
| EP3（分級）| 「我有幾嚴重？幾時要搵人？」 | 分級清單 + 紅旗清單 | 讓觀眾知道自己的位置，並知道邊界在哪 |

**以足底筋膜炎系列為例：**

| 集數 | 關鍵字 | 誘餌內容 | 認知遞進 |
|------|--------|---------|---------|
| EP1 | `FOOT` | 10 秒自測足弓法 | 「我有冇足弓問題？」 |
| EP2 | `驗鞋` | 鞋磨損對應自救指引 | 「我的鞋在告訴我什麼？」 |
| EP3 | `晨痛` | 足底筋膜炎自我分級 + 紅旗清單 | 「我有幾嚴重？幾時要搵人？」 |

### 2.2 遞進設計的三個條件

**條件一：每集誘餌必須「唔撞」**
- 不撞片內容（誘餌是片的延伸，不是片的懶人包）
- 不撞其他集的誘餌（每集提供不同維度的價值）

**條件二：每集誘餌必須「預設上一層認知」**
- EP3 的誘餌（分級清單）預設觀眾已知道「足底筋膜炎是什麼」（EP1 建立的認知）
- 如果觀眾直接從 EP3 進入，誘餌的吸引力會略低——這是正常的，因為 EP3 本來就是服務「已有基礎」的人

**條件三：最後一集誘餌要「封頂」**
- 系列的最後一集誘餌，應該是「整個系列最有價值的資源」
- 足底筋膜炎系列的封頂誘餌 = 紅旗清單（「幾時要搵人」是最高價值的判斷）

## 三、護理師身份的「紅旗清單」差異化武器

### 3.1 為什麼「紅旗清單」是護理師身份最值錢的地方

普通健身 KOL 的誘餌：「完整訓練計劃」「動作示範包」「飲食建議」
→ 這些任何人都可以做，護理師身份沒有加分

護理師身份的獨特價值：**「幾時要搵專業」這個問題**
- 普通 KOL 不敢答（怕責任）
- 普通 KOL 也答不了（沒有臨床判斷能力）
- 觀眾最想知道的，恰恰是這個問題

**「紅旗清單」的定義：**
> 一份清單，列出「哪些症狀出現時，代表問題已超出自我處理範圍，需要尋求專業評估」的具體訊號。

### 3.2 紅旗清單的設計規格

一份有效的紅旗清單應包含三個部分：

**Part A：自我分級（我有幾嚴重？）**

| 級別 | 症狀描述 | 建議行動 |
|------|---------|---------|
| 🟢 輕度 | 偶爾晨痛，行幾步後消失，不影響日常 | 自我練習 + 預防性訓練 |
| 🟡 中度 | 每天晨痛，行路一段後仍有隱隱不適，上下樓梯有感 | 加強自我訓練 + 密切觀察 |
| 🔴 重度 | 全日持續痛，休息後無改善，或已影響步態 | 需要尋求臨床評估 |

**Part B：紅旗訊號（幾時要立刻搵人？）**

以下任何一個訊號出現，代表問題已超出自我處理範圍：
- 痛症持續超過 3 個月，自我訓練無改善
- 腳跟出現腫脹或發熱（可能有急性發炎）
- 痛症蔓延至腳踝或小腿（可能有其他結構問題）
- 行路時出現麻痺感或刺痛感（可能涉及神經）
- 早上第一步痛到無法正常落地（嚴重程度需評估）

**Part C：轉介前可做的事（給重度組的希望）**

> 即使是重度，在等待專業評估期間，仍可做：毛巾拉伸 + 腳踝轉圈（本集教的兩個動作）。這兩個動作不會加重傷害，可以暫時緩解晨痛。

### 3.3 紅旗清單的護理師差異化話術

在 CTA 中，護理師身份要明確出現：

**一般 KOL 的 CTA：**
> 「留言 XXX，我 DM 你完整訓練計劃。」

**護理師身份的 CTA（足底筋膜炎 EP3）：**
> 「留言『晨痛』，我 DM 你一份**自我分級 + 紅旗清單**——睇你係輕度、中度定重度，仲有邊幾個訊號一出現就唔好再自己搞、要搵專業。呢個係護理師先答到你嘅問題。」

**差異化的關鍵句：「呢個係護理師先答到你嘅問題。」**
- 不需要說「我是護理師」，用「護理師先答到」暗示身份
- 讓觀眾感受到「這個人給的不是普通 KOL 的內容」

## 五、系列 CTA 遞進設計的「封頂集」原則

### 5.1 什麼是封頂集

系列片的最後一集（或階段性封頂集）應具備：
- **最高認知深度的誘餌**（分級 + 紅旗，而非自測或診斷）
- **最強的護理師身份背書**（「幾時要搵人」是護理師才能答的問題）
- **最清晰的下一步行動**（輕/中/重三個級別各有對應行動）

### 5.2 封頂集的 CTA 結構

```
[情感落點] + [誘餌描述] + [護理師身份暗示] + [關鍵字]
```

**足底筋膜炎 EP3 示範：**
> 「痛咗幾個月、朝朝都係咁——唔好再拖。留言『晨痛』，我 DM 你一份自我分級 + 紅旗清單：睇你係輕度定已經轉慢性，仲有邊個訊號一出就唔好再自己搞——呢個係護理師先答到你嘅問題。」

## 七、使用指引

**何時使用此框架：**
- 當 Cathy 需要為系列片設計多集 CTA 誘餌時
- 當 Cathy 需要設計「分級 + 紅旗清單」類型的 DM 資源時
- 當 Cathy 需要在 CTA 中體現護理師身份差異化時
- 當 Cathy 規劃系列的「封頂集」時

**使用前必須確認：**
1. 這是系列的第幾集？（決定用哪一層的誘餌）
2. 系列已有哪些誘餌？（確保不撞）
3. 這集是否是封頂集？（決定是否用紅旗清單）
4. 紅旗清單的臨床內容，Cathy 需要確認準確性（護理師身份背書的前提是內容準確）

**快速診斷問題：**
- 「這集的誘餌，比上一集的誘餌，認知深度有沒有遞進？」
- 「這份 DM 資源，普通 KOL 能不能做？如果能，護理師身份沒有加分。」
- 「觀眾收到這份 DM 資源後，下一步是什麼？有沒有清晰的行動指引？」
