# 體態系列出片策略框架
## 適用場景：規劃痛症→體態掛勾系列 + 品牌帶貨片的出片次序

---

## 核心原則：痛症與體態強制掛勾

每一條 Reels 必須包含以下兩層，缺一不可：

### A 層：升格至體態（製造認知升級）
公式：
> 「呢個唔止關[痛症]事。[痛症部位]係你成個體態嘅[地基/鏈條/底座]——[部位]一[問題]，上面所有嘢都會[代償]。」

範例：
- 「足弓係你成個體態嘅地基，地基唔穩，上面所有嘢都會歪。」
- 「膝蓋內扣係你整個下半身力線歪咗的可見症狀，唔係獨立問題。」
- 「足底筋膜炎唔係腳板問題，係你整個下半身力線歪咗，腳板喺度硬頂。」

### B 層：惡化連鎖（製造緊迫感）
公式：
> 「如果唔處理，[時間框架]後，[後果 A] 同 [後果 B] 就會出現——到時唔係 [現有問題] 咁簡單，係 [更嚴重後果]。」

範例：
- 「半年到一年，膝頭同腰都要幫手頂住呢個唔穩」
- 「3-5 年後，唔係膝蓋痛，係退化性關節炎」
- 「腳底筋膜纖維化，到時唔係痛，係每一步都係撕裂感」

## 七條片出片次序框架

### 第 1 條：教學型（已驗證選題）
- 目的：漲粉 + 養信任
- 結構：視覺 Hook → 場景對號 → 推翻常識 → 原理 → 惡化層 → 動作 → 情感落點 → CTA
- CTA：留言關鍵字，DM 體態自評表

### 第 2 條：分級自測型（激活系列流量）
- 目的：天然驅動留言，激活演算法推流
- 結構：視覺 Hook → 場景對號 → 分級自測（輕/中/重）→ 升格至體態層 → 惡化層 → 1 個通用動作 → CTA
- CTA：留言「[關鍵字]」，DM 分級對應動作包 + 體態自評表

### 第 3 條：觀點型（打破變現死結）⭐ 最重要
- 目的：解決「痛的人只去找 physio」的變現死結
- 選題：「做完物理治療又復發？不是 physio 沒用，是少做了一步」
- 核心邏輯：Physio = 處理「痛」；體態矯正 = 處理「因」。兩者不對立，是流程的兩個環節。
- CTA：留言「評估」，DM 體態自評表（軟導流到 1v1）

### 第 4 條：教學型（高視覺衝擊）
- 目的：高意向觀眾，高視覺衝擊力
- 選題優先：X 型腿 + 膝痛（肉眼可見的體態問題）
- Hook：身體部位特寫，肉眼可見的體態問題

### 第 5 條：帶貨型（品牌合作）⭐ 7 月底前
- 目的：變現
- 結構：前 70% 教學（主動方案）→ 後 30% 帶出產品（被動方案）
- 核心邏輯：「主動（動作）+ 被動（鞋墊）= 完整的雙防線」
- 詳見 `brand_collab_reels_framework.md`

### 第 6 條：知識型（精準人群定向）
- 目的：精準觸及高意向人群
- 選題：行山 / 行街膝痛（精準場景定向）
- Hook：具體場景（行山落斜、行街行半個鐘）

### 第 7 條：分級自測型（重啟系列）
- 目的：重啟下滑系列的流量
- 選題：已有基礎但流量下滑的系列（如拇趾外翻 EP6）
- 結構：同第 2 條

## 另一個 AI 建議選題的底層邏輯分析

另一個 AI 的選題清單（12 個選題）背後有三個核心邏輯：

### 邏輯一：「橋樑邏輯」（痛是果，體態是因）
- 每個選題都在建立「痛症 → 體態問題」的因果鏈
- 最強的選題是「做完 physio 又復發」（#6）——直接打破「痛了才去找 physio」的思維定式

### 邏輯二：「排他性人群定向」
- 每個選題都有明確的人群排他性（行山的人、久坐的人、戴護膝的人）
- 避免「任何人都可以看」的泛人群選題

### 邏輯三：「自測工具作為變現漏斗入口」
- 每個選題都有「自測」的元素
- 自測 → 發現問題 → 需要專業評估 → 1v1 諮詢

## Legacy 帶貨片的選題切入優先級

| 切入角度 | 推薦度 | 原因 |
|---------|--------|------|
| 「主動有極限，被動要補上」 | ⭐⭐⭐ 最推薦 | 自然植入，不顯廣告感 |
| 「護理師試用報告」 | ⭐⭐ 推薦 | 建立信任，但需要有真實體感 |
| 「足底筋膜炎患者的日常防線」 | ⭐⭐ 推薦 | 精準 TA，高意向觀眾 |

### Recovery 舒痛醫學鞋墊 vs PB ProSport 運動鞋墊

| 維度 | Recovery 舒痛醫學鞋墊 | PB ProSport 運動鞋墊 |
|------|---------------------|---------------------|
| TA 匹配度 | ✅ 高（30-45 歲女性，久站/久坐，足底痛） | ❓ 中（運動愛好者） |

## 強制出片檢查清單

### Hook 層（0-3s）
- [ ] 第 1 幀係身體部位特寫（唔係人臉）
- [ ] 第 1 秒有大字幕（佔螢幕 50%+）
- [ ] Hook 有「排他性」（唔係任何人都會有呢個問題）
- [ ] Hook 唔過早揭示答案（製造懸念）

### 內容層
- [ ] 包含「升格至體態層」的句子（A 層）
- [ ] 包含「惡化連鎖」的時間框架（B 層）
- [ ] 片長 ≤ 55 秒
- [ ] 有至少 1 個可即時執行的動作

### CTA 層
- [ ] 有明確「留言關鍵字」誘餌
- [ ] 誘餌與前一條片的誘餌不重複
- [ ] DM 內容已準備好

## 變現漏斗設計

```
Reels（教學/分級自測）
↓ 留言關鍵字
DM 自動回覆（體態自評表 / 動作包）
↓ 體態自評表
發現「我需要專業評估」
↓
1v1 諮詢引導
↓
Legacy 鞋墊推薦（帶貨）
```

**關鍵：每一條片的 CTA 誘餌都應該指向「體態自評表」，而不是直接推 1v1 諮詢。**
體態自評表是「過濾機制」——只有真正有需要的人才會完成，這些人就是高意向客戶。
