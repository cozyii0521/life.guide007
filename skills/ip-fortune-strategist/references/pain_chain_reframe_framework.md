# 痛症鏈重構框架（Pain Chain Reframe Framework）
**版本：** 1.0 | **建立日期：** 2026-07-13  
**觸發來源：** 另一個 AI 對「三層體態自測」口播稿的重構分析（pasted_content_4.txt）

---

## 一、這個框架解決什麼問題

現有框架（`viral_replication_system.md` 六格公式、`teacher_zoom_0709_framework.md`）已定義了 Hook、潛在惡化層、職業定向等原則。但在分析另一個 AI 對「三層體態自測」口播稿的重構過程中，發現了三個現有框架尚未完整覆蓋的維度：

1. **「痛處≠病根」主張的前置植入**：觀眾在接受「三層自測」之前，必須先接受「你一直醫錯地方」的認知前提。若跳過這一步直接教自測，觀眾會把片當作「教學片」而非「解決我問題的片」。

2. **「平行三層」vs「遞進力鏈」的結構差異**：把三層體態問題排列成「平行清單」（每層都是「看位置→不正常→肌肉瞓著→痛」）會讓觀眾在第二層就能預測第三層，失去繼續看的動力。改為「由下往上傳的力鏈」（腳歪→逼膝→逼骨盆）能讓每一層都成為「下一層的懸念」。

3. **「physio 止痛 vs 我搵根」的定位分界線**：這是 Cathy 最核心的變現卡點——有痛症的人去找 physio，體態不好的人又不是 Cathy 的精準 TA。解決方法是在 CTA 前明確植入「physio 止痛，我重排力鏈」的分工定義，讓觀眾自己判斷「我需要的是哪一個」。

4. **「精準瞬間 Hook」vs「泛場景 Hook」的強度差異**：「返工坐得耐腰痛」是泛場景（任何人都講得出），「坐足一日，夜晚起身要撐住張枱先企得起」是精準瞬間（觀眾感覺被偷看日記）。精準瞬間的命中率遠高於泛場景。

5. **「版本 A 養信任 vs 版本 B 篩選變現」的 CTA 分流策略**：CTA 不是一個固定版本，而是根據帳號信任厚度選擇不同力度。現有框架缺少這個「CTA 力度分流」的決策工具。

## 二、另一個 AI 的底層邏輯分析

### 2.1 推斷的 Prompt 結構

根據對話內容，另一個 AI 的 Prompt 包含以下核心指令：

```
角色：文案策略師 + 轉化顧問
任務：
  1. 重構口播稿結構（先立差異化主張，再教知識）
  2. 設計 CTA 兩個版本（養信任型 vs 篩選變現型）
  3. 分析 Hook 強度（泛場景 vs 精準瞬間）
  4. 設計 5 條片的信任遞進排期

底層邏輯：
  - 觀眾不會由「看片」直接跳到「付費」，中間需要「信任建立」
  - 主張先於知識：先讓觀眾接受「你醫錯地方」，才能接受「三層自測」
  - 每條片只做一件事：立主張 / 教一層 / 自然變現
```

### 2.2 另一個 AI 的核心改動邏輯

| 原版問題 | 另一個 AI 的診斷 | 改動方向 |
|---------|----------------|---------|
| Hook 是「自測鉤子」（唔使去照 X 光…） | 沒有先建立「你醫錯地方」的認知前提，觀眾把片當教學片 | 改為「痛極唔斷尾」Hook（physio→好返→又痛返） |
| 三層結構是平行清單 | 每層都是「看位置→不正常→肌肉瞓著→痛」，觀眾第二層就預測到第三層 | 改為「由下往上傳的力鏈」：腳歪→逼膝→逼骨盆 |
| 「肌肉瞓著咗」重複三次 | 重複三次變成公式，失去頓悟感 | 改為「根喺下面／根喺底層」，與「痛係一條鏈」主線扣緊 |
| CTA 只有一個版本 | 沒有根據帳號信任厚度調整 CTA 力度 | 設計版本 A（養信任）和版本 B（篩選變現）兩個版本 |
| Hook 用泛場景 | 「返工坐得耐腰痛」任何人都講得出，命中率低 | 改為精準瞬間：「坐足一日，夜晚起身要撐住張枱先企得起」 |

### 2.3 另一個 AI 的「教練身份」設計

另一個 AI 在結尾加入了「教練身份講句實話」的段落，提出了兩個反直覺警告：
1. 「第 2-4 條最易犯的錯是變成三條一模一樣的片」
2. 「唔好死守 5 條先變現，睇數據才是指南針」

這個設計的底層邏輯是：**在給出排期的同時，主動指出排期的風險**，讓用戶感受到「這個 AI 不是在給我一個公式，而是在幫我思考」。這是建立信任感的重要技巧。

## 三、「精準瞬間 Hook」原則（新增）

### 3.1 定義

**精準瞬間** = 一個帶有時間、動作、情緒的具體瞬間，讓觀眾感覺「你怎麼知道我是這樣的」。

**泛場景** = 任何人都可以代入的通用描述，觀眾聽完只是點頭，不會停下來。

### 3.2 強度對比

| Hook 類型 | 例子 | 觀眾反應 | 命中率 |
|---------|------|---------|-------|
| **泛場景** | 「返工坐得耐腰痛」 | 「係喎我都係咁」（點頭，繼續滑） | 低 |
| **精準瞬間** | 「坐足一日，夜晚起身要撐住張枱先企得起」 | 「吓你連我起身要撐枱都知？」（震一震，停下來） | 高 |

### 3.3 精準瞬間的三個構成要素

```
時間 + 動作 + 情緒/後果
```

| 要素 | 說明 | 例子 |
|------|------|------|
| **時間** | 具體的時間點（夜晚、朝早、落樓梯時） | 「夜晚起身嗰下」「朝早落床嗰一步」 |
| **動作** | 具體的身體動作（撐枱、扶扶手、側住身） | 「要撐住張枱先企得起」「扶住扶手一級一級落」 |
| **情緒/後果** | 這個瞬間帶來的感受或後果 | 「要側住身一級一級落」「個腰梗晒要慢慢先轉到身」 |

### 3.4 常見痛症的精準瞬間庫（30-45 歲久坐女性）

| 痛症 | 泛場景（避免） | 精準瞬間（使用） |
|------|-------------|--------------|
| **腰痛** | 「返工坐得耐腰痛」 | 「坐足一日，夜晚起身要用手撐住張枱先企得起身」 |
| **腰痛（晨間）** | 「瞓醒腰痛」 | 「瞓醒個腰梗晒，要慢慢先轉到身，先至敢落床」 |
| **膝痛** | 「行行走走膝頭痛」 | 「落樓梯膝頭『咔』一聲，要扶住扶手一級一級落」 |
| **膝痛（蹲下）** | 「蹲低會膝頭痛」 | 「蹲低執嘢，起身要扶住嘢先起到，起唔到就係跌低」 |
| **腳板痛** | 「朝早腳板痛」 | 「朝早落床嗰一步，腳跟刺到好似踩住玻璃」 |
| **頸痛** | 「望電腦頸痛」 | 「望電腦望到夜晚，個頸梗到轉唔到，要用手托住個頭先轉到」 |
| **拗柴** | 「容易拗柴」 | 「著返平底鞋行快兩步，腳踝就歪——唔係唔小心，係每次都係」 |

## 四、「痛係一條鏈」遞進力鏈結構

### 4.1 平行清單 vs 遞進力鏈

| 結構類型 | 特徵 | 觀眾反應 |
|---------|------|---------|
| **平行清單** | 每層都是「看位置→不正常→肌肉瞓著→痛」 | 第二層就能預測第三層，失去繼續看的動力 |
| **遞進力鏈** | 每層都是「上一層歪了，逼下一層硬撐」 | 每一層都製造「原來係咁」的頓悟感，越看越想看 |

### 4.2 遞進力鏈的寫法公式

```
第一層（地基）：腳踝歪 → 足弓控制力不足
    ↓「地基歪咗，上面層層都要幫佢執手尾」
第二層（傳導）：腳歪 → 逼膝蓋硬撐 → 膝痛
    ↓「你按極個膝頭都冇用，因為問題喺下面」
第三層（終點）：底層歪 → 逼骨盆代償 → 腰痛
    ↓「你冷敷熱敷做 gym 都好，個根喺底層冇郁過，痛咪返轉頭囉」
```

### 4.3 每層的「獨立頓悟」設計

每層必須有一個獨立的「原來如此」，不能是同一個公式的重複：

| 層次 | 獨立頓悟 | 關鍵句 |
|------|---------|-------|
| **第一層（腳）** | 「地基概念」——足弓是整個下半身的地基 | 「地基歪咗，上面層層都要幫佢執手尾」 |
| **第二層（膝）** | 「膝痛竟然賴腳」——膝蓋痛的根不在膝蓋 | 「你按極個膝頭都冇用，因為問題喺下面」 |
| **第三層（骨盆）** | 「腰痛竟然由最底傳上嚟」——腰痛的根在底層 | 「你冷敷熱敷做 gym 都好，個根喺底層冇郁過，痛咪返轉頭囉」 |

## 五、「physio 止痛 vs 我搵根」定位分界線

### 5.1 Cathy 的變現卡點

```
有痛症的人 → 去找 physio（不找 Cathy）
體態不好的人 → 不一定有緊迫感（不找 Cathy）
```

**解決方法：** 在 CTA 前植入「physio 止痛，我重排力鏈」的分工定義，讓觀眾自己判斷「我需要的是哪一個」。

### 5.2 分界線話術

```
「physio 可以幫你止嗰陣痛，但佢唔會幫你重排成條力鏈，
所以你痛極都斷唔到尾。
呢個正正係我做嘅嘢：一次一對一評估，
我幫你揾出源頭嗰層，即場設計你專屬嘅矯正動作，
由個根度斷尾。」
```

**這句話的三個功能：**
1. **不貶低 physio**：「physio 可以幫你止嗰陣痛」——承認 physio 的價值，不製造對立
2. **定義 Cathy 的獨特價值**：「重排力鏈」是 physio 做不到的事
3. **讓觀眾自我分流**：「我需要止痛還是斷尾？」——觀眾自己做判斷，不是被推銷

### 5.3 在每條片中植入的頻率

| 片的類型 | 植入方式 | 植入位置 |
|---------|---------|---------|
| **教學型（第 1-4 條）** | 輕植入，只說「physio 止痛，我搵根」 | CTA 前最後一句 |
| **變現型（第 5 條）** | 完整植入，解釋分工 | CTA 段落 |

## 六、CTA 力度分流策略（版本 A vs 版本 B）

### 6.1 決策框架

```
帳號信任厚度 → 選擇 CTA 版本
```

| 條件 | 選擇 | 理由 |
|------|------|------|
| 粉絲量 < 1000 / 互動率 < 5% / 留言多是「謝謝分享」 | **版本 A（養信任型）** | 信任基礎未夠，直接推付費會嚇走人 |
| 粉絲量 > 1000 / 留言有人主動問「咁我應該點做」 | **版本 B（篩選變現型）** | 信任夠厚，可以主動篩選高意向客戶 |
| 不確定 | **先用版本 A，觀察 3-5 條片的留言** | 看有多少人留言「評估」，夠的話切版本 B |

### 6.2 版本 A（養信任型）的核心機制

```
免費清單降低門檻 → 拉 engagement
↓
「三層都有問題」的人自然對號入座
↓
「清單搞唔掂」畫出界線
↓
付費評估變成觀眾自己判斷「我係嗰種需要的人」
```

**關鍵句：** 「但我要老實同你講——如果你三層都有問題，即係你條力鏈已經歪咗成條，靠清單自己執好難搞得掂，因為你唔知邊層先係源頭。」

### 6.3 版本 B（篩選變現型）的核心機制

```
「數下你有幾多層歪咗」逼觀眾即場自我診斷
↓
「一層 vs 兩層以上」自動分流
↓
對「兩層以上」明講「physio 止痛≠重排力鏈」
↓
「名額有限」加輕微稀缺感
```

**關鍵句：** 「如果你兩層或以上都歪，聽好——你唔係靠一兩個動作救得返，因為你根本分唔清邊層帶頭歪，做錯方向只會越矯越傷。」

### 6.4 版本 A vs 版本 B 對比

| | 版本 A 養信任型 | 版本 B 篩選變現型 |
|---|---|---|
| 核心動作 | 留言拎免費清單 | 自我分流 + 直接約評估 |
| 適合階段 | 粉絲／信任未夠厚 | 已有熟客、準備收單 |
| 轉化速度 | 慢，但關係穩 | 快，客更精準 |
| 風險 | 太軟，變純 engagement 冇單 | 太急，信任未夠會嚇走人 |

## 七、5 條片信任遞進排期框架

### 7.1 排期邏輯

**不是 5 條片講 5 個知識點，而是一條「認知升級鏈」。**

```
第 1 條：立主張（「你一直醫錯地方」）
    ↓ 種下「痛係一條鏈」概念
第 2 條：第一層（腳是地基）
    ↓ 觀眾驗證「係喎我腳踝真係歪咗」
第 3 條：第二層（膝痛根喺腳）
    ↓ 觀眾驗證「係喎我膝頭痛係因為腳」
第 4 條：第三層（腰痛根喺底層）
    ↓ 觀眾驗證「係喎我腰痛係因為底層」
第 5 條：整合 + 自然變現
    ↓ 「呢兩星期好多人留言問我同一個問題」
```

### 7.2 逐條任務定義

| # | 主題 | 這條片的唯一任務 | CTA 力度 |
|---|------|--------------|---------|
| **1** | 痛處≠病根（總論） | 立主張，種「痛係一條鏈」概念 | 純互動：「你邊度痛？留言」 |
| **2** | 第一層：腳（地基） | 示範腳踝自測，讓觀眾驗證「我腳踝真係歪咗」 | 軟：「試完留言你係內翻定外翻」 |
| **3** | 第二層：膝（膝痛根喺腳） | 示範膝蓋自測，讓觀眾驗證「膝頭痛係因為腳」 | 軟：「留言你膝蓋內扣定正常」 |
| **4** | 第三層：骨盆（腰痛根喺底層） | 示範骨盆自測，收「一條鏈」概念 | 開始鋪：「三層自測完，留言你歪幾多層」 |
| **5** | 整合＋自然變現 | 回應前 4 條留言，帶出免費清單＋評估 | 版本 A 完整 CTA |

### 7.3 第 1 條和第 5 條的特殊設計

**第 1 條（立主張）：**
- 唯一任務：種下「你一直醫錯地方」的認知前提
- CTA 最輕：只問「你邊度痛」，目的是收集留言，為第 5 條的「回應」做準備
- 不要急著教自測，先讓觀眾接受主張

**第 5 條（自然變現）：**
- Hook：「呢兩星期好多人留言問我同一個問題」
- 這句話的功能：把「推銷」變成「回應」，觀眾不覺得被推銷，反而覺得「佢係應我哋要求先出」
- 信任堆到這個程度，付費評估才接得住

### 7.4 排期的彈性原則

**不要死守 5 條先變現。**

- 如果第 3、4 條留言已有人主動問「咁我應該點做」「可唔可以幫我睇下」
- 代表信任夠，可以提早在第 4 條就切 CTA
- **排期是地圖，不是鐵律；觀眾的反應才是指南針**

## 九、使用指引

**觸發時機：**
- 當 Cathy 要把「多層體態自測」的知識點拆成多條片時，必須先用「遞進力鏈結構」設計每層的獨立頓悟
- 當 Cathy 設計 Hook 時，必須先用「精準瞬間 vs 泛場景」的強度對比診斷 Hook 是否夠狠
