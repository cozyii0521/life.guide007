## 一、這個框架解決什麼問題

現有 `hook_framework.md` 已建立六大 Hook 機制（身份代入、利益前置、反常識、問句、數字、場景）。但在 15.7.2025 的對話中，另一個 AI 揭示了一個更精細的 Hook 技術：**「好奇缺口雙觸發」**——在同一句話裡同時打開兩個好奇缺口，讓觀眾無法滑走。

**問題的根源：**
- 單一好奇缺口 Hook：「我放棄咗跳舞成十幾年」→ 觀眾知道是跳舞，好奇心只有一個維度（為什麼放棄）
- 雙觸發好奇缺口 Hook：「我做咗一件事，令我重拾返我不得不放棄咗好多年嘅興趣」→ 觀眾有兩個好奇缺口：①「咩興趣？」②「點解『不得不』？」

## 二、好奇缺口雙觸發的核心機制

### 2.1 定義
> **好奇缺口（Curiosity Gap）：** 在觀眾已知資訊與未知資訊之間製造的認知張力。大腦對「未完成的資訊」有強烈的填補衝動（Zeigarnik Effect）。

### 2.2 單觸發 vs 雙觸發的對比

| 維度 | 單觸發 | 雙觸發 |
|------|--------|--------|
| 好奇缺口數量 | 1 個 | 2 個 |
| 觀眾停留動機 | 「我想知道 A」 | 「我想知道 A，而且我還想知道 B」 |
| 滑走風險 | 中（只有一個理由留下） | 低（兩個理由同時拉住） |
| 例子 | 「我放棄咗跳舞成十幾年」 | 「我做咗一件事，令我重拾返我不得不放棄咗好多年嘅興趣」 |

### 2.3 雙觸發的兩個缺口類型

**缺口 A：「是什麼？」（Identity Gap）**
- 刻意不說出具體的人、事、物
- 讓觀眾的大腦自動填空
- 例：「咩興趣？」「咩嘢？」「邊個人？」

**缺口 B：「為什麼？」（Causality Gap）**
- 暗示背後有一個不尋常的原因
- 關鍵詞：「不得不」「竟然」「原來」「點解」「居然」
- 例：「點解『不得不』放棄？」「點解做咗呢件事就可以重拾？」

## 三、雙觸發 Hook 的構建公式

### 公式 A：「行動 + 結果（吊住主角）」
```
「我做咗一件事，令我重拾返我不得不放棄咗好多年嘅[模糊名詞]。」
```
- 行動：「做咗一件事」（不說是什麼）→ 缺口 A
- 結果：「重拾返」（正面結果，吸引力）
- 「不得不」：暗示有不得已的原因 → 缺口 B
- 「模糊名詞」：「興趣」而非「跳舞」→ 保持缺口 A

### 公式 B：「反常識 + 隱藏原因」
```
「[反常識結論]——唔係你以為嗰個原因，係[暗示性描述]。」
```
- 反常識結論 → 缺口 A（「點解係咁？」）
- 「唔係你以為嗰個原因」→ 缺口 B（「咁係咩原因？」）

### 公式 C：「精準瞬間 + 懸念問句」
```
「[具體痛苦瞬間]——你有冇諗過，其實係[暗示性描述]？」
```
- 精準瞬間 → 身份代入（觀眾對號入座）
- 「其實係...」→ 打破認知，製造缺口 B

## 四、Cathyii IP 應用例句庫

### 4.1 故事型 Hook（商業合作片適用）

| 場景 | 單觸發版（較弱） | 雙觸發版（較強） |
|------|----------------|----------------|
| 重拾跳舞 | 「我放棄咗跳舞成十幾年」 | 「我做咗一件事，令我重拾返我不得不放棄咗好多年嘅興趣」 |
| 腳痛改善 | 「我試過好多方法都冇用」 | 「我換過幾十對鞋、做過動作，但係有一樣嘢我一直冇做——直到我試咗，先知道點解一直好唔返。」 |
| 體態改善 | 「我改善咗我嘅體態」 | 「我做咗一個決定，令我唔再需要每日提醒自己坐直——因為我搵到咗個根本唔係姿勢問題嘅原因。」 |

### 4.2 知識型 Hook（自測/教學片適用）

| 場景 | 單觸發版（較弱） | 雙觸發版（較強） |
|------|----------------|----------------|
| 拗柴原因 | 「你知唔知你點解成日拗柴？」 | 「上班企足一日，行到唔平地面就容易扭到。唔係鞋唔好，唔係你唔小心——一個動作，話你知你點解成日拗柴。」 |
| 腰痛根源 | 「你嘅腰痛可能唔係腰嘅問題」 | 「返工坐足一日，夜晚起身要撐住張枱先企得起——腰痛你去按摩，但點解好返冇幾耐又痛返？」 |
| 膝蓋痛 | 「膝蓋痛唔係膝蓋壞咗」 | 「你按極個膝頭都冇用——因為問題根本唔喺嗰度。」 |

## 五、雙觸發 Hook 的三個禁忌

### 禁忌 1：太早揭露答案（殺死好奇心）
```
❌ 「我做咗一件事，令我重拾返跳舞——就係用咗個鞋墊。」
✅ 「我做咗一件事，令我重拾返我不得不放棄咗好多年嘅興趣。」
```
**原因：** 一旦答案說出，好奇缺口立刻關閉，觀眾沒有理由繼續看。

### 禁忌 2：缺口太模糊（觀眾無法代入）
```
❌ 「我做咗一件事，改變咗我嘅生活。」（太泛，觀眾無法代入）
✅ 「我做咗一件事，令我重拾返我不得不放棄咗好多年嘅興趣。」（「不得不放棄」有具體情感重量）
```
**原因：** 好奇缺口必須有情感重量，才能讓觀眾感受到「我想知道」的衝動。

### 禁忌 3：雙觸發變成雙重混亂（超過兩個缺口）
```
❌ 「我做咗一件事，令我重拾返我不得不放棄咗好多年嘅興趣，而且係用咗一個好多人都唔知嘅方法。」
（三個缺口：咩興趣？點解不得不？咩方法？→ 太多，觀眾認知超載）
✅ 最多兩個好奇缺口，讓觀眾的大腦可以同時追蹤
```

## 七、快速診斷清單

使用以下問題診斷你的 Hook 是否達到雙觸發效果：

- [ ] **缺口 A 存在嗎？** 有沒有一個「是什麼？」的問題被打開但未回答？
- [ ] **缺口 B 存在嗎？** 有沒有一個「為什麼？」的問題被暗示但未解釋？
- [ ] **答案被保留了嗎？** Hook 有沒有提前說出任何答案？
- [ ] **情感重量夠嗎？** 缺口有沒有讓觀眾感受到「我想知道」的衝動？
- [ ] **缺口數量控制在 2 個以內嗎？** 有沒有超過兩個未解答的問題？

全部 ✅ = 雙觸發 Hook，留人力度最強
有 ❌ = 需要修改對應部分
