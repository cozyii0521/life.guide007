## 一、系列片 Hook 陌生人原則（最高優先級）

### 1.1 核心法則

> **「系列片的 Hook，永遠要當看的人是新觀眾。前情、呼應上集這些東西，放在正文中段用『我之前有條片講過』帶過就夠，不要放在頭三秒做門檻。Hook 的職責是攔截陌生人，不是招呼熟客。」**

### 1.2 為什麼這個原則如此重要

IG 的流量分發邏輯是「演算法把每條片推給陌生人」——即使是你的粉絲，也未必看過上一集。**九成滑到你這條片的人，是第一次見到你或者沒看過上集的人。**

用「上次講完……」「上集我哋講到……」開場，等於頭三秒對大部分人說一句他們聽不明的話，他們會滑走。

### 1.3 「靠前情 Hook」vs「自己企得住 Hook」對比

| 類型 | 例子 | 問題 |
|------|------|------|
| ❌ **靠前情 Hook** | 「上次講完腳痛源頭係足弓塌，最多人問我：咁我點知自己塌咗未？」 | 假設觀眾看過上集，新觀眾頭三秒聽不明，滑走 |
| ✅ **自己企得住 Hook** | 「成日行耐啲隻腳板就痛？望一望你對鞋——如果鞋踭一邊磨得特別犀利，唔係對鞋衰咗，係你隻腳喺度求救。」 | 新觀眾即刻對號，不需要任何前置知識 |

### 1.4 如何在正文中「照顧舊粉 + 引新粉去看上集」

Hook 改成不靠前情後，正文中段可以用一句話同時服務兩類觀眾：

**公式：**
> 「[揭根源段尾]……點重建返個足弓，**我有另一條片詳細講咗兩個動作，可以睇返**；今日先教你點睇對鞋，驗證源頭真係喺度。」

**效果：**
- 看過 EP1 的人：「哦呼應返」，增加系列黏性
- 新觀眾：「哦原來仲有條片講動作，去睇」，順手谷 EP1 播放
- 兩邊都照顧到，不因為一句「上次」流失新人

### 1.5 系列片 Hook 自我檢查清單

每次寫系列片 Hook 前，必須問：
- [ ] 這個 Hook 假設觀眾看過上集嗎？如果是，必須改
- [ ] 一個完全不認識 Cathy 的人，頭三秒能不能即刻對號入座？
- [ ] Hook 有沒有「即場行動指令」（如「望下你對鞋」「企起身試下」）？
- [ ] 如果要引上集，是放在正文中段而不是 Hook 嗎？

## 二、片身份定性框架（Content Identity Diagnosis）

### 2.1 「身份模糊」問題的定義

**身份模糊**：一條片的 Hook 主題、內容核心、動作解法，分屬不同的痛症或問題，讓觀眾和演算法都不知道這條片「是關於什麼的」。

**典型症狀：**
- Hook 用 A 問題的痛感入場（足底筋膜炎的刺痛）
- 原理解釋用 B 問題的機制（足弓塌陷 = 扁平足）
- 動作解法治的是 B（練足弓），不是直接治 A（筋膜發炎）

### 2.2 身份模糊的診斷三步驟

```
Step 1：找出片的「因果鏈」
→ 觀眾看到的「果」（痛症/症狀）是什麼？
→ 片解釋的「因」（根源）是什麼？
→ 片教的「解法」治的是因還是果？

Step 2：判斷「身份踩界」的程度
→ 輕微踩界：因果鏈清晰，但 Hook 主題和解法主題不完全一致 → 可接受，但要在片中明確交代因果連接
→ 嚴重踩界：Hook 承諾解決 A，但片教的是 B，且沒有清晰連接 → 必須定性選邊

Step 3：定性選邊（兩條路）
→ 路 A：以「果」（痛症）定性 → 適合 Hook 痛感強、拉新力強的情況
→ 路 B：以「因」（根源）定性 → 適合想建立「根源專家」定位的情況
```

### 2.3 足底筋膜炎 EP1 的定性案例

**因果鏈分析：**
```
Hook：足底筋膜炎的刺痛（果）
原理：足弓塌陷（因）
動作：重建足弓（治因，不是直接治果）
```

**定性決策：**

| 定性方向 | 優點 | 缺點 |
|---------|------|------|
| **路 A：足底筋膜炎 EP1**（以果定性）| Hook 痛感強、拉新力強；觀眾為「痛」入來，動機足 | 動作治的是因（足弓），需要在片中清晰交代「治因才能治果」的邏輯 |
| **路 B：扁平足 EP1**（以因定性）| 建立根源專家定位 | Hook（踩釘咁痛）和主題（扁平足）有落差；扁平足拉新力弱 |

**建議：路 A（足底筋膜炎 EP1）**——以痛感定性，拉新力強；同時在片中清晰交代「足弓塌→筋膜硬食→發炎」的因果鏈，讓觀眾明白「治足弓 = 治腳痛的根本」。

**「因果交叉點」的戰略價值：**
> 一條片同時埋下「足弓塌」的伏，天然接得到扁平足線——這條片是整個宇宙的「因果交叉點」，一條片連住兩個主題，是好事，不是問題。

### 2.4 「因果交叉點」的應用原則

當一條片的因果鏈跨越兩個主題時，不要強行選一個、捨棄另一個。正確做法是：

1. **以「果」（痛症）定性**，因為觀眾是為「果」入來的
2. **在片中清晰交代因果鏈**，讓觀眾明白「果的根源是因」
3. **在 Tags 和 Caption 同時涵蓋兩個主題**，讓兩邊的搜尋都食得到
4. **把「因」的主題留給下一條片**，形成天然的系列銜接

## 三、過度承諾（Over-promise）診斷框架

### 3.1 什麼是過度承諾

**過度承諾**：Hook 或片名承諾了一個觀眾做完之後無法實現的效果，導致觀眾「試完冇好」後產生「呃 like」感，損害信任度和專業形象。

**Cathyii 最常見的過度承諾模式：**
- 時間承諾：「10 秒搞得掂」「3 分鐘解決」——但實際效果需要兩週
- 效果承諾：「叫緊救命」「完全根治」——誇大嚴重性或效果
- 完整性承諾：「完整訓練計劃」——但 DM 內容只是片的重複

### 3.2 過度承諾的三個診斷問題

```
問題一：片尾有沒有說「需要幾週才見效」？
→ 如果有，但 Hook 說「10 秒搞掂」→ 頭尾打架，必須修正

問題二：這個承諾，觀眾做完之後能不能實現？
→ 如果不能，這就是過度承諾

問題三：這個用詞，符不符合護理師的專業形象？
→ 「叫緊救命」「完全根治」→ 不符合，會損害可信度
```

### 3.3 過度承諾的修正原則

**原則：把「效果承諾」改成「方向承諾」**

| 類型 | ❌ 過度承諾版 | ✅ 方向承諾版 |
|------|------------|------------|
| 時間承諾 | 「10 秒鐘搞得掂」 | 「唔使買鞋墊，兩個動作教你根治源頭」 |
| 效果承諾 | 「叫緊救命」 | 「喺度求救」（收斂但有力）|
| 完整性承諾 | 「完整訓練計劃」 | 「阻力對照＋選購指南」（具體說明 DM 給什麼）|

**核心邏輯：**
- 承諾「方向」（你會知道根源、你會知道怎麼做）而不是承諾「結果」（你會好）
- 具體說明 DM 給什麼，而不是用「完整計劃」這種空泛詞

### 3.4 「求救」vs「救命」的力度校準

這是一個細節但重要的區分：

| 用詞 | 力度 | 問題 |
|------|------|------|
| 「叫緊救命」 | 過火 | 磨損不是救命級警號，over-claim，與護理師專業形象衝突 |
| 「喺度求救」 | 夠力但不過火 | ✅ 有迫力，但不誇張，符合護理師可信度 |
| 「已經塌緊都唔知」 | 中性穩健 | ✅ 穩陣，適合想守住專業可信的情況 |

**建議：Cathyii 的人設是「專業且有態度」，「求救」比「救命」更符合這個定位。**

## 四、Hook 兩個版本的評估框架（Hook A vs Hook B 比較法）

### 4.1 當用戶提供兩個 Hook 版本時的評估步驟

這個 AI 在對話中展示了一個清晰的「Hook 比較評估」框架：

```
Step 1：找出每個版本的「贏的地方」
→ Hook A 贏在哪裡？（結構、邏輯、反差）
→ Hook B 贏在哪裡？（語感、長度、口語感）

Step 2：找出每個版本的「輸的地方」
→ Hook A 的問題是什麼？（太長、弱化詞太多）
→ Hook B 的問題是什麼？（過度承諾、用詞失準）

Step 3：合併兩個版本的優點，去掉各自的缺點
→ 用 A 的結構（有反差有邏輯）
→ 用 B 的語感（短、急、口語）
→ 去掉 A 的弱化詞（未必、可能）
→ 去掉 B 的過度承諾（叫緊救命）

Step 4：輸出一個「合併優化版」
```

### 4.2 弱化詞的識別與處理

**弱化詞**：在 Hook 中使用「未必」「可能」「或者」等不確定詞，會削弱 Hook 的衝擊力和確定感。

| ❌ 有弱化詞 | ✅ 去掉弱化詞 |
|-----------|------------|
| 「你**未必**係行得多——**可能**係足弓塌咗」 | 「唔係行得多——係你隻腳塌緊喺度求救」 |
| 「**可能**已經塌緊都唔知」 | 「已經塌緊都唔知」 |

**原則：Hook 要有確定感，不要用弱化詞保護自己。如果需要免責，放在 Caption 的 ⚠️ 聲明，不要放在 Hook。**

## 五、「診斷 → 方案」分工原則（片 vs DM）

### 5.1 核心法則

> **「片 = 診斷（教你看見問題），DM = 方案（教你解決問題）。誘餌不能是片內容的懶人包。」**

### 5.2 EP1 vs EP2 的誘餌分工案例

| 集數 | 片的職責 | DM 誘餌 | 分工邏輯 |
|------|---------|---------|---------|
| **EP1（足底筋膜炎）** | 教「足弓塌→腳痛」的原因 + 兩個重建動作 | 自測足弓方法（FOOT）| 片教「因果」，DM 教「自我診斷」 |
| **EP2（鞋磨損）** | 教「鞋踭磨損 = 足弓塌的外部證據」+ 三種磨損類型 | 鞋磨損對應自救指引（驗鞋）| 片教「診斷」，DM 教「診斷完怎麼做」 |

**兩個誘餌不撞的關鍵：**
- EP1 誘餌：「自測足弓方法」= 身體自測（濕腳印法等）
- EP2 誘餌：「鞋磨損對應自救指引」= 測完之後按磨損類型的對應做法

片 → DM 的邏輯是「片給你問題，DM 給你答案」，而不是「片給你問題，DM 重複問題」。

### 5.3 「診斷 → 方案」分工的自我檢查

每次設計 CTA 誘餌時，必須問：
- [ ] 片已經給了什麼？（診斷/動作/原理）
- [ ] DM 給的是片沒有給的東西嗎？
- [ ] 觀眾看完片，還有什麼「片講唔晒、但即刻想知」的問題？
- [ ] DM 誘餌是否精準擊中這個「未解問題」？
