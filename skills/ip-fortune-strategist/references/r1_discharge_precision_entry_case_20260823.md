## 二、老師覆盤的正確解讀

老師的結論不是「方向錯」或「文案不順」。原話的核心是：**方向對、文案順，只是流量入口小；對 Trial 而言，二千多 views 已不差。**

原因是這條片的觀眾需要同時符合多個條件：

1. 是正在處理父母照顧的成年子女；
2. 家中長者健康已出現需要安排的狀況；
3. 長者剛住過院；
4. 正處於「即將／剛剛出院」的短時間窗；
5. 家屬仍未釐清返家第一晚的優先次序。

條件疊加越多，當下會自認「這條正講我」的人越少。這是**精準入口的天然播放天花板**，不是帳號被限流、舊內容拖累新內容，或 hashtag 一定失效的證據。

### 精準題的複盤順序

> 先問「這個題材本身要幾多個條件同時成立」；再看首屏是否令那一小群人立即停下；最後才看觀看、收藏、轉發和 DM 是否符合高意圖角色。

精準入口也不能因為窄就放棄 Hook。R1 的 Hook 有父母關係、今日出院、今晚返屋企的時間壓力及具體任務，屬於可用的精準場景 Hook；因此 R1 的低於泛流量的播放，優先解釋為入口篩選，而非先判成 Hook 完全失敗。

## 四、對內容組合的規則

**規則一：** 出院題要保留，但不能連續做成帳號主流量母題。

**規則二：** 新定位首 6–12 條內容要同時有：

| 題材角色 | 建議內容範圍 | 功能 |
|---|---|---|
| 泛入口 | 父母日常功能、覆診準備、照顧節奏開始改變。 | 先打開「有父母、開始覺得不對路」的較大人群。 |
| 協作／整合 | 覆診資料如何交接、家庭誰負責、已有資源卻未排到先後。 | 證明 Cathyii 的健康教育 × 家庭決策整合價值。 |
| 精準入口 | 出院、改藥、急性轉銜。 | 接住高意圖家庭；不以播放量單獨判成敗。 |

**規則三：** 泛入口不是刪光條件、講「長者健康」就夠。它仍要在首 0–8 秒放入：`阿爸／阿媽／父母`＋`當下生活畫面或正在處理的任務`＋`原有完成感／正常化理解不夠`。R1 的窄入口教的是「減少條件疊加」；R2 Trial 教的是「減少條件不等於接受抽象描述」。

## 五、對標方向

對標可從「銀髮、長者健康、成年子女照顧」的內容與服務找，不必只找香港一模一樣的院舍／出院服務。研究時要抽取：

1. **角色：** 內容是否寫給子女，而不是直接教育長者；
2. **入口：** 如何從日常功能、健康變化或覆診任務打開較大人群；
3. **漏斗：** 如何由健康教育接到家庭整合、服務路由或進一步支持；
4. **邊界：** 如何不把健康教育寫成個案診斷、處方或代辦服務。

不要照搬外地長照制度、服務名稱、補貼或收費。

## 六、舊帳號轉型規則

舊體態內容不需要隱藏；舊 WhatsApp 群亦不需要因為怕不適合新題材而停止分享。讓不再相關的人自行退出，專注保留同時有護老需求的人。平台亦會按新內容探索合適新受眾；不要把一條精準題的播放結果歸咎於舊內容。

## 七、每次使用出院精準題前的 4 問

1. 這條是在接住哪一個「已在轉銜內」的家庭，而非假裝要吸引所有子女？
2. 0–3 秒是否有 `父母關係詞＋出院／改藥等可見事件`？
3. 片內有沒有一個安全微交付，讓家屬今天少靠一次估？
4. 發片後是否用高意圖訊號（保存、轉發、留言／DM 內容）判讀，而非只以 views 判死刑？
