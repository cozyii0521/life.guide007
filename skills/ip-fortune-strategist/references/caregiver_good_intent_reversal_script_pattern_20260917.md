# 家庭護老 Reel「善意照顧反轉鏈」

**建立日期：** 2026-09-17  
**來源：** Cathy 與 IP 老師對 R7 老火湯高張力稿的共同取向，以及對標 Reel `DdK8W2AzVnP` 的結構拆解。  
**適用：** 子女出於好意替父母做一件日常健康／照顧行動，但當中有一個需要先核對的限制或風險。

## 一、只複製結構，不複製恐嚇

對標片的可複用 DNA 不是死亡恐嚇、專業縮寫清單或替代方案承諾，而是：

> **一個善意動作 → 一個完成感反轉 → 一條隱藏因果 → 一個專業核對動作。**

家庭護老觀眾的強動機往往不是「把父母變得更健康」，而是「不要因為自己不懂而好心做錯」。這個身份衝突比純知識迷思更容易形成停留與分享。

## 二、七拍文案結構

| 拍點 | 任務 | 寫法 |
|---:|---|---|
| 1 | **善意行動 Hook** | `你以為［具體照顧行動］畀阿爸阿媽，係幫緊佢？` |
| 2 | **完成感反轉** | `真正要留意嘅，可能就係［關鍵動作／遺漏］呢一下。` |
| 3 | **舊理解** | `好多人以為［常見理解］。` |
| 4 | **隱藏機制／後果** | 只解釋一條主因果；說到足以理解下一步便停。 |
| 5 | **關係修復** | `唔好返去怪阿爸阿媽；佢肯照做，係因為信你。` |
| 6 | **單一核對行動** | `帶［實物／紀錄］，問［專業人士］一句［具體問題］。` |
| 7 | **價值觀收束** | `照顧唔係［表面投入］，係［更安全的照顧原則］。` |

## 三、為何這個結構比純知識片強

| 純知識片 | 善意反轉鏈 |
|---|---|
| 由「這個迷思是真是假」入場 | 由「我是否正在好心做錯」入場 |
| 觀眾身份較弱 | 一開始就是父母與子女的關係 |
| 中段容易變成平行資訊 | 全片圍繞同一照顧動作推進 |
| 行動常是「下次問醫生」 | 帶甚麼、問誰、問哪一句都具體 |
| 結尾多數只叫收藏／分享 | 可用一句價值觀完成情緒記憶 |

## 四、一條線檢查：風險遞進不等於堆病名

可以使用「第一層／仲有一層／最容易漏」的節奏，但所有層次必須服務同一主命題。

> **若刪掉某一段後，該段仍可獨立成另一條完整 Reel，便應拆片。**

例如「湯料營養」「痛風／尿酸」「腎病飲食」「草本與抗凝血藥」要求不同健康條件，不可只因語氣順便當成同一條普遍因果。高張力不能靠把多個病名堆在所有父母身上。

## 五、情緒回扣：由責怪轉成責任

「父母肯食／肯做，是因為信任子女」能增加情緒重量，但不得用來羞辱觀眾。

| 目的 | 合格 | 不合格 |
|---|---|---|
| 保護父母尊嚴 | `唔好返去怪佢，佢肯食係因為信你。` | `佢出事係因為你逼佢食。` |
| 讓子女有行動 | `所以先帶齊資料問清楚。` | `碗湯係你遞嘅，你要負責。` |
| 保留力度 | 指出善意仍需核對 | 用內疚替代證據 |

## 六、專業核對動作規格

行動必須包含三項：

1. **物件：** 包裝、成分表、材料清單、處方資料、生活紀錄；
2. **對象：** 藥劑師、醫生、營養師、物理治療師或原有醫護；
3. **一句問題：** 觀眾可以原句照問的具體問題。

避免：

- 只說「問專業人士」；
- 承諾「五分鐘搞掂」；
- 列出固定禁配清單叫家屬自行判讀；
- 提供停藥、改藥、磨藥、改劑型、固定相隔時間或個人化飲食／運動處方。

## 七、醫療事實防火牆

套用此結構前逐句檢查：

1. 這個後果是否有可靠資料支持？
2. 它適用所有父母，還是只適用某疾病、藥物、食材或劑量？
3. 若只適用部分人，Hook 是否已同步收窄？
4. 「真正出問題就由這一下開始」是否把相關性誇成單一因果？
5. 是否用了「一定、即刻、害死、出事」等超出證據的字眼？
6. 行動是整理與核對，還是已越界成個人化醫療決定？

> **IP 老師認可內容力度，不等於完成臨床 fact-check。先保留骨架，再把高張力放在證據真正覆蓋的位置。**

## 八、首屏視覺

善意動作必須可見，但不要落入產品廣告感：

- 可用：遞湯、打開藥盒、翻成分表、列材料、拍低包裝；
- 避免：手持一排品牌產品正面對鏡頭介紹；
- 首幀要讓觀眾看見「正在做一件照顧任務」，不是「正在推介一件產品」。

## 九、可套用模板

> **你以為［具體善意行動］畀阿爸阿媽，係幫緊佢？真正要留意嘅，可能就係［關鍵動作／遺漏］呢一下。**
>
> 點解咁講？好多人以為［常見理解］。但其實［一條清楚、有限定、可證明的機制］。
>
> 最容易漏嘅係［同一因果線上的第二層］。
>
> 不過唔好返去怪阿爸阿媽。佢肯照做，係因為佢信你。
>
> 下次先做一件事：帶住［實物／紀錄］，問［專業人士］一句：「［具體問題］？」
>
> **照顧唔係［表面投入］，係［更安全、更清楚的照顧原則］。**
