## 一、9/7/2026 Zoom 核心指引

### 1.1 對標帳號分析（@bakykykk 類型）
老師指出對標帳號多數定位為「老年人唔處理就會好痛」——這是一個**後果導向**的定位，而非症狀導向。

**底層邏輯：** 後果導向的定位比症狀導向更能製造緊迫感。「你有拇趾外翻」是症狀陳述，觀眾可以忽略；「拇趾外翻唔處理，10 年後你會行唔到」是後果陳述，觀眾無法忽略。

---

### 1.2 職業定向 TA（最重要新指引）

**老師建議：試下 target 特定職業——例如老師。**

**底層邏輯：** 現有 IG 內容的問題是「講特定問題 only」——只講症狀，沒有鎖定人群。結果是：
- 有這個症狀的人會看
- 但沒有這個症狀的人（即使她是你的 TA）不會停

職業定向的威力在於：**同一個症狀，加上職業身份，命中率從「有這個症狀的人」擴大到「這個職業的所有人」。**

**對比：**
| 定向方式 | Hook 例子 | 命中人群 |
|---------|---------|---------|
| 症狀定向 | 「拇趾外翻腳痛？」| 只有已知自己有拇趾外翻的人 |
| 職業定向 | 「老師成日要企，腳板痛係必然？」| 所有老師（不管她知不知道自己有拇趾外翻） |
| 職業 + 後果 | 「老師每日企 6 小時，唔處理腳板痛，5 年後你嘅拇趾外翻會嚴重到影響你落樓梯」| 所有老師 + 製造緊迫感 |

**可應用的職業定向方向（Cathy 的 TA 範疇）：**
- 老師（長期站立）
- 護士 / 醫護（長期站立 + 走動）
- 辦公室文員（久坐）
- 零售 / 服務業（長期站立）
- 媽媽 / 主婦（長期站立 + 抱小孩）

### 1.3 「有立場的內容」框架（三層遞進結構）

老師建議：**唔好只係講出痛症，點解決——要講有立場的野。**

**三層遞進結構：**

```
第一層：令 TA 意識到自身有問題（可能之前但未足夠痛）
    ↓
第二層：解釋原理（點解會有呢個問題）
    ↓
第三層：潛在惡化層——如果再唔處理 XXX，就會令 YYY 點樣惡化
    ↓
第四層：教動作（解決方法）
```

**關鍵：第三層「潛在惡化層」是現有內容最缺失的一層。**

現有內容結構（Cathy 常用）：
```
症狀陳述 → 原理解釋 → 動作
```

老師建議的結構：
```
症狀陳述 → 原理解釋 → 潛在惡化（如果唔處理會點）→ 動作
```

**「潛在惡化層」的寫法公式：**
> 「如果 [症狀] 唔處理，[時間框架] 後，[後果 A] 同 [後果 B] 就會出現——到時唔係腳板痛咁簡單，係 [更嚴重的後果]。」

**例子（拇趾外翻）：**
> 「如果拇趾外翻唔處理，足弓會繼續塌，膝頭同腰部就要代償——到時唔係腳板痛咁簡單，係成個下半身都會出問題。」

**例子（腰痛）：**
> 「如果彎腰腰痛唔處理，椎間盤長期受壓，5 年後可能係椎間盤突出——到時唔係做幾個動作就得，係要睇醫生。」

## 二、6/7/2026 Zoom 核心指引

### 2.1 「圈唔到人群」診斷（Dac5WkzTHfZ 那條片）

老師對 6/7 那條片的診斷：**「未圈到人群，呢條片想圈所有人，所以咩人都圈唔到。」**

**底層邏輯：** Hook 越廣，命中率越低。「訓醒落床嗰下太廣泛」——所有人都會訓醒落床，所以沒有人覺得「係講緊我」。

**「圈唔到人群」的三個診斷標準：**
1. Hook 裡沒有「身份詞」（職業、年齡、習慣）
2. Hook 裡沒有「具體場景」（只有症狀，沒有觸發情境）
3. Hook 裡沒有「排他性」（任何人都可以代入，等於沒有人代入）

**修正公式：**
```
廣泛 Hook：「訓醒落床腳跟痛？」
↓
加身份詞：「成日要企嘅你，訓醒落床腳跟刺痛？」
↓
加具體場景：「朝早落床嗰一步，腳跟刺到好似踩住玻璃——你係咪每朝都係咁？」
```

---

### 2.2 視覺 Hook 先行原則（DaSo7YCp-1G 那條片）

老師建議 Hook 改為：**「如果你既鞋踭係咁樣，咁你就要小心啦！」（配合鞋踭磨蝕圖）**

**底層邏輯：** 這是「視覺 Hook 先行」的應用——**先用畫面製造好奇心，再用口播解釋**。

觀眾在 0-0.5 秒是用眼睛掃描，不是用耳朵聽。如果畫面沒有吸引力，口播再好都沒用。

**「視覺 Hook 先行」的應用場景：**
- 有可見症狀的選題（鞋踭磨蝕、拇趾外翻、O 型腿）→ 先用特寫圖，再口播
- 有可做動作的選題（腳趾抓筆、腳跟提起）→ 先做動作，再解釋
- 有對比效果的選題（做前 vs 做後）→ 先放對比圖，再口播

**老師建議的 Hook 結構（視覺版）：**
```
畫面：[可見症狀特寫 / 可做動作 / 對比圖]
字幕：[一句引發好奇的話]
口播：[解釋「點解你要小心」]
```

## 三、Cathy 常犯的三個問題（從老師指引提取）

### 問題一：症狀定向，忽略職業定向
**表現：** 每條片都從「你有 XXX 症狀嗎？」開始，沒有鎖定特定職業或生活方式。
**後果：** 只有已知自己有這個症狀的人才會停，錯過大量潛在 TA。
**修正：** 在 Hook 加入職業身份詞（老師、護士、辦公室一族），把症狀定向升級為職業定向。

### 問題二：缺少「潛在惡化層」，內容停在「解決現有問題」
**表現：** 腳本結構是「症狀 → 原理 → 動作」，沒有「如果唔處理會點」這一層。
**後果：** 觀眾看完覺得「知道了，但唔係好急」，不會立刻行動（留言、DM、follow）。
**修正：** 在原理段之後、動作段之前，加入「潛在惡化層」——「如果再唔處理，XXX 個月後會出現 YYY」。

### 問題三：Hook 太廣，想圈所有人，結果圈唔到任何人
**表現：** Hook 用的是「你有冇 XXX？」的廣泛問句，沒有身份詞、沒有具體場景、沒有排他性。
**後果：** 演算法不知道把這條片推給誰，停留率低，觸及率低。
**修正：** Hook 必須有「身份詞 + 具體場景 + 排他性」三個元素中至少兩個。

## 五、使用指引

**當生成新 Reels 腳本時，必須先問以下四個問題：**

1. **這條片的 TA 是哪個職業？** 如果答案是「所有人」，必須縮窄到至少一個職業。
2. **Hook 有沒有「身份詞 + 具體場景」？** 如果沒有，必須加入。
3. **腳本有沒有「潛在惡化層」？** 如果沒有，必須在原理段後加入。
4. **這條片的視覺 Hook 是什麼？** 如果開場是人臉口播，必須改為症狀特寫或動作示範。

**快速診斷：「這條片想圈所有人嗎？」**
- 如果 Hook 裡沒有任何「排他性」（任何人都可以代入），這條片就是在「想圈所有人」，必須修正。
- 排他性的來源：職業身份、年齡段、具體習慣（久坐、長期站立）、具體場景（朝早落床、行樓梯）。
