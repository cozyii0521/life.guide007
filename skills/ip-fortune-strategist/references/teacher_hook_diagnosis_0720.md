## 一、老師診斷的底層邏輯

### 1.1 三條片的共同問題：「面熟感」殺死略過率

老師對三條片（20/7、15/7、9/7）的診斷指向同一個根本問題：

> **「平時 xxx，試過做 D 咩都唔 WORK……其實係 YYY 出問題！」**
> 這個 pattern 一來唔吸到人留低，略過率高，而且有機會太相似的 Hook 會令人有種好似已經睇過的錯覺，佢哋會滑走。

**底層邏輯：「面熟感 = 略過」**

觀眾的大腦有一個「守門員」機制——在 0-2 秒內快速判斷「這條片我見過類似的嗎？」如果答案是「見過」，大腦就判定「不需要看」，手指自動滑走。這個判斷不是有意識的，是自動的。

「狀況描述型 Hook」之所以失效，是因為腳痛/體態類帳號幾乎全部都在用這個 pattern——觀眾的大腦已經建立了「這類開頭 = 我知道結局」的條件反射。你的內容再好，他已經滑走了。

**面熟感的三個來源：**

| 來源 | 例子 | 觀眾腦袋的判斷 |
|------|------|-------------|
| 句式面熟 | 「你係咪成日 xxx？」 | 「又係呢個開頭，見過一百次」 |
| 結構面熟 | 症狀 → 試過方法 → 都唔得 → 有解法 | 「知道了，又係賣嘢」 |
| 觀點面熟 | 「換鞋冇用」「按摩只係暫時」 | 「呢個觀點我已經聽過了」 |

---

### 1.2 老師建議的解法：反常識 Hook 的底層邏輯

老師建議：**「指出 TA 日常生活某習慣原來係錯的，例如坐得耐起身腰痛千其唔好咁按條腰！建議必須要反常識。」**

**反常識 Hook 為什麼有效？**

反常識 Hook 打斷的是觀眾的「自動判斷」。當你說「你一直做緊的嘢係錯」，觀眾的大腦產生「認知失調」——他不能忽略這個訊息，因為如果他忽略了，他可能繼續做錯誤的事。這種「不安感」逼使他停下來。

**關鍵：反常識必須是「你真係咁諗」**

反常識不是為了反而反。它必須：
1. 來自你真實的專業洞察（不是砌出來的）
2. 指向觀眾真實在做的習慣（不是假設的）
3. 有具體的後果（不是模糊的「對你不好」）

## 二、「狀況描述型 Hook」的系統性禁忌

### 2.1 什麼是狀況描述型 Hook（必須識別並避免）

**定義：** Hook 的主要內容是描述觀眾的症狀或處境，沒有新的洞察或反轉。

**識別公式：**
```
[你係咪有 XXX 症狀？] + [試過 YYY 都唔得？] + [其實係 ZZZ 出問題]
```

**三條片的實際例子：**

| 片 | Hook 內容 | 問題所在 |
|----|---------|---------|
| 20/7 | 「你係咪換極鞋，對腳都係痛？行耐啲就腳板脹...」 | 純症狀描述，觀眾已見過一百次 |
| 15/7 | 類似的症狀描述開場 | 與 20/7 同一問題，觀眾產生「面熟感」 |
| 9/7 | 類似的症狀描述開場 | 三條連續用同一 pattern，演算法信任分下降 |

**老師的判斷：** 連續使用同一 pattern，不只是單條片的問題——它會讓觀眾對你整個帳號產生「我知道她要說什麼」的預判，導致帳號整體略過率上升。

---

### 2.2 狀況描述型 Hook 的五個變體（全部禁用）

| 變體 | 例子 | 問題 |
|------|------|------|
| **症狀問句** | 「你係咪成日腰痛？」 | 任何人都可以代入，沒有排他性 |
| **試過方法都唔得** | 「試過按摩、換鞋都冇用？」 | 觀眾已聽過一百次，面熟感極高 |
| **描述日常不適** | 「行耐啲就腳板脹，坐低又唔想起身」 | 概括句，沒有畫面衝擊，觀眾被動接收 |
| **問題歸因** | 「其實係你個足弓出問題」 | 在 Hook 就揭答案，好奇心消失 |
| **自我介紹式** | 「我係教體態嘅，我有拇趾外翻...」 | 開頭講自己，不是講觀眾 |

## 三、反常識 Hook 的操作系統

### 3.1 反常識 Hook 的四個類型

**類型 A：勸阻型（最強）**

> 公式：`[觀眾正在做的習慣] + [停/慳/唔好] + [反直覺後果]`

老師例子：「坐得耐起身腰痛千其唔好咁按條腰！」

拆解：
- `坐得耐起身腰痛` = 觀眾正在做的習慣（具體場景）
- `千其唔好咁按` = 勸阻（反直覺）
- 隱含後果：「按了反而更差」（觀眾想知為什麼）

**Cathyii 應用例句庫：**

| 選題 | 勸阻型 Hook |
|------|-----------|
| 腰痛 | 「坐耐咗起身腰痛，千其唔好即刻按條腰——你按嘅位置根本唔係問題所在。」 |
| 足弓 | 「腳痛想換對好鞋？慳返啲錢啦——你換幾多對都冇用，因為問題唔係喺對鞋，係喺對鞋入面。」 |
| 拇趾外翻 | 「拇趾外翻想戴矯正器？停手——你戴得越耐，隻腳趾越嚟越廢。」 |
| 頸痛 | 「頸痛想拉頸？停一停——你拉嘅位置，係你頸痛嘅結果，唔係根源。」 |
| 膝蓋痛 | 「膝蓋痛想按摩膝蓋？慳返啲錢——膝蓋根本唔係問題，係你嘅腳踝。」 |

---

**類型 B：習慣指錯型**

> 公式：`[觀眾以為正確的習慣] + [原來係錯的] + [真正的問題係...]`

**Cathyii 應用例句庫：**

| 選題 | 習慣指錯型 Hook |
|------|--------------|
| 坐姿 | 「你以為坐直係保護腰——其實你嘅『坐直』正在傷害你嘅椎間盤。」 |
| 拉筋 | 「每朝拉斜方肌想放鬆？你拉得越用力，佢就夾得越緊——因為你拉錯咗。」 |
| 走路 | 「你以為大步行路係好事——其實你每一步都在加速你嘅足弓塌陷。」 |
| 企姿 | 「你以為夾實屁股企直係正確姿勢——其實呢個動作正在鎖死你嘅骨盆。」 |

---

**類型 C：根源歸位型（最貼 Cathyii IP 核心洞察）**

> 公式：`[你一直治療的地方] + [冇罪/唔係問題] + [真正的根源係...]`

這個類型直接體現 Cathyii 的核心 IP 洞察：「痛係一條鏈，你一直治療的地方不是根源。」

**Cathyii 應用例句庫：**

| 選題 | 根源歸位型 Hook |
|------|--------------|
| 腰痛 | 「腰痛唔係腰嘅問題——係你嘅骨盆一直都係歪嘅。」 |
| 膝蓋痛 | 「膝蓋痛唔關膝蓋事——係你嘅腳踝塌咗，膝蓋幫你頂住。」 |
| 頸痛 | 「頸痛唔係頸嘅問題——係你嘅胸椎鎖死咗，頸幫你代償。」 |
| 腳痛 | 「腳痛唔係鞋嘅問題——係你嘅足弓塌咗，鞋根本撐唔到你。」 |
| 肩膀痛 | 「肩膀痛唔係肩膀嘅問題——係你嘅呼吸方式一直都係錯嘅。」 |

---

**類型 D：數字衝擊型**

> 公式：`[反常識數字/比例] + [觀眾以為的] + [真相]`

**Cathyii 應用例句庫：**

| 選題 | 數字衝擊型 Hook |
|------|--------------|
| 痛症根源 | 「我見過超過 500 個腰痛個案——97% 嘅根源唔係腰。你嘅呢？」 |
| 按摩效果 | 「按摩舒服 3 日，痛返——你知唔知你每次按摩其實只係在延遲問題？」 |

---

### 3.2 反常識 Hook 的三個必要條件（缺一不可）

| 條件 | 說明 | 失敗例子 |
|------|------|---------|
| **真實洞察** | 反常識必須來自你真實的專業判斷，不是為了反而反 | 「吃飯會傷腰」（無根據，標題黨） |
| **具體習慣** | 指向觀眾真實在做的具體動作，不是模糊的「某些行為」 | 「你的日常習慣可能係錯的」（太模糊） |
| **可信後果** | 後果要有邏輯支撐，讓觀眾覺得「有可能係真的」 | 「你會死」（誇張，失去可信度） |

---

### 3.3 反常識 Hook 的「面熟感」防護機制

反常識 Hook 也有面熟感問題——如果你每條片都用「其實係 XXX 出問題」這個句式，觀眾同樣會產生面熟感。

**防護原則：每三條片只能用同一個反常識句式一次。**

**句式輪換表：**

| 輪次 | 句式 | 例子 |
|------|------|------|
| 第 1 條 | 勸阻型（「千其唔好」） | 「坐耐起身腰痛，千其唔好即刻按條腰」 |
| 第 2 條 | 根源歸位型（「唔係 X，係 Y」） | 「腰痛唔係腰嘅問題，係你嘅骨盆歪咗」 |
| 第 3 條 | 習慣指錯型（「你以為 X，其實 Y」） | 「你以為坐直係保護腰，其實正在傷害你」 |
| 第 4 條 | 回到勸阻型，但換場景 | 「膝蓋痛想按膝蓋？慳返啲錢」 |

## 四、「狀況描述型 → 反常識型」轉換公式

### 4.1 三步轉換法

**第一步：找出你的核心洞察**
問自己：「關於這個痛症，我知道一件大部分人不知道的事是什麼？」

**第二步：找出觀眾正在做的錯誤習慣**
問自己：「我的 TA 在這個問題上，最常做的錯誤動作/習慣是什麼？」

**第三步：用勸阻型或根源歸位型表達**
把「核心洞察」和「錯誤習慣」組合成一句反常識 Hook。

### 4.2 實際轉換對照表（三條片的 Hook 改寫）

| 片 | 原版（狀況描述型）| 改寫版（反常識型）| 改寫類型 |
|----|----------------|----------------|---------|
| 20/7 | 「你係咪換極鞋，對腳都係痛？行耐啲就腳板脹...」 | 「腳痛想換對好鞋？慳返啲錢啦——你換幾多對都冇用，因為問題唔係喺對鞋，係喺對鞋入面。」 | 勸阻型 |
| 15/7 | 類似症狀描述 | 「坐耐咗起身腰痛，千其唔好即刻按條腰——你按嘅位置根本唔係問題所在。」 | 勸阻型 |
| 9/7 | 類似症狀描述 | 「你以為坐直係保護腰——其實你嘅『坐直』正在傷害你嘅椎間盤。」 | 習慣指錯型 |

## 六、使用指引（每次生成 Hook 前必讀）

### 6.1 Hook 生成前的四個問題

1. **這個 Hook 是「狀況描述型」嗎？** 如果是，必須用三步轉換法改寫。
2. **這個 Hook 的句式，最近三條片用過嗎？** 如果用過，必須換句式。
3. **反常識的洞察是真實的嗎？** 如果是砌出來的，必須重新找真實洞察。
4. **反常識指向的習慣，TA 真的在做嗎？** 如果不確定，必須先確認。

### 6.2 快速診斷：「這個 Hook 是狀況描述型嗎？」

**測試方法：** 把 Hook 填入以下模板，如果完全符合，就是狀況描述型：

```
「你係咪有 [症狀]？試過 [方法] 都唔得？其實係 [根源] 出問題！」
```

如果你的 Hook 可以用這個模板概括，必須改寫。

### 6.3 反常識 Hook 的最終檢查

- [ ] 第一句有沒有「勸阻詞」（千其唔好/停手/慳返啲錢）或「反轉詞」（唔係X係Y/你以為X其實Y）？
- [ ] 反常識的洞察是否來自你真實的專業判斷？
- [ ] 後果是否具體、可信、有邏輯支撐？
- [ ] 這個句式最近三條片有沒有用過？

## 七、老師建議的具體例子（直接可用）

老師在複盤中提供的反常識 Hook 例子：

> **「坐得耐起身腰痛千其唔好咁按條腰！」**

拆解：
- `坐得耐起身腰痛` = 具體場景（TA 每天都經歷）
- `千其唔好咁按條腰` = 勸阻（反直覺，觀眾本能就想按）
- 隱含懸念：「唔按腰，咁按邊？」（觀眾想知答案）

**這個例子的底層結構就是「勸阻型 Hook」的標準模板。**
