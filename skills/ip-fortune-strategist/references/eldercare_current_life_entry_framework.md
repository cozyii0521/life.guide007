# 家庭護老「當下生活入口」+ 首屏衝突框架

**建立日期：** 2026-08-22  
**適用：** 家庭護老、父母照顧需要漸變、出院轉銜、院舍／服務決策，以及由體態／肌肉內容橋接到老年功能的 Reels。

---

## 一、先賣「今天已發生」，不要先賣「將來可能很嚴重」

在職子女不會因為「父母將來會老」「你老後可能跌倒」自動停下來。首屏要先讓她認出一個**今天或本週已目擊的生活改變**，再打開護老的決策缺口。

> 正確路徑：**當下生活畫面 → 被常識帶過的改變 → 家屬講不清下一步 → 一口安全微交付。**

| 弱入口 | 問題 | 改成當下入口 |
|---|---|---|
| 「練肌肉，老後先有用」 | 觀眾須先跨過幾十年的心理距離 | 「以前食完飯行一圈，現在行到半路要歇」 |
| 「父母可能會退化」 | 抽象、像健康宣導 | 「以前自己做到的事，現在開始少做／做得辛苦」 |
| 「將來跌倒後果很大」 | 恐嚇或未證實因果風險 | 「這個改變不要只用『老了就是這樣』帶過」 |

**測試問題：** 觀眾能否在 3 秒內想起一個父母最近做過或沒做到的具體動作？不能，先不要寫老年後果。

---

## 二、窄題材有天花板；首屏衝突決定地板

有些題材本身只命中較少人，例如腰痛而且正在戴腰封的人。這是**題材天花板**，代表它較適合既有粉絲轉化或精準教育，不能要求它必然有泛流量。

但即使是窄題材，也不能把真正的衝突藏在第 2 秒以後。這是**首屏地板**：0 秒沒有具體對象、視覺異常和不同觀點，陌生流量連知道這條片值得看都沒有。

> 不要把「播放差」一律歸因於題材太窄；先分開問：**它的受眾本來有多大？首屏有沒有在 0 秒交出不同？**

| 題材角色 | 首屏必須交付 | KPI 優先順序 |
|---|---|---|
| 泛引流／主入口片 | 現在生活畫面 + 未被說破的缺口 | 略過率、Reels 分頁、分享／傳送 |
| 精準教育／轉化片 | 特定使用情境 + 立即衝突 | 收藏、DM、已有粉絲回應 |
| 主入口後的單點片 | 已知困境的一個可處理環節 | 收藏、留言、資產索取 |

## 三、具體畫面後，必須立即打開回更廣人群

一個具體畫面能停滑，但不要把全片鎖死在該動作。寫法是：

> **一個具體例子** + **「這類改變」的廣泛命名** + **被推翻的舊解釋**。

**示例結構：**

> 「你有沒有發現？父母以前食完飯會落公園行一圈，現在行到半路要歇。**這類改變**，很容易被一句『老了就是這樣』帶過。」

落公園只是讓觀眾先有畫面；「這類改變」才讓不出門、但在煮飯、覆診、社交或日常照顧中看見變化的家庭都能代入。

---

## 四、家庭護老主入口片的安全微交付路徑

主入口片不做遙距醫療分流，也不替陌生家庭判斷「觀察／求醫／改安排」的固定門檻。

> **看見改變 → 說不清改變 → 記清楚一件改變 → 覆診時帶去討論。**

### 片內可交付

要求觀眾只選**一件**生活改變，記下：

1. 以前怎樣做；
2. 何時開始有變化；
3. 最近一週出現多少次。

這是整理觀察資料，不是診斷規則。下一次覆診時，家屬可用這三樣資料說清楚生活上的改變；醫護再按個別情況評估。

### 不可交付

- 「一星期幾次以上就要怎樣做」等固定門檻；
- 用短片判斷認知障礙、跌倒風險、是否需要院舍或外傭；
- 用單一高風險例子（例如忘記關爐）替整個漸變期入口定義問題；
- 用「拖延必定出事」「黃金期」「護老悲劇」逼迫家屬互動。

## 五、0 秒視覺執行規格

不要以真人面向鏡頭講話作首幀。先用一件非識別、可代入的生活物件／動作，配高對比大字：

| 內容說的是 | 可用首屏 | 不要用 |
|---|---|---|
| 出門／步行變化 | 門口散步鞋、兩張對比便條 | 偷拍長者或院友 |
| 覆診資料整理 | 空白日曆、無個資的提醒便條 | 真實覆診紙、病歷 |
| 照顧需要改變 | 未使用的餐具、空白記事紙 | 戲劇化危險畫面冒充個案 |

**首屏字卡模板：**

```text
以前：食完飯落公園
現在：行到半路要歇
```

第 2 秒再切出鏡，才說明這不是單一「散步」問題，而是值得被記清楚的生活改變。

- [ ] 反常識是否在 0 秒與具體畫面同步，而不是等觀眾兩秒？

## 七、體能內容仍要對子女說，不要變成長者運動課（17.9.2026 新增）

IP 老師確認：長者體能題可以有簡單動作或方法，但目標觀眾仍是 30–50 歲子女，不是直接向長者授課。方法不是選題本身；**先講清楚子女正在擔心的具體生活痛點，再決定是否需要示範。**

操作原則：

1. 不以複雜、細緻的動作教學作開場；先用父母日常能力與子女擔心的結果切入。
2. 若需要動作畫面，優先由 Cathy 示範一個容易理解的生活動作概念，不偷拍父母或院友。
3. 不做長者居家自測、單腳站／閉眼站計秒、打分、跌倒風險判定或個人化運動處方。
4. 不把示範寫成「人人照做」；個別長者是否適合及如何進行，交回其原有醫護或物理治療師。
5. 檢查第一句是否已說清「解決哪個具體痛點」；若只見方法、看不到問題，先重寫切入角度。
