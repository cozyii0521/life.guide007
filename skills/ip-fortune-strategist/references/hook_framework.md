# Hook 寫作框架完全手冊（Cathyii IP 專用版）

本文件整合 IP 老師課程精華（33 張圖片），提取 6 大 Hook 機制、組合技、語氣節奏規則及常見錯誤，並全部應用至 Cathyii 的體態痛症 IP 主題，提供可直接使用的例句庫。

---

## 核心原則：Hook 的本質

Hook 不是標題黨，是內容的「預告片」。它的唯一目的是讓觀眾在前 3 秒決定「繼續看」。

> 「你只需要開一個他走不了的頭，剩下的，大腦會替你完成。」

**No Hook = No View。**

## 六大 Hook 機制

---

### 機制一：身份代入（Identity Injection）

**原理：** 人最在意的永遠是自己。當第一句話精準點名「你是誰」，大腦會即時反應「說的是我！」，停止滑動。

**公式：** `[精準身份標籤] + [他正在面對的處境/問題]`

**精準度原則：**
- 越精準越好，「香港女生」比「女生」好，「30+ 久坐上班族」比「香港女生」好
- 不要用「所有人都符合」的標籤（例如「你有沒有試過……」）
- 描述了身份後必須接上理由繼續看，不能只說「如果你是打工仔……」然後沒有下文

**Cathyii IP 應用例句庫：**

| 場景 | Hook 例句 |
|------|-----------|
| 泛人群 | 「30+ 女生聽好——你以為嘅健康習慣，可能正在傷害你嘅脊椎。」 |
| 久坐族 | 「每日坐超過 6 小時嘅你——你嘅骨盆已經開始出問題了。」 |
| 腰痛 | 「腰痛超過 3 個月嘅你，我要跟你講一件你從來沒有想過嘅事。」 |
| 頸痛 | 「頸痛好唔返嘅上班族——你係咪一直拉錯位置？」 |
| 拇趾外翻 | 「先天性拇趾外翻嘅你，唔做手術都可以控制惡化——但你要知道呢一件事。」 |
| 足弓塌陷 | 「足弓塌陷嘅你，你嘅膝蓋同腰椎正在默默受苦——你知道嗎？」 |
| 媽媽族群 | 「帶小朋友帶到腰痠背痛嘅媽媽——唔係你唔夠強，係你用錯咗發力方式。」 |
| 辦公室女生 | 「辦公室坐足 8 小時嘅你——你嘅肩膀高低位已經告訴我你嘅痛症根源在哪。」 |

### 機制二：利益前置（Benefit First）

**原理：** 大腦每秒都在做「值不值得花時間」的判斷。馬上告訴觀眾看完能得到什麼，大腦判斷「有用」才會停下來。

**兩個心理學原理：**
- 損失規避：怕錯過好處
- 即時回報偏好：「今晚就能用」比「未來某天有用」更吸引

**公式：** `[看完可以得到的具體好處] + [時間成本低/即時可用]`

**常見錯誤：**
- 利益太模糊：「看完你會有收穫」→ 改為具體的結果
- 誇大到不可信：「保證你月入十萬」→ 利益要真實可信
- 利益跟觀眾無關：用專業術語說利益，觀眾聽不懂

**Cathyii IP 應用例句庫：**

| 場景 | Hook 例句 |
|------|-----------|
| 即時動作 | 「今日教你 1 個動作，做完即刻感覺腰輕咗——唔使去健身房，坐係屋企就做得。」 |
| 省時 | 「3 分鐘，幫你搞清楚你嘅腰痛根源係邊度——比你去睇 10 次骨科更有用。」 |
| 避免浪費 | 「你係咪花咗好多錢按摩但只維持 3 日？今日教你點樣解決根源，唔係症狀。」 |
| 自測 | 「60 秒自測你係咪假胯寬——睇完你會知道你嘅體態問題根源係邊度。」 |
| 知識乾貨 | 「我用咗 12 年護理經驗總結出嘅 3 個體態真相，今日 60 秒講俾你聽。」 |
| 改善效果 | 「呢 2 個動作，我嘅學員做咗 2 週，腰痛減少咗 70%——你今晚就可以試。」 |

### 機制三：認知衝突（Cognitive Conflict）

**原理：** 每個人腦中都有一套「我以為的世界」。當你說出一句跟他認知矛盾的話，大腦產生「認知失調」，非常不舒服，必須繼續看下去來「修復」這個矛盾。

> 「大腦最受不了的一件事：發現自己可能是錯的。」

**公式：** `[反常識的結論/事實]` 或 `[你以為是 A，其實是 B]`

**常見錯誤：**
- 只有衝突沒有解釋：說完「做運動不會瘦」就沒有下文，觀眾覺得標題黨
- 衝突太離譜：「吃飯會死人」→ 衝突要「出乎意料但合乎情理」
- 每條都用認知衝突：觀眾疲勞，要搭配其他機制使用

**Cathyii IP 應用例句庫：**

| 場景 | Hook 例句 |
|------|-----------|
| 拉筋迷思 | 「你拉緊嘅筋，其實根本唔係肌肉緊——你一直拉錯位置。」 |
| 運動迷思 | 「你做嘅腹肌訓練，正在加重你嘅腰痛。」 |
| 按摩迷思 | 「你去按摩，只係暫時舒服——真正嘅問題你根本冇解決過。」 |
| 姿勢迷思 | 「你以為嘅『正確坐姿』，其實係你腰痛嘅根源之一。」 |
| 努力迷思 | 「你越努力做運動，你嘅體態問題可能越嚴重。」 |
| 老化迷思 | 「30+ 女性呢個常見既姿勢，令你身體加快老化。」 |
| 足弓迷思 | 「你以為足弓塌陷係腳嘅問題——其實根源係你嘅骨盆。」 |
| 頸痛迷思 | 「你嘅頸痛，唔係因為你望手機太多——係你嘅呼吸方式出咗問題。」 |
| 腰痛迷思 | 「腰痛唔係因為腰弱——係因為你嘅骨盆位置一直都係錯嘅。」 |

### 機制四：情緒劫持（Emotional Hijacking）

**原理：** 情緒腦比理性腦快 400 倍。當第一句話觸發強烈情緒，觀眾在理性腦來不及判斷「要不要看」之前，已經被抓住了。

**5 種最有效的情緒觸發點：**

| 情緒 | 觸發方式 |
|------|---------|
| 心疼/感動 | 分享真實的掙扎或感人時刻 |
| 憤怒/不公平 | 揭露不公平的現象或被誤導的經歷 |
| 恐懼/危機感 | 點出「你現在不做，後果很嚴重」 |
| 震驚/意外 | 說出一個讓人難以置信的真實情況 |
| 共鳴/被理解 | 精準描述觀眾的內心感受，讓他覺得「有人懂我」 |

**Cathyii IP 應用例句庫：**

| 情緒類型 | Hook 例句 |
|---------|-----------|
| 心疼/共鳴 | 「我有個學員，腰痛咗 5 年，睇過 8 個醫生，每次都係『開藥、休息』——直到我問咗佢一個問題。」 |
| 憤怒/不公平 | 「你係咪花咗幾千蚊去按摩、去睇骨科，但痛症根本冇好過？唔係你嘅問題——係你一直被告知錯嘅方向。」 |
| 恐懼/危機感 | 「你而家嘅腰痛，如果唔處理根源，5 年後可能係椎間盤突出。」 |
| 震驚/意外 | 「我第一次幫一個學員做體態評估，佢以為係腰痛——結果根源係佢嘅呼吸方式。」 |
| 共鳴/被理解 | 「你試過做完所有運動、拉完所有筋，但第二日腰仲係痛——你係咪覺得係自己嘅問題？唔係。」 |
| 危機感（老化） | 「你現在嘅體態，正在決定你 10 年後係行得起定係行唔起。」 |

### 機制五：好奇心缺口（Curiosity Gap）

**原理：** 人類大腦無法忍受「資訊不完整」。當你提供了部分資訊，但刻意留下空缺，大腦會強迫觀眾繼續看下去來填補缺口。

**公式：** `[暗示有重要資訊] + [但沒有直接說出來]`

**好奇心缺口 vs 懸念的區別：**
- 好奇心缺口：想知道答案，但不知道答案是什麼（Netflix 的推薦清單）
- 懸念：故事去到一半，不知道結局（Netflix 播到一半停了）
- 懸念多了一層「故事代入感」——觀眾不只是想知道答案，已經在你的故事裡了

**Cathyii IP 應用例句庫：**

| 場景 | Hook 例句 |
|------|-----------|
| 根源揭秘 | 「你嘅腰痛根源，唔係你以為嗰個位置——大部分人都搞錯咗。」 |
| 專家視角 | 「作為體態護理師，我一眼就能睇出你嘅痛症根源——但你可能從來沒有想過係呢個原因。」 |
| 反常識 | 「有一個動作，幾乎所有人都做錯——而且越做越傷腰。你知道係咩嗎？」 |
| 數字勾引 | 「我見過超過 500 個腰痛個案，只有 3% 嘅人係真正嘅腰部問題——其他 97% 根源都唔係腰。」 |
| 秘密感 | 「護理師唔會主動告訴你嘅一件事——你嘅痛症為什麼好唔返。」 |
| 測試引導 | 「做一個動作，10 秒，你就知道你嘅腰痛根源係邊度。」 |

### 機制六：懸念（Cliffhanger）

**原理：** 蔡格尼克效應（Zeigarnik Effect）——人類大腦對「未完成的事」的記憶比「已完成的事」強 2 倍。你打開了一個「迴路」但沒有關掉，大腦會一直分配資源記住這件事，直到得到答案。

> 「他不是『選擇』要看——他是『被迫』要看。這不是意志力的問題——是大腦的本能。」

**公式：** `[故事/事件開頭] + [關鍵時刻停住，不說結局]`

**常見錯誤：**
- 懸念鋪墊太長：5 秒內要進入故事，開頭就直接拋出懸念
- 結局太普通：期望越高失望越大，結局要對得起你開的懸念
- 每條都用「發生了一件事」：觀眾疲勞，要換不同公式和角度

**Cathyii IP 應用例句庫：**

| 場景 | Hook 例句 |
|------|-----------|
| 學員故事 | 「我有個學員，腰痛咗 7 年，試過所有方法都冇用——直到我叫佢做咗一件佢從來沒有想過嘅事。」 |
| 個人經歷 | 「我第一次幫人做體態評估，佢哭咗——唔係因為痛，係因為終於有人搞清楚咗佢嘅問題。」 |
| 意外發現 | 「上個月有個學員嚟到，話腰痛好返咗——但我第一眼就知道，佢嘅問題根本未解決。」 |
| 診斷故事 | 「佢話自己係腰痛，但我第一眼睇嘅唔係佢嘅腰——我睇嘅係佢嘅腳掌。然後我明白咗一切。」 |
| 轉折故事 | 「我叫佢停止所有運動，停止所有拉筋——佢以為我瘋咗。但 2 週後佢發咗一個訊息俾我。」 |

## 組合技：同時觸發多個機制，威力翻倍

單一機制 = 有效；兩個機制疊加 = 很難滑走；三個機制疊加 = 完全走不了。

| 組合 | 通用公式 | Cathyii 應用例句 |
|------|---------|----------------|
| 身份代入 × 好奇心缺口 | 「[身份標籤]，這件事你一定要知——但大部分人不知道。」 | 「腰痛超過 3 個月嘅你，有一件事你一定要知道——但你嘅醫生可能從來沒有告訴你。」 |
| 認知衝突 × 好奇心缺口 | 「[反常識結論]——真正嘅原因你一定猜不到。」 | 「你嘅腰痛，唔係因為腰弱——真正嘅根源你一定猜唔到。」 |
| 情緒劫持 × 懸念 | 「[強烈情緒開頭]……[停住不說結局]」 | 「佢腰痛咗 5 年，試過所有方法——直到佢做咗一件我叫佢做嘅事，佢哭咗。」 |
| 身份代入 × 利益前置 | 「[身份標籤]聽好——[具體好處]。」 | 「30+ 久坐女生聽好——呢 2 個動作，幫你今晚就減輕腰痛。」 |
| 認知衝突 × 身份代入 | 「如果你[做了某件事]但[沒有效果]——恭喜你，你做對了第一步。」 | 「如果你每日都拉筋但腰仲係痛——恭喜你，你已經找到問題所在了。」 |
| 三重組合 | 身份代入 × 認知衝突 × 好奇心缺口 | 「腰痛嘅你——你以為係腰嘅問題，但根源其實係一個你從來沒有想過嘅地方。」 |

## Hook 的語氣與節奏（口播必讀）

**三個關鍵規則：**

1. **第一句話要短**：❌「大家好今日我想跟大家分享一下……」→ ✅「你嘅腰痛，唔係你嘅錯。」（短、有力、直接）

2. **語速要比平時慢**：前 3 秒特別放慢，讓每一個字都打進去。正常語速太快，觀眾來不及接收。

3. **表情要配合 Hook 類型：**

| Hook 類型 | 表情 |
|-----------|------|
| 好奇心缺口 | 帶微笑，像要講秘密 |
| 認知衝突 | 嚴肅，像在講一件大事 |
| 情緒劫持 | 真實，該感動就感動 |
| 懸念 | 帶懸疑，像在講故事 |

## 5 個最常見的 Hook 錯誤

| 錯誤 | 案例 | 修正方向 |
|------|------|---------|
| 開頭太客氣 | 「大家好，今日想跟大家分享一下……」 | 直接進入 Hook，不要寒暄 |
| 開頭太長 | 鋪墊了 30 秒還沒進入重點 | 第一句話就是 Hook |
| 開頭自嗨 | 「我最近有一個感悟……」 | 講他，不是講你 |
| 開頭太模糊 | 「關於體態這件事……」 | 用 6 個機制中的任何一個 |
| Hook 跟內容脫節 | 開頭很吸引但內容完全對不上 | Hook 是內容的「預告」，不是標題黨 |

## 使用指引

每次為 Cathyii 生成 Reels 腳本時，必須：

1. **選擇 1-2 個 Hook 機制**，根據內容主題和目標受眾層選擇最合適的組合
2. **從例句庫中選取或改編**，確保 Hook 與內容主題直接相關
3. **檢查 5 個常見錯誤**，確保 Hook 不犯以上錯誤
4. **確認 Hook 與內容不脫節**，Hook 是內容的預告，結尾必須兌現 Hook 的承諾

| 受眾層 | 推薦 Hook 機制 |
|--------|--------------|
| 泛人群 | 身份代入 + 認知衝突（反常識，任何人都有共鳴） |
| 泛垂直人群 | 認知衝突 + 好奇心缺口（已有痛症意識，但想知道根源） |
| 垂直人群 | 情緒劫持 + 懸念（已在痛苦中，需要被理解和解決方案） |
| 精準人群 | 身份代入 + 利益前置（已準備行動，直接給具體好處） |

## 進階補充：Gemini Prompt 提煉（1.6.2026 新增，已對照老師理念驗證）

### A. 動態 Hook 分配決策樹

> **核心原則：唔好盲目用單一 Hook 套路。先判斷片長與目標，再選 Hook 類型。**

| 片長 / 目標 | 強制使用的 Hook 類型 |
|------------|-------------------|
| **≤30s 衝流量短片** / 受眾正在做錯誤操作 | **高品味制止型 Hook** |
| **>60s 建立信任長片** | **混合式 Hook** 或 **跨部位認知橋接 Hook** |

**橋接公式（跨部位選題必用）：**
- 「你以為係兩件事，其實係同一件」
- 「真兇唔喺 A，喺 B」

---

### B. 高品味制止型 Hook 公式

**公式：**
```
[用戶正踩坑的具體行為/場景] + [科學代價制止句] + [反常識認知缺口]
```

**❌ 低俗恐嚇版（嚴禁使用）：**
> 「大腳趾歪？大件事啦！千祈唔好戴矯正器！」

問題：流於微商恐嚇，無科學代價，無缺口，觀眾感覺被騙。

**✅ 高品味制止版（必須執行）：**
> 「夜晚戴矯正器？停手。你戴得越耐，隻腳趾越嚟越廢——因為你入面嗰條肌肉已經放棄撐住你。」

拆解：
- `夜晚戴矯正器` = 具體踩坑行為（觀眾對號入座）
- `停手` = 高品味制止（唔係恐嚇，係科學警告）
- `越戴越廢` = 科學代價（有邏輯，唔係嚇人）
- `因為入面嗰條肌肉放棄撐住你` = 認知缺口（點解？觀眾想知）

**Cathyii 應用範例：**

| 選題 | 高品味制止型 Hook |
|------|----------------|
| 矯正器 | 「夜晚戴矯正器？停手。你戴得越耐，隻腳趾越嚟越廢。」 |
| 拉筋 | 「每朝拉斜方肌？停一停。你拉得越用力，佢就夾得越緊。」 |
| 止痛藥 | 「頭痛食止痛藥？只係封住佢個嘴，過兩個鐘佢又叫救命。」 |

### C. Hook 審查：AND 邏輯 → OR 邏輯（擴大命中面）

**問題：** Hook 用「AND 邏輯」描述受眾，同時需要符合多個條件，命中面窄。

**解決：** 改為「OR 邏輯」或「嚴重度遞進」，讓更多人覺得「係講緊我」。

| 類型 | 例子 | 命中人數 |
|------|------|---------|
| **AND 邏輯（窄）** | 「久坐 8 小時 AND 有腰痛 AND 試過買護腰」 | 三個條件都符合才命中 |
| **OR 邏輯（寬）** | 「久坐腰痛 OR 站久腳痠 OR 瞓醒膊頭緊」 | 符合任何一個就命中 |
| **嚴重度遞進（最強）** | 「坐耐少少腰痠？定係已經痛到要靠藥油撐？」 | 輕症到重症全部命中 |

**使用時機：** 泛人群片優先用 OR 邏輯；垂直片才用精準 AND 邏輯。

## 八、三維 Hook 設計系統（5.6.2026 對話提煉，已對照老師理念驗證）

> 來源：5.6.2026AICHAT-BYGEMINI.docx
> 核心：好的 Hook 唔只係文字，係視覺 + 字幕 + 口播三者同步

---

### 8.1 三維 Hook 定義

**「好的 Hook = 視覺爆點（畫面指令）+ 核心痛點（置中大字幕）+ 懸念台詞（口播旁白）」**

三者缺一，略過率就會破 60%。

| 維度 | 作用 | 例子（拇趾外翻）|
|------|------|--------------|
| **視覺爆點** | 前 0.8 秒抓住眼球，讓觀眾停止滑動 | 特寫：腳趾歪斜 + 矯正器 |
| **置中大字幕** | 讓觀眾即使靜音也能被 Hook 住 | 「戴矯正器瞓覺？你係咁害緊隻腳」 |
| **口播旁白** | 製造認知衝突，讓觀眾想繼續聽 | 「以為戴矯正器瞓覺就改善——其實咁樣只係叫你隻腳放棄自救」 |

**與老師原則的關係：**
老師講「前 3 秒讓大腦守門員放行」，三維 Hook 係操作化版本：視覺解決 0-0.5 秒掃描，字幕解決 0.5-1.5 秒判斷，口播完成 1.5-3 秒決定。

---

### 8.2 視覺 Hook 優先級（唔係所有 Hook 都靠文字）

**當略過率 >60%，問題 100% 在前 3 秒畫面，唔係文字。**

| 視覺 Hook 類型 | 效果 | 適用選題 |
|--------------|------|---------|
| **物件特寫** | 即時識別，觸發「係我！」| 矯正器、藥貼、護膝 |
| **動作懸念** | 「佢要做咩？」的好奇感 | 示範動作前的特寫 |
| **對比畫面** | Before/After 視覺衝擊 | 體態對比、腳型對比 |
| **自測即場做** | 觀眾即場跟做，立刻驗證 | 單腳企、腳趾張開 |

**鐵律：真人望鏡頭開場 = 高略過率。除非你係高知名度 KOL，否則避免純出鏡口播開場。**

---

### 8.3 精準泛人群化的 Hook 原則

**核心：泛人群化唔係跨賽道，係擴大入口語言。**

| 類型 | 做法 | 例子 |
|------|------|------|
| ✅ **正確泛人群化** | 擴大入口（所有久坐族都有的身體感）→ 保留專業出口 → 即時動作交付 | 「下晝 3 點 down 機？唔係攰咁簡單——係你個後頸鎖死咗，大腦供氧不足」 |
| ❌ **錯誤泛人群化** | 跨賽道講心靈雞湯（「36 歲不甘心」），沒有即時交付 | 吸引錯誤受眾，轉換率為零 |

**鐵律：所有話題入口再寬，也必須在「身體/痛症/體態」守備範圍內。**

## 九、Hook 精修三層診斷框架（6.6.2026 對話提煉，已對照老師理念驗證）

> 來源：6.6.2026aichat.docx — EP2 Hook 改寫對話記錄
> 核心邏輯：Hook 問題唔係「太長」，係「推翻嚟得太遲」或「改寫後變模糊」

---

### 9.1 Hook 三層診斷

**第一層：推翻嚟得太遲（最常見問題）**
- 症狀：有推翻，但前面鋪陳太長，觀眾 2 秒內未見到衝突
- 診斷：「推翻嚟得太遲」≠「Hook 太長」
- 修法：第一句直接推翻，唔使等

**第二層：改寫後變模糊（改了反而更差）**
- 症狀：縮短了但用「呢個部位」「呢樣嘢」等模糊詞代替具體對立
- 診斷：觀眾聽到「呢個部位」→「邊度啊？」→ 估謎感 → 滑走
- 修法：保留具體對立（A vs B），唔用模糊詞

**第三層：改寫後失去反差（最隱蔽問題）**
- 症狀：改成「唔好當冇事」「要注意」等普通提醒
- 診斷：失去「你一直盯住的嘢根本唔係重點」的反差衝擊
- 修法：保留「你睇錯重點」的結構，唔能變成普通警告

---

### 9.2 Hook 精修對照表（實例）

| 版本 | 文字 | 問題 |
|------|------|------|
| ❌ 原版（推翻太遲）| 「好多人一發現拇趾外翻，第一件事就係照鏡睇隻趾歪咗幾多——歪得多就驚到死，歪得少就當冇事。但其實隻趾歪幾多度，根本唔係重點。」| 前面鋪咗成句先到肉，口播頭 2 秒冇衝突 |
| ❌ 改寫版（變模糊）| 「發現拇趾外翻，唔好以為歪得少就冇事，呢個部位先決定救唔救得返」| 「呢個部位」模糊，失去具體對立 |
| ✅ 精修版（即刻到肉）| 「拇趾外翻，唔好再對住塊鏡數隻趾歪咗幾多度——歪幾多根本唔係重點。真正決定你救唔救得返嘅，係佢仲扳唔扳得返。」| 第一句即刻推翻 + 具體對立 + 尾句勾自測好奇 |

---

### 9.3 Hook 詞彙選擇原則：動作詞 > 概念詞

| 選項 | 問題 |
|------|------|
| 「歸位」（概念詞）| 書面、抽象，觀眾唔知要做咩，需要腦海多翻譯一次 |
| 「扳唔扳得返」（動作詞）| 具體，自測動作本身就係「用手扳」，Hook 用詞同動作一致，觀眾零轉換 |

**原則：Hook 的動詞必須同片內的示範動作一致，唔好製造詞彙轉換成本。**

## 十、動作型 Hook 原則（6.6.2026 升級版，已對照老師理念驗證）

> 來源：6.6.2026aichat.docx — EP2 Hook 最終升級對話記錄
> 核心升級：Hook 唔係講概念，係叫觀眾**即刻做動作**——用動作鎖住佢，唔係用金句

---

### 10.1 概念型 Hook vs 動作型 Hook

| 類型 | 例子 | 效果 |
|------|------|------|
| ❌ **概念型** | 「唔好對住塊鏡數角度——角度唔係重點」 | 講道理，觀眾被動接收 |
| ✅ **動作型** | 「依家用手扳一扳你嘅腳趾公——扳得返定扳唔返，先決定你救唔救得返」 | 叫觀眾郁手，身體跟住停低試，走唔到 |

**核心原理：知識型口播，Hook 入面就叫觀眾郁手，佢個身體會跟住停低試。佢一試，就走唔到——因為佢想知自己的結果。用一個動作鎖住佢，唔係用一句金句。**

---

### 10.2 動作型 Hook 的結構公式

```
[主題錨點（2-4字）] + [即刻動作指令] + [動作結果 = 懸念]
```

**示範：**
> 「**拇趾外翻**，依家用手扳一扳你嘅腳趾公——**扳得返定扳唔返**，先決定你救唔救得返。」

拆解：
- `拇趾外翻` = 主題錨點（0.5 秒鎖定主題，觀眾即知關我事）
- `依家用手扳一扳你嘅腳趾公` = 即刻動作指令（觀眾郁手）
- `扳得返定扳唔返，先決定你救唔救得返` = 動作結果 = 懸念（做完想知自己係邊種）

---

### 10.3 動作型 Hook 的連鎖效應：Hook 與自測段的銜接

**問題：Hook 叫咗觀眾做動作，自測段唔能再重複叫佢做同一動作。**

| 段落 | 功能 | 正確做法 |
|------|------|---------|
| **Hook** | 叫做 | 「依家用手扳一扳你嘅腳趾公」 |
| **自測段** | 收成果 | 「扳緊未？睇你係邊種：」→ 直接落分級結果 |

**❌ 錯誤做法（Hook 與自測段撞）：**
> Hook：「依家用手扳一扳你嘅腳趾公」
> 自測段：「依家即刻試，用手揸住腳趾公扳返正」← 重複叫扳，觀眾感覺被重複指令

**✅ 正確做法（Hook 叫做、自測收成果）：**
> Hook：「依家用手扳一扳你嘅腳趾公」
> 自測段：「扳緊未？睇你係邊種：🟢輕鬆扳得返... 🟡扳得返但好緊... 🔴點扳都扳唔返...」

---

### 10.4 主題錨點的必要性

**問題：「歪幾多根本唔係重點」獨立做第一句，觀眾未知你講緊咩「歪」。**

**修法：加 2-4 字主題錨點在最前。**

| 版本 | 問題 |
|------|------|
| ❌ 「歪幾多根本唔係重點。依家用手扳一扳...」 | 觀眾聽到「歪」→「歪咩？」→ 需要 0.5 秒反應 |
| ✅ 「**拇趾外翻**，歪幾多根本唔係重點。依家用手扳一扳...」 | 「拇趾外翻」四字即刻鎖定主題，觀眾 0 秒知關我事 |

**原則：Hook 第一個詞必須係觀眾能即刻對號入座的主題詞，唔能讓觀眾花時間猜「你講緊咩」。**

## 十一、ReelScript AI 提煉框架（11.6.2026 新增，已對照老師理念驗證）

> 來源：11.6.2026chat.docx — Cathyii 與 ReelScript AI 的 EP4 完整對話記錄
> 核心：三個現有框架未涵蓋的新法則：威脅行先次序法、三軌補位法、核心詞雙重落錨

---

### 11.1 威脅行先，條件殿後（Hook 次序法則）

**核心洞察：** Hook 的問題通常不是「太長」，而是「最狠的那句排到最後才出」。解法不是刪字，是調次序。

**黃金法則：** `結果／威脅行先，條件殿後`

| 版本 | 結構 | 問題 |
|------|------|------|
| ❌ 原版（威脅太遲） | 條件（如果你買咗器材）→ 指令（睇到尾）→ 威脅（會令你愈嚟愈差）| 威脅排第三，觀眾等到第三句才到肉 |
| ✅ 調次序版（威脅行先） | 威脅（矯正器正喺度令你隻腳愈嚟愈歪）→ 條件（如果你買咗器材）→ 卸防衛（唔係叫你掉咗佢）| 0-2 秒就到肉，條件和卸防衛全部保留 |

**一句講白：** 你個顧慮啱，但解法唔係刪字，係「把最狠嗰句搬去第一秒」。條件、鎖定、卸防衛全部可以留，只要威脅行頭，長啲都 hold 得住人。

**與老師原則的關係：** IP 老師說「第一句話要短、有力、直接」——「威脅行先」就是把最有力的那句放到第一秒的操作化。

---

### 11.2 三軌補位法（口播 × 畫面 × 字幕）

**核心邏輯：** 口播趕唔切交代的資訊，畫面和字幕幫你補。三軌不是重複，是分工。

| 軌道 | 功能 | 例子（EP4 矯正器） |
|------|------|----------------|
| **口播** | 傳遞威脅／邏輯／情緒 | 「矯正器正喺度令你隻腳愈嚟愈歪」 |
| **畫面** | 即時視覺確認（觀眾眼睛看到） | 手攞住矯正器對住鏡頭（實物出現） |
| **字幕** | 鎖定關鍵詞（靜音用戶 + 演算法） | 大字「拇趾外翻」（雙重落錨） |

**3 秒內三軌齊收，略過率就壓得返落嚟。** 觀眾耳朵聽威脅、眼睛同時睇到實物、字幕補上核心詞——三個感知通道同時觸發守門員。

**知識型片的特殊應用：** 知識型片冇動作可睇，要用「實物演示」撐住畫面（矯正器戴上/除返/戴鬆 vs 戴谷），唔好變成「對住鏡頭講足 70 秒」。

**鐵律：** 真人望鏡頭開場 = 高略過率（與 8.2 節一致）。知識型片尤其要靠實物撐住前 3 秒。

---

### 11.3 核心詞雙重落錨（SEO + 演算法派送）

**核心邏輯：** 核心詞（如「拇趾外翻」）必須同時出現在三個位置，演算法才能精準派送。

**三錨位置：**

| 位置 | 作用 | EP4 應用 |
|------|------|---------|
| **Hook 口播** | 語音識別，演算法讀取 | 「如果你**為咗拇趾外翻**買咗矯正器」 |
| **分鏡 1 字幕** | 文字識別，靜音用戶 + 演算法 | 「**拇趾外翻**買咗矯正器？睇到尾⚠️」 |
| **Caption 開頭** | SEO 搜尋 + 派送 | 「**拇趾外翻**矯正器戴咗咁耐……」 |

**為什麼重要：** 演算法靠頭幾秒的語音 + 字幕判斷要派給哪班人。核心詞只出現在口播而不在字幕，等於只落了一個錨，派送精準度減半。

**使用規則：** 每次生成 Reels 腳本後，必須確認核心詞是否在三個位置都出現。這不是風格選擇，是 must。

## 第十二節：體感落地法（14.6.2026 新增，來源：EP5 對話）

### 核心邏輯

知識型內容最大的風險是「觀眾聽完說『哦，知道了』然後滑走」。解法是讓觀眾在看片的過程中，用自己的身體「感受到」這個知識——身體記憶比語言記憶更持久。

### 操作三步驟

1. **設計一個「30 秒內可完成」的即場動作**（不需要任何工具，企喺度就可以做）
2. **這個動作要讓觀眾感受到你說的問題**（而不是只是「理解」）——做了之後，觀眾說「哦，係喎，我 feel 到」
3. **在口播中明確說「試吓」「你即刻 feel 到」**——邀請觀眾參與，而不是只是說給他們聽

### EP5 的應用例

> 「試吓而家企起身，夾住隻大腳趾、唔好用佢力，淨係用腳外側行兩步——你即刻 feel 到成個身要扭、膝頭要繃住先企得穩。你隻歪咗嘅腳趾公，就係日日廿四個鐘逼你咁樣行。」

這個動作讓「腳趾歪了會影響全身」這個抽象概念，變成觀眾「剛才親身感受到的事」。

### 與三軌補位法的關係

三軌補位法（口播×畫面×字幕）確保觀眾「聽到、看到、讀到」；體感落地法確保觀眾「感受到」。前者是感知層，後者是體驗層——兩者結合，觀眾帶走的不只是「知識」，而是「記憶」。

### 適用場景

- 知識型片（解釋抽象概念、力學原理、身體機制）
- 系列收尾集（需要讓觀眾「感受到」問題的嚴重性，而不只是「理解」）
- 任何觀眾可能說「哦，知道了」然後滑走的片

## 第十三節：行為承諾缺口法 + 留言缺口保護法（20.6.2026 新增）

> 來源：20.6.2026 — 另一 AI 對膝痛 EP1 口播稿的診斷對話
> 核心：兩個現有框架未涵蓋的新法則：行為承諾缺口（高於資訊缺口的留言動力機制）、留言缺口保護法（避免自己填掉 CTA 的缺口）

---

### 13.1 底層邏輯拆解：這個 AI 的思維框架

這個 AI 的評估框架建立在**觀眾參與層級理論**上，把觀眾的投入程度分為三層：

| 層級 | 觀眾狀態 | 留言動力 |
|------|---------|---------|
| **被動聽** | 觀眾只是接收資訊 | 低 |
| **主動理解** | 觀眾在腦海中形成畫面（資訊缺口）| 中 |
| **身體參與** | 觀眾真的郁手做了動作（行為承諾缺口）| **高** |

它的核心洞察是：**「行為承諾缺口」比「資訊缺口」更高一層**。觀眾一旦身體投入了，心理上就更難滑走——因為她已經「做了」，她需要知道結果。

---

### 13.2 逆向推導：這個 AI 的 Prompt 框架

根據其評估邏輯，可以逆向推導出它的核心評估 Prompt：

```
評估這個 Hook 時，問以下三個問題：

1. 觀眾的參與層級是什麼？
   - 被動聽（只是接收）→ 改為主動做
   - 主動理解（腦海有畫面）→ 改為身體參與
   - 身體參與（真的郁手）→ 最高層級，保留

2. Hook 的動作指令是否符合「0-3 秒執行門檻」？
   - 指令數量：1 個（最佳）/ 2 個（可接受）/ 3 個以上（太複雜，觀眾未做已滑走）
   - 執行難度：坐住可做（最低門檻）> 企起身做（中等）> 需要道具（太高）
   - 原則：Hook 的動作必須是觀眾「此刻、此地、立即」可以完成的

3. CTA 的留言缺口是否被自己填掉了？
   - 懸念段有沒有說出「具體點做」？
   - 如果說了，觀眾就不需要留言——因為她已經知道答案
   - 原則：製造「知道存在、但不知內容」的缺口，而不是「知道存在、也知道內容」
```

### 13.3 行為承諾缺口法（Interactive Hook）

**定義：** 在 Hook 的第一秒就叫觀眾做一個動作，讓她從「觀眾」變成「參與者」。她一旦做了，就產生一個「未完成迴路」——「我試咗，但仲未知答案」，這個迴路逼住她看完 + 留言。

**與現有「動作型 Hook」（第十節）的關係：**
- 第十節的動作型 Hook 強調「叫觀眾郁手，用動作鎖住她」
- 第十三節的行為承諾缺口法補充了**心理機制的解釋**：為什麼動作型 Hook 有效——因為身體投入產生了「行為承諾」，觀眾的心理成本讓她更難放棄

**公式：**
```
[主題錨點（2-4字）] + [極簡動作指令（1個）] + [動作結果 = 懸念]
```

**執行門檻三原則（新增）：**

| 原則 | 說明 | 例子 |
|------|------|------|
| **坐住可做** | 動作不需要觀眾站起來或移動位置 | 「坐喺度，試吓將腳底向上拱起」（✅）vs「企起身，行兩步」（❌ 太複雜）|
| **一個指令** | 0-3 秒只給一個動作，不能同時要求多個步驟 | 「拱起足弓」（✅）vs「企起身 + 唔郁腳趾 + 拱起足弓」（❌ 三個指令）|
| **即時有感覺** | 做完之後觀眾馬上有體感反饋，不需要等 | 「拱唔起」「一邊冇力」「臀部冇感覺」（✅）vs「做三個禮拜後才有感覺」（❌）|

**Cathyii 應用例句庫：**

| 選題 | 行為承諾缺口型 Hook |
|------|------------------|
| 膝頭痛 | 「膝頭痛——依家坐喺度，試吓將腳底足弓向上拱起。拱得起定拱唔起，先決定你個膝頭幾時唔再痛。」|
| 腰痛 | 「腰痛——依家坐直，試吓唔用手撐，淨係用腰撐住個身。撐得住定撐唔住，先決定你條腰幾時唔再痛。」|
| 頸痛 | 「頸痛——依家坐住，試吓將個頭向後收，好似要將後頸拉長咁。收得到定收唔到，先決定你條頸幾時唔再痛。」|
| 圓肩 | 「圓肩——依家坐住，試吓將兩邊肩胛骨向中間夾。夾得到定夾唔到，先決定你對肩幾時唔再向前扣。」|

### 13.4 留言缺口保護法（CTA Gap Protection）

**定義：** 懸念段（40-50s）是 CTA 的「前置廣告」。如果在懸念段說出了「具體點做」，觀眾就不需要留言——因為她已經知道答案。這叫「自己填掉留言缺口」。

**核心矛盾：** 你想建立專業感（說出具體肌肉名稱），但又不能讓觀眾覺得「我已經知道了，唔使留言」。

**解法：「知道存在、但不知內容」的缺口結構**

```
❌ 填掉缺口（說出具體點做）：
「仲要訓練你個脛後肌頂住足弓、叫醒你個臀中肌防止膝頭向內扣」
→ 觀眾：「哦，練脛後肌同臀中肌，我知了，唔使留言。」

✅ 保護缺口（說出存在，但不說內容）：
「你仲有兩塊更深層嘅肌肉要叫醒——一塊負責由內側頂住足弓，一塊負責喺上面鎖住個膝頭。少叫醒一塊，個膝頭照舊被扭。呢兩塊喺邊、點叫醒，我放晒喺清單入面。」
→ 觀眾：「有兩塊肌肉，但係邊塊？點做？我要留言攞清單。」
```

**保護缺口的三個技巧：**

| 技巧 | 說明 | 例子 |
|------|------|------|
| **功能描述，不說名稱** | 說出肌肉的「功能」，不說「名稱」 | 「負責由內側頂住足弓的那塊」（✅）vs「脛後肌」（❌）|
| **數量暗示，不說內容** | 說「有 X 個動作 / X 塊肌肉」，但不說是什麼 | 「仲有兩個關鍵動作」（✅）vs「脛後肌訓練 + 臀中肌訓練」（❌）|
| **清單指向** | 明確說「呢啲我放晒喺清單入面」，把答案的位置指向 DM | 「點叫醒，我放晒喺清單入面」（✅）|

**與現有 CTA 框架的關係：** 現有框架強調「對號入座型 CTA」（觀眾留言自我診斷）；第十三節補充了「懸念段的缺口保護」——兩者合力，懸念段製造「想知道」的慾望，CTA 給出「如何得到」的路徑。

### 13.5 系列連結技巧（Series Universe Building）

**定義：** 在每集延伸片的懸念段或升級感段，加入一句「如果你做過上一個系列，你會發現這個是升級版」，把新舊觀眾同時鎖住。

**三重效果：**
1. **勾回舊粉**：做過拇趾外翻系列的觀眾會去翻舊片
2. **建立系列宇宙感**：你不是單條片，而是一個有層次的完整體系
3. **強化專業權威**：「我講的東西是有進階、有層次的」

**公式：**
```
「如果你做過我[上一個系列名]，你會發現呢個係升級版——
你而家係喺[更高層次的描述]，唔只係[上一個系列的描述]。」
```

**鐵律：** 這句話要變成每個延伸系列的**固定基因**，不是可選項。長遠會幫你建立「Cathy = 睇成個身連鎖反應嘅專家」的心智定位。

### 13.6 使用指引（整合現有框架）

每次為 Cathyii 生成 Reels 腳本時，在完成第十節（動作型 Hook）的設計後，額外執行以下檢查：

**Hook 檢查（行為承諾缺口）：**
- [ ] Hook 動作指令只有 1 個？
- [ ] 觀眾坐住就可以做（不需要站起來或移動）？
- [ ] 做完之後即時有體感反饋？

**懸念段檢查（留言缺口保護）：**
- [ ] 有沒有說出「具體點做」？（如果有，刪掉，改為功能描述）
- [ ] 觀眾看完懸念段後，是否仍然「知道存在、但不知內容」？

**系列連結檢查：**
- [ ] 如果是延伸系列，有沒有加入「升級版」連結句？
