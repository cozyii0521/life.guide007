# Reels 爆款策略與文案公式

本文件整合了 Instagram 演算法邏輯與 29 套短片公式，用於指導生成高轉化的 Reels 腳本。

## 1. 核心演算法邏輯 (0 粉起號)
- **觸及非粉絲**：Reels 是唯一能低成本觸及非粉絲的工具。
- **完播率 (Retention)**：前 3 秒 Hook 決定生死，避免「大家好我是...」的開場白。
- **分發訊號**：
  - **收藏**：提供高密度乾貨、懶人包、步驟清單。
  - **分享**：引發共鳴、吐槽、或極具實用性的內容。
  - **留言**：結尾設置簡單提問或引導索取資料（如「留言『我要』」）。

## 2. 爆款 Hook 設計 (前 3 秒)
- **視覺衝擊**：強烈的對比（痛症 vs 輕鬆）、誇張表情、或直接展示結果。
- **文字鉤子**：
  - 痛點直擊：「久坐 8 小時，腰快斷了？」
  - 認知翻轉：「別再這樣拉筋了，越拉越痛！」
  - 極低門檻：「辦公室最不尷尬的消痛法，坐著就能做。」

## 3. Slogan 量化邏輯
- **公式 1 (經典+量化)**：我幫助 [TA] + [如何做到] + [實現「數字化」結果]。
  - *例：我幫久坐族每天 15 分鐘，告別圓肩駝背。*
- **公式 2 (結果+量化)**：讓 [TA] + 在 [時間/步驟] 內 + [得到「數字化」成果]。
  - *例：讓職場女性 1 週挑戰烏龜頸變天鵝頸。*
- **公式 3 (痛點+量化解決)**：告別 [痛點]，[數字化時間/方法] 實現 [結果]。
  - *例：告別假肚腩，3 套動作還原真實身形。*

## 4. 常用短片公式 (精選)
- **反向操作**：提出反直覺觀點（如：越拉筋越痛），打破常規，吸引注意力。
- **成本/場景元素**：強調極低的時間/金錢成本（如：3 分鐘、坐著做），降低行動門檻。
- **驗證/解密**：破解常見迷思（如：假肚腩真相），建立專業權威。
- **推薦清單**：提供系統性的解決方案（如：3 個必備動作），觸發收藏。
- **情感/故事**：分享真實經歷（如：從行屍走肉到掌控生活），建立深度信任。
