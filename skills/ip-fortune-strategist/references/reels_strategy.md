# Reels 爆款策略與文案公式

本文件整合了 Instagram 演算法邏輯與 29 套短片公式，用於指導生成高轉化的 Reels 腳本。

## 1. 核心演算法邏輯 (0 粉起號)
- **觸及非粉絲**：Reels 是唯一能低成本觸及非粉絲的工具。
- **完播率 (Retention)**：前 3 秒 Hook 決定生死，避免「大家好我是...」的開場白。
- **分發訊號**：
  - **收藏**：提供高密度乾貨、懶人包、步驟清單。
  - **分享**：引發共鳴、吐槽、或極具實用性的內容。
  - **留言**：結尾設置簡單提問或引導索取資料（如「留言『我要』」）。

## 2. 爆款 Hook 設計 (前 3 秒)
- **視覺衝擊**：強烈的對比（痛症 vs 輕鬆）、誇張表情、或直接展示結果。
- **文字鉤子**：
  - 痛點直擊：「久坐 8 小時，腰快斷了？」
  - 認知翻轉：「別再這樣拉筋了，越拉越痛！」
  - 極低門檻：「辦公室最不尷尬的消痛法，坐著就能做。」

## 3. Slogan 量化邏輯
- **公式 1 (經典+量化)**：我幫助 [TA] + [如何做到] + [實現「數字化」結果]。
  - *例：我幫久坐族每天 15 分鐘，告別圓肩駝背。*
- **公式 2 (結果+量化)**：讓 [TA] + 在 [時間/步驟] 內 + [得到「數字化」成果]。
  - *例：讓職場女性 1 週挑戰烏龜頸變天鵝頸。*
- **公式 3 (痛點+量化解決)**：告別 [痛點]，[數字化時間/方法] 實現 [結果]。
  - *例：告別假肚腩，3 套動作還原真實身形。*

## 4. 常用短片公式 (精選)
- **反向操作**：提出反直覺觀點（如：越拉筋越痛），打破常規，吸引注意力。
- **成本/場景元素**：強調極低的時間/金錢成本（如：3 分鐘、坐著做），降低行動門檻。
- **驗證/解密**：破解常見迷思（如：假肚腩真相），建立專業權威。
- **推薦清單**：提供系統性的解決方案（如：3 個必備動作），觸發收藏。
- **情感/故事**：分享真實經歷（如：從行屍走肉到掌控生活），建立深度信任。

## 6. 45 秒法則（完播率最佳化）

- **目標時長**：45 秒以內
- **精簡公式**：原始腳本 → 刪去解釋性語句 → 只保留結論性語句 → 加回體感動作 → 完成
- **每 10 秒原則**：每 10 秒必須有一個新的視覺或資訊刺激，否則觀眾會滑走

## 8. 5 段成交鏈應用與內容策略（2026-07-03 更新）

### 8.1 5 段成交鏈模型

從被看見到被購買，共有五環：

| 環節 | 關鍵任務 | 觀眾內心 OS |
|---|---|---|
| **注意力 (Attention)** | 讓人停下來 | 「等等，這是什麼？」 |
| **影響力 (Influence)** | 讓觀眾開始認定你的路線與主張 | 「這個人，不一樣。」 |
| **關係 (Relationship)** | 讓他願意再回來、持續互動 | 「我想繼續看下去。」 |
| **信任 (Trust)** | 讓他相信你是真的、有料的 | 「這不是套路。」 |
| **成交 (Conversion)** | 讓他願意採取付費或下一步行動 | 「我要，怎麼找你？」 |

**Cathy 當前卡點：** 你的 Reels 有「注意力」，但從第 3 環「關係」開始斷裂。留言拿引流品後，沒有設計後續互動，導致無法建立信任和成交。

### 8.2 三層選題法模型

同一主題可以拆成三層，吸引不同層級的受眾：

| 層級 | 特性 | 吸引誰 |
|---|---|---|
| **教學層 (Layer 1)** | 教具體方法、步驟、動作 | 已經意識到問題、願意學的人 |
| **推翻層 (Layer 2)** | 打破迷思、提出反常識觀點 | 猶豫的人、卡住的人、被錯誤認知困住的人 |
| **價值觀層 (Layer 3)** | 講立場、講人生、講更大的結果與身份認同 | 真正會被你吸住、會記住你的人 |

**Cathy 當前卡點：** 你的內容目前集中在「教學層」，導致吸引的受眾只想拿走方法，難以建立觀點和信任，也無法推動成交。

### 8.3 融合流量與轉化的 CTA 策略

**核心邏輯：用「引流品」做誘餌，用「私訊」做轉化。** 不是「二選一」，而是「兩步走」。

1.  **第一步：用引流品推高留言數（流量）**
2.  **第二步：在引流品的基礎上，設計「私訊對話」（轉化）**

#### 方案 A：「引流品 + 深度問題」二合一

在 Reels 的 Caption 中設計這樣的 CTA：

```
留言「痛症名稱」，我 DM 你 10 秒自測法。

但 DM 之前，我會問你 3 個問題：
1. 你係咪要長期企立工作？
2. 你試過咩方法都冇用？
3. 你最想改善咩？

答完之後，我會根據你嘅情況，給你針對性嘅建議。
```

**效果：** 留言數不下降，DM 質量提升，對話自然發生。

#### 方案 B：「引流品分層」

根據受眾留言內容，給予不同層次的引流品。例如，對於「拇趾外翻」的留言，DM 時可提供「10 秒自測法」後，再根據其回覆提供「拇趾外翻 3 個微習慣清單」。

#### 方案 C：「Story 誘因設計」融合流量與轉化（推薦）

利用 Story 建立誘因，將「拎引流品」轉化成「深度對話」，同時提升流量和轉化率。

**Reels 發佈後 3–5 天的 Story 流程：**

1.  **Reels CTA**：「留言『拇趾外翻』，我 DM 你 10 秒自測法」
2.  **Day 1 Story**：「好多人留言。我想問下，你係咪穿高踭鞋？」（投票）
3.  **Day 2 Story**：「根據投票，70% 都係因為穿高踭鞋。想知道你個人嘅改善方案嗎？DM 我『評估』。」
4.  **Day 3 Story**：「已經有 5 個人 DM 我『評估』咗。佢哋都話改善咗。你想試試嗎？」
5.  **DM 中**：發完引流品後，加一句：「想知道你個人嘅改善方案嗎？回答以下 3 個問題，我會根據你嘅情況設計課程。」

**效果：** Reels 留言數不下降，DM 質量大幅提升，對話自然發生，轉化率提升。

### 8.4 7 月內容調整建議

根據「三層選題法」和「5 段成交鏈」，你的 7 月 Reels 應該這樣分配：

| 週次 | 教學層 | 推翻層 | 價值觀層 | 目的 |
|------|--------|--------|---------|------|
| 第 1 週 | 1 條（器材加強版） | 0 | 0 | 測試行為場景 Hook |
| 第 2 週 | 0 | 1 條（破解迷思） | 0 | 建立觀點 |
| 第 3 週 | 0 | 0 | 1 條（見證預告） | 建立信任 |
| 第 4 週 | 0 | 0 | 1 條（朋友案例） | 推動成交 |

**注意：** 不是要你停止教學層內容，而是要你在教學層之外，加入推翻層和價值觀層，形成一個「漏斗」。

Cathy 的引流品數據顯示受眾 60–70% 為女性，但無職業線索。這說明受眾的共同點是**性別 + 痛症**，而非單一職業。

**TA 縮窄的正確維度是「行為場景」，而非「職業」。**

| 縮窄維度 | 效果 | 適用情境 |
|---------|------|----------|
| 職業（教師、護士） | 排除大量同痛症但職業不同的女性 | 不推薦 |
| 只講痛症 | 指向性弱，人人都可看但人人都唔覺得係講自己 | 初期流量期可用 |
| **行為場景（推薦）** | 精準且不排除人，讓她自己對號入座 | 流量 + 轉化並重 |

**行為場景 Hook 公式：行為 + 誤解 + 真相**

```
「[TA 的具體行為]，[痛症]——[她已經試過但失敗的方法]，因為[真正原因]。」
```

範例：
> 「穿咗幾年高踭鞋，拇趾外翻、腳板痛——換鞋冇用、買鞋墊冇用，因為你從來冇訓練過隻腳。」

**Hook 設計禁忌：**
- 避免過早揭示答案（保持神秘感，引導觀眾繼續看）
- 避免抽象詞彙（如「代價」），要具體有畫面感
- 避免假設受眾已看過前集（每條 Reel 要能獨立成立）


## 七、 結合「5 段成交鏈」與「三層選題法」的 Reels 內容策略 (2026-07-04 更新)

### 7.1 診斷當前卡點：成交鏈中段斷裂與選題層次單一

**當前問題：**
1.  **成交鏈中段斷裂**：Reels 雖能吸引「注意力」和產生「影響力」，但缺乏從「關係」到「信任」再到「成交」的有效設計。留言引流品後，未能有效轉化為深度對話或課程諮詢。
2.  **選題層次單一**：Reels 內容過於集中在「教學層」，導致受眾只願獲取免費方法，難以建立個人觀點和信任，模糊了教練的付費服務定位。

### 7.2 應用「5 段成交鏈」優化 Reels 轉化

Reels 內容設計應貫穿成交鏈的各個環節，而不僅僅停留在「注意力」和「影響力」：

| 成交鏈環節 | Reels 內容策略 | 目的 |
|------------|----------------|------|
| **1. 注意力** | **拉新 Reels**：強 Hook，直接擊中痛點或好奇點。例如：痛症科普、常見誤區。 | 吸引陌生流量 |
| **2. 影響力** | **觀點 Reels**：提出獨特見解，破解迷思，建立專業權威。 | 讓受眾認同你的專業和價值觀 |
| **3. 關係** | **互動 Reels**：引導留言、投票、DM 深度對話。例如：提問式 Hook、引流品 + 深度問題 CTA。 | 建立與受眾的個人連結，從廣泛受眾篩選潛在客戶 |
| **4. 信任** | **見證 Reels**：分享學員案例、Before/After 對比、學員心聲。 | 證明你的服務有效，降低受眾的購買風險 |
| **5. 成交** | **產品 Reels**：清晰介紹服務內容、價值主張、解決方案。 | 直接引導受眾購買課程或諮詢 |

**關鍵：** 每個 Reels 發佈後，必須配合 Story、DM 管理等後續動作，才能將成交鏈完整串聯。

### 7.3 應用「三層選題法」深化 Reels 內容

Reels 內容應從單一的「教學層」擴展到「推翻層」和「價值觀層」，以建立更深層次的信任和連結：

| 選題層次 | 內容策略 | 目的 |
|----------|----------|------|
| **1. 教學層** | **實用動作、科普知識**：直接解決受眾的表面問題。 | 吸引流量，提供即時價值 |
| **2. 推翻層** | **破解迷思、揭示真相**：挑戰受眾的固有認知，指出錯誤方法。 | 建立專業觀點，讓受眾感覺「原來我一直都錯了」 |
| **3. 價值觀層** | **案例故事、生活轉變**：展示服務帶來的深層次改變，不僅是痛症改善，更是生活品質提升。 | 建立情感連結，讓受眾認同你的品牌價值 |

**Reels 內容分配建議：**
- **起步期**：教學層 (50%) + 推翻層 (30%) + 價值觀層 (20%)
- **成長期**：推翻層 (40%) + 價值觀層 (40%) + 教學層 (20%)
