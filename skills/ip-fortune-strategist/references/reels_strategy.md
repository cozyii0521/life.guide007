# Reels 爆款策略與文案公式

本文件整合了 Instagram 演算法邏輯與 29 套短片公式，用於指導生成高轉化的 Reels 腳本。

## 1. 核心演算法邏輯 (0 粉起號)
- **觸及非粉絲**：Reels 是唯一能低成本觸及非粉絲的工具。
- **完播率 (Retention)**：前 3 秒 Hook 決定生死，避免「大家好我是...」的開場白。
- **分發訊號**：
  - **收藏**：提供高密度乾貨、懶人包、步驟清單。
  - **分享**：引發共鳴、吐槽、或極具實用性的內容。
  - **留言**：結尾設置簡單提問或引導索取資料（如「留言『我要』」）。

## 2. 爆款 Hook 設計 (前 3 秒)
- **視覺衝擊**：強烈的對比（痛症 vs 輕鬆）、誇張表情、或直接展示結果。
- **文字鉤子**：
  - 痛點直擊：「久坐 8 小時，腰快斷了？」
  - 認知翻轉：「別再這樣拉筋了，越拉越痛！」
  - 極低門檻：「辦公室最不尷尬的消痛法，坐著就能做。」

## 3. Slogan 量化邏輯
- **公式 1 (經典+量化)**：我幫助 [TA] + [如何做到] + [實現「數字化」結果]。
  - *例：我幫久坐族每天 15 分鐘，告別圓肩駝背。*
- **公式 2 (結果+量化)**：讓 [TA] + 在 [時間/步驟] 內 + [得到「數字化」成果]。
  - *例：讓職場女性 1 週挑戰烏龜頸變天鵝頸。*
- **公式 3 (痛點+量化解決)**：告別 [痛點]，[數字化時間/方法] 實現 [結果]。
  - *例：告別假肚腩，3 套動作還原真實身形。*

## 4. 常用短片公式 (精選)
- **反向操作**：提出反直覺觀點（如：越拉筋越痛），打破常規，吸引注意力。
- **成本/場景元素**：強調極低的時間/金錢成本（如：3 分鐘、坐著做），降低行動門檻。
- **驗證/解密**：破解常見迷思（如：假肚腩真相），建立專業權威。
- **推薦清單**：提供系統性的解決方案（如：3 個必備動作），觸發收藏。
- **情感/故事**：分享真實經歷（如：從行屍走肉到掌控生活），建立深度信任。

## 5. Reels 實戰數據分析（2026-06 更新）

### EP4（2026-06-18）：「矯正器使用迷思」

**Hook：** 「買返黎嘅拇趾外翻矯正器，隨時令腳趾越來越歪！」（反直覺/恐懼型）

**結構：** 痛點放大 → 迷思破解（矯正器 vs 分離器）→ 正確使用方法 → CTA（留言「HOW」）

**優點：**
- Hook 強力，製造認知失調
- 實物展示（矯正器 + 分離器）增加真實感
- 圖文輔助（X光圖、3D解剖圖）解釋複雜機制效率高

**問題（老師直接指出）：**
- 語速 fast forward 剪輯太明顯，觀眾感到不自然
- 解決方案：刪除不必要內容，而非加速，目標 45 秒以內

### EP5（2026-06-22）：「拇趾外翻連鎖反應」

**Hook：** 視覺衝擊（嚴重拇趾外翻特寫）+ 反常識文案（「最痛的不是腳，是腰和膝蓋」）

**結構：** 痛點 → 互動體驗（讓觀眾模擬錯誤姿勢）→ 原理解釋 → 後果放大 → 系列感建立 → CTA（留言「CHAIN」）

**優點：**
- 互動體驗設計（讓觀眾親身感受代償）是最強的「帶走」設計
- A/B 選擇法 CTA 利用損失厭惡心理
- 系列感建立（秀出 EP1–EP4）增加信任

**可改善：**
- 模擬錯誤姿勢時缺乏「❌ 錯誤示範，請勿長期模仿」警告字樣
- 0:45 可加一個簡單的放鬆小動作作為「即時甜頭」
- 核心力學解釋時語速可稍微放慢 10%

**關鍵學習：EP5 > EP4，原因是題材更窄更具體。**

## 6. 45 秒法則（完播率最佳化）

- **目標時長**：45 秒以內
- **精簡公式**：原始腳本 → 刪去解釋性語句 → 只保留結論性語句 → 加回體感動作 → 完成
- **每 10 秒原則**：每 10 秒必須有一個新的視覺或資訊刺激，否則觀眾會滑走
