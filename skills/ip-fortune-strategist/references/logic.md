# 命理推算邏輯參考

## 1. 八字與 IP 經營
- **食神/傷官 (食傷)**：代表才華、創意、內容產出。食傷生財者，適合透過內容變現。
- **正官/七殺 (官殺)**：代表名聲、地位、權威。官殺旺者，適合建立專業權威形象。
- **比肩/劫財 (比劫)**：代表自我、競爭、執行力。身旺者能承接大運名聲。
- **正印/偏印 (印星)**：代表學習、思考、專業深度。印星旺者適合深耕專業領域。

## 2. 流年流月互動
- **身旺官旺**：最利於 IP 爆發，名聲大噪。
- **食神生財**：利於內容轉化，變現能力強。
- **土旺埋金**：經營可能陷入沉悶，需加強內容創新。
- **水火既濟**：火旺之年得水潤局，名聲與財運兼得。

## 3. 性格與經營風格
- **辛金**：追求完美、專業細膩。建議：先求有再求好。
- **雙子座**：靈活多變、善於溝通。建議：聚焦核心定位，避免發散。
- **生命靈數 1**：天生領導者、開創性強。建議：主動出擊，建立個人品牌。
