# 三層選題法 (Three-Altitude Method)

這份筆記的核心思想是：流量不會自動變成生意，問題往往不在內容本身，而在你選題時所採用的「海拔」不對。相同主題，可以從三種不同高度切入，因此會吸引不同層級的人。

## 關鍵原則
> 你的專業，決定誰會買；你的角度，決定誰會看。

這意味著不需要放棄專業，而是要把同一個專業主題，用不同的切角包裝，去接住不同溫度的受眾。

## 三層選題法模型
同一主題可以拆成三層：

| 層級 | 特性 | 吸引誰 |
|---|---|---|
| **教學層 (Layer 1)** | 教具體方法、步驟、動作 | 已經意識到問題、願意學的人 |
| **推翻層 (Layer 2)** | 打破迷思、提出反常識觀點 | 猶豫的人、卡住的人、被錯誤認知困住的人 |
| **價值觀層 (Layer 3)** | 講立場、講人生、講更大的結果與身份認同 | 真正會被你吸住、會記住你的人 |

## 升級選題不是換題目，而是換海拔
不是每次都要找新題目，而是可以用同一個題目，往上抬高切入角度。

基本公式如下：

| 層級 | 公式 |
|---|---|
| 教學層 | 如何 + 做某事的具體結果 |
| 推翻層 | 越多人以為要做的事，越不該這樣做 |
| 價值觀層 | 一個人做了某件事，得到更大結果，於是明白另一件事 |

## 三層不是三選一，而是排成漏斗
最重要的應用點：
1. 教學層負責接住已經知道自己有問題的人。
2. 推翻層負責讓還沒有完全相信的人開始注意你。
3. 價值觀層負責把真正認同你的人拉近。
4. 三層不是選一層做，而是要一起排成一個從流量到成交的漏斗。

## Cathy 當前卡點與應用
你現在的內容明顯集中在教學層，也就是「教動作、教伸展、教怎樣舒緩」。這會帶來兩個問題：

第一，會吸引一批只想拿走方法、自己做的人，而不是會想找你服務的人。第二，因為缺少推翻層與價值觀層，你很難讓人形成「這個人有自己的觀點、值得持續跟」的印象。

換句話說，你不是沒有內容，而是目前大多數內容都擠在漏斗底部的同一層，導致流量來了，卻沒有被往上推進成信任和成交。

**你需要做的改變：**
- **加入「推翻層」內容**：讓觀眾產生「等等，我之前理解錯咗」的頓悟感，這樣她才會開始相信你有不同的視角。
- **加入「價值觀層」內容**：讓觀眾看到「跟你做不只係改善痛症，而係改善生活品質」，這樣她才會願意付費。

**7 月的內容調整建議：**

| 週次 | 教學層 | 推翻層 | 價值觀層 | 目的 |
|------|--------|--------|---------|------|
| 第 1 週 | 1 條（器材加強版） | 0 | 0 | 測試行為場景 Hook |
| 第 2 週 | 0 | 1 條（破解迷思） | 0 | 建立觀點 |
| 第 3 週 | 0 | 0 | 1 條（見證預告） | 建立信任 |
| 第 4 週 | 0 | 0 | 1 條（朋友案例） | 推動成交 |

這是一個「漏斗」式的內容分配，確保流量能被有效轉化。
