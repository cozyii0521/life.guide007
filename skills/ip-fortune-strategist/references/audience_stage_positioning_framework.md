# 受眾階段定位一致性框架（Audience Stage Positioning Framework）

> 本文件從 26.6.2026 的 AI 對話中提取底層邏輯，記錄「進階工具型內容的定位一致性法則」。
> 核心問題：當內容使用進階工具（彈力帶、yoga block、器材）時，Hook、內容、引流品三者必須鎖定同一批人在同一個階段。
> 適用場景：任何使用工具/器材的升級版 Reels，或需要區分「入門受眾」vs「升級受眾」的選題。

---

## 一、底層邏輯拆解：這個 AI 的思維框架

### 1.1 這個 AI 的核心評估 Prompt（逆向工程）

根據其分析邏輯，可以逆向推導出它的核心評估框架：

```
評估任何一條 Reels 腳本時，先問一個前置問題：

「這條片的工具/內容難度，是為哪個階段的人設計的？」
→ 入門（從未訓練過）
→ 升級（已有基礎，想突破瓶頸）
→ 維持（已有成效，想鞏固）

確認階段後，用以下三重一致性測試：

1. Hook 是否在釣同一個階段的人？
   - 入門 Hook：「換鞋按腳都冇用？」「腳板痛係必然？」
   - 升級 Hook：「做咗幾個禮拜但好似撐到一個位就上唔到？」「徒手練去到樽頸？」
   - 如果工具是進階的，但 Hook 在釣入門人 → 定位打架

2. 內容難度是否與 Hook 承諾的受眾匹配？
   - 入門人看到彈力帶 + yoga block → 「咁複雜，唔係我」→ 走
   - 升級人看到彈力帶 + yoga block → 「係喎，我需要加阻力」→ 留
   - 工具的存在必須被 Hook 的邏輯「預先合理化」

3. 引流品是否是這個階段的人「片內講唔完、但迫切想知」的東西？
   - 入門人需要：完整動作清單、基礎自測方法
   - 升級人需要：阻力選購指南、強度對照表、進階動作庫
   - 「完整訓練計劃」是通用詞，入門人和升級人都聽得懂，所以兩個都不會特別想要
```

### 1.2 這個 AI 的底層哲學

這個 AI 的整個評估框架建立在一個核心信念上：

> **「Hook + 內容 + 引流品，必須服務同一個人在同一個時刻的同一個需求。任何一個環節跳出這個框架，整條漏斗就斷了。」**

這不是一個 Hook 技巧，也不是一個 CTA 技巧，而是一個**漏斗一致性哲學**：
- Hook 是入口，決定誰進來
- 內容是承諾兌現，決定誰留下
- 引流品是下一步，決定誰轉化

三者必須服務同一個人，否則每個環節都在「篩走」上一個環節留下的人。

## 二、定位打架的四種症狀

### 2.1 症狀診斷表

| 症狀 | 表現 | 後果 |
|------|------|------|
| **入門 Hook + 進階工具** | Hook 釣入門人，但片內用彈力帶/yoga block | 入門人看到工具門檻高，走；升級人沒被 Hook 到，也走 |
| **進階工具 + 通用引流品** | 工具是進階的，但引流品是「完整訓練計劃」 | 升級人覺得「計劃我自己排得到」，不留言 |
| **Hook 數字 ≠ 內容數字** | Hook 說「2 個工具」，片有 3 個動作 | 觀眾感覺被騙，信任度下降 |
| **系列前後定位跳躍** | EP1-EP4 是入門，突然出一集進階工具片 | 舊粉絲不知道這集是給誰的，新粉絲沒有前置認知 |

### 2.2 最常見的「定位打架」組合（Cathyii 版本）

**高風險組合：**
- Hook：「腳板痛係必然？換鞋按腳都冇用？」（入門痛點語言）
- 內容：彈力帶 + yoga block 三個動作（進階工具）
- 引流品：「完整訓練計劃」（通用，無階段感）

**問題鏈：**
1. 入門人被 Hook 吸進來 → 看到工具 → 「咁複雜唔係我」→ 走
2. 升級人沒被 Hook 到（Hook 語言是入門的）→ 根本不進來
3. 留下的少數人看完 → 「完整計劃就係把這三個動作排時間表」→ 不留言

## 三、工具存在理由法則（Tool Justification Rule）

### 3.1 核心原則

> **任何使用工具/器材的 Reels，Hook 必須在第一句話回答：「為什麼徒手做不夠？」**

工具的存在會在觀眾腦中製造一個即時問題：「我要買嘢？」這個問題如果沒有被 Hook 的邏輯預先化解，觀眾的第一反應是「門檻太高」而不是「我需要這個」。

### 3.2 工具合理化的兩種路徑

| 路徑 | 說明 | 例子 |
|------|------|------|
| **徒手有極限路徑** | 先承認徒手有效，再說明為什麼到了某個階段需要工具 | 「徒手練拇趾外翻去到樽頸？你隻腳要嘅唔係練多啲，係練啱條肌肉——而呢條肌肉，徒手根本提供唔到足夠阻力。」 |
| **精準肌肉路徑** | 說明工具能訓練到徒手訓練不到的特定肌肉 | 「呢個係訓練拇趾外翻最直接嘅肌肉——外展拇肌，徒手做唔到足夠阻力，要靠彈力帶先有效果。」 |

**注意：** 「精準肌肉路徑」適合在片內機制段使用，不適合在 Hook 使用（太技術性）。Hook 必須用「徒手有極限路徑」——先建立「你已經做過基礎但卡住了」的共鳴，再引出工具。

### 3.3 升級版 Hook 公式

**釣「已練緊但卡住」受眾的 Hook 結構：**

```
[主題錨點] + [承認已有基礎] + [點出瓶頸] + [工具存在理由]
```

**示範（彈力帶 + yoga block 拇趾外翻升級版）：**

> **版本 A（瓶頸型）：**
> 「拇趾外翻嘅動作做咗幾個禮拜，但好似撐到一個位就上唔到？問題唔係你唔夠勤力，係徒手練根本去到極限——隻腳真正要進步，要加阻力。」

> **版本 B（精準型，較短）：**
> 「徒手練拇趾外翻去到樽頸？你隻腳要嘅唔係練多啲，係練啱條肌肉。」

**為什麼這兩個 Hook 有效：**
1. **鎖定「已練緊但卡住」**：「做咗幾個禮拜」「樽頸」是升級受眾的精準語言
2. **推翻一個信念**：「唔係你唔夠勤力，係徒手有極限」——卸責 + 製造認知缺口
3. **自然引出工具**：「要加阻力」讓工具的出現有邏輯支撐，不是強迫推銷

## 四、引流品階段匹配法則（Lead Magnet Stage Matching）

### 4.1 核心原則

> **引流品必須包含「這個階段的人需要、但片內講唔完」的東西。**
> 「完整訓練計劃」是任何階段都聽得懂的詞，所以任何階段都不會特別想要。

### 4.2 按受眾階段設計引流品

| 受眾階段 | 她的核心焦慮 | 片能給的 | 引流品應該給的 |
|---------|------------|---------|--------------|
| **入門** | 「我不知道怎麼開始」 | 基礎動作教學 | 完整自救清單 + 自測方法 |
| **升級（練緊但卡住）** | 「我做了但感覺沒進步」「我用對工具了嗎？」 | 動作示範 + 原理 | 阻力強度對照表 + 工具選購指南 + 「做啱 vs 做錯」對照 |
| **維持（已有成效）** | 「我怎麼知道我做得夠好？」 | 進階動作 | 進階動作庫 + 自我評估標準 |

### 4.3 「升級版」引流品設計框架

**針對「彈力帶 + yoga block 升級版」的引流品設計：**

**❌ 錯誤做法：**
> 「留言『升級』，我 DM 你完整訓練計劃。」
> 問題：「完整訓練計劃」= 把片內三個動作排成時間表，觀眾已知，無誘因。

**✅ 正確做法：**
> 「留言『升級』，我 DM 你一份**加強訓練包**：每個動作該用幾大阻力、拉到咩程度先啱（連『做啱 vs 做錯』嘅對照）、加埋彈力帶同 yoga block 點揀唔買錯——跟住個強度做，先唔會白費力。」

**為什麼這個有效：**
1. **不重複片內容**：片教「點做」，DM 給「強度/選購」——有真誘因
2. **精準擊中升級人焦慮**：「我做啱未？阻力啱未？買邊條？」
3. **未來變現空間**：「買邊條彈力帶」可以連到聯盟/推薦產品

### 4.4 引流品設計的反向測試

設計完引流品後，用以下問題測試：

```
測試問題：「如果觀眾只看了片，沒有拿 DM，她會覺得少了什麼？」

✅ 通過：「她知道動作，但不知道該用多大阻力、買哪種工具」
❌ 不通過：「她已經知道所有動作了，DM 只是把它們整理成清單」
```

## 五、Hook-內容數字一致性法則

### 5.1 核心原則

> **Hook 中出現的任何數字（工具數量、動作數量、時間），必須與片內實際內容完全一致。**

數字不一致是一種隱性的「標題黨」行為，觀眾不一定能說出來，但會感覺到「被騙了一點點」，信任度下降。

### 5.2 常見數字衝突

| 衝突類型 | 例子 | 後果 |
|---------|------|------|
| **工具數量 ≠ 實際** | Hook 說「2 個工具」，片用了 2 件工具做 3 個動作 | 觀眾數：「你說 2 個，但我看到 3 個動作？」|
| **動作數量 ≠ 實際** | Hook 說「3 個動作」，片只教了 2 個 | 觀眾等第 3 個，等不到，失望 |
| **時間承諾 ≠ 實際** | Hook 說「3 分鐘」，片長 5 分鐘 | 觀眾感覺被騙 |

### 5.3 數字一致性檢查清單

每次生成腳本後，必須執行以下檢查：

```
□ Hook 提到的工具數量 = 片內實際使用的工具數量？
□ Hook 提到的動作數量 = 片內實際教的動作數量？
□ Hook 提到的時間 = 片的實際長度（合理誤差 ±15%）？
□ Caption 的數字 = Hook 的數字 = 片內的數字？
```

## 六、系列升級版的定位銜接策略

### 6.1 升級版的雙重挑戰

升級版 Reels（使用進階工具）面對兩個同時存在的挑戰：

1. **舊粉絲需要被告知「這是升級版」**：她們做過基礎，需要知道這集是給她們的
2. **新粉絲需要被告知「你需要先有基礎」**：沒做過基礎的人看到工具會直接走

### 6.2 升級版的定位銜接句

在 Hook 或機制段加入一句「升級版定位句」，同時解決兩個挑戰：

**公式：**
```
「如果你做過我之前教嘅[基礎動作名稱]，你而家係時候升級——
徒手練到某個程度，肌肉需要更大阻力先有進步。」
```

**示範（彈力帶 + yoga block 版）：**
> 「如果你做過我之前教嘅拇趾外翻基礎動作，你而家係時候升級——徒手練到某個程度，外展拇肌需要更大阻力先有進步。」

**效果：**
- 舊粉絲：「係喎，我做過基礎，呢集係給我的」→ 留下
- 新粉絲：「哦，原來有基礎版，我先去睇」→ 去翻舊片（流量回流）

### 6.3 升級版在系列中的位置

**建議：升級版不應該是系列的第一集或第二集。**

| 位置 | 問題 |
|------|------|
| 太早出升級版 | 大部分觀眾還是入門，升級版觸及面窄 |
| 太晚出升級版 | 已做基礎的粉絲等太久，流失 |
| **最佳位置** | 在基礎系列（4-5集）建立足夠粉絲基礎後，出升級版作為「系列延伸」 |

## 八、使用指引

### 8.1 何時啟用本框架

每次為 Cathyii 生成使用工具/器材的 Reels 腳本時，必須先執行「定位前置判斷」：

```
Step 1：這條片的工具/內容難度，是為哪個階段的人設計的？
→ 入門 / 升級 / 維持

Step 2：Hook 是否在釣同一個階段的人？
→ 如果不是，先修 Hook，再寫其他部分

Step 3：引流品是否是這個階段的人「片內講唔完、但迫切想知」的東西？
→ 如果是通用詞（「完整計劃」「動作清單」），必須細化到階段專屬內容

Step 4：Hook 中的數字是否與片內完全一致？
→ 工具數量、動作數量、時間承諾
```

### 8.2 快速診斷：你的腳本有沒有「定位打架」？

```
問題一：你的 Hook 第一句話，描述的是「從未訓練過的人」還是「已練緊但卡住的人」？
問題二：你的片內工具/動作，是「入門人能立刻開始」還是「需要有基礎才能用到」？
問題三：你的引流品，是「任何人都想要」還是「只有這個階段的人才迫切需要」？

如果三個答案不一致 → 定位打架，必須修改。
```

### 8.3 本框架的核心記憶點

> **「你釣的人、你給的東西、你要她做的下一步，必須是同一個人在同一個時刻的同一個需求。」**
