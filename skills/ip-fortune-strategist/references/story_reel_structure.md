# 故事型 Reel 完整結構公式
# Story Reel Full Structure Framework
**版本：** 1.0 | **建立日期：** 2026-07-15
**觸發來源：** 15.7.2025ai.docx 對話分析——另一個 AI 為 Legacy FootCare 鞋墊合作片設計的完整結構邏輯

---

## 一、這個框架解決什麼問題

現有 `brand_collab_reels_framework.md` 已建立「品牌植入黃金公式」和「主動+被動雙防線」框架。但沒有系統化定義「故事型 Reel」的完整段落結構——即每個段落的功能、時間分配、口播設計原則，以及各段落之間的情感邏輯。

本框架填補這個缺口，提供一個可以直接套用的故事型 Reel 結構模板。

---

## 二、故事型 Reel 的核心公式

```
具體痛畫面（Hook）
    ↓
拉入觀眾日常（架橋）
    ↓
痛點根源（你的真實故事）
    ↓
冤枉路（你試過但沒用的方法）
    ↓
危機升級（不解決會惡化到什麼程度）
    ↓
轉折（發現真正有效的方法）
    ↓
點解有效（知識型補完）
    ↓
情感高潮（回扣 Hook，情緒最高點）
    ↓
動作補完（守住 IP 專業定位）
    ↓
軟 CTA（扣金句，唔講產品參數）
```

## 三、各段落詳細設計原則

### 段落 1：Hook（0-7s）— 具體痛畫面 + 懸念

**功能：** 在前 3 秒製造「我要繼續看」的衝動

**設計原則：**
- 使用「好奇缺口雙觸發」技術（參見 `curiosity_gap_hook.md`）
- 展示「結果」而非「過程」（先讓觀眾看到你現在的狀態，吊住「怎麼做到的」）
- B-roll 必須是情緒最高點的畫面（跳舞、輕鬆行走等）

**例子：**
```
口播：「我做咗一件事，令我重拾返我不得不放棄咗好多年嘅興趣。」
字幕：「著耐就痛 → 跳成堂舞都唔痛」
B-roll：你而家跳舞的片段（動感，不說原因，吊住）
```

**禁忌：**
- ❌ 一開口就說出「興趣」是什麼（殺死好奇心）
- ❌ 一開口就說出「方法」是什麼（觀眾沒有理由繼續看）

---

### 段落 2：架橋（4-9s）— 拉入觀眾日常

**功能：** 把你的故事連接到觀眾的日常痛點，讓觀眾感受到「這也是我的問題」

**設計原則：**
- 用「你有冇試過...」或「你有冇感覺...」把觀眾拉進來
- 描述一個觀眾自己也有的具體感受（不是你的感受，是觀眾的感受）
- 這段是從「你的故事」過渡到「觀眾的問題」的橋樑

**例子：**
```
口播：「你未必跳舞，但你有冇試過——企足一日，收工返到屋企一坐低，對腳好似拖住兩嚿鉛咁，又攰又重？」
字幕：「企足一日，對腳好似拖住鉛」
B-roll：收工坐低脫鞋、揼腳、按腳板的動作
```

---

### 段落 3：痛點根源（9-16s）— 你的真實故事

**功能：** 建立「我和你一樣」的信任感，同時植入你的身份標籤

**設計原則：**
- 說出你的具體診斷（扁平足、拇趾外翻等）
- 說出你的具體職業/生活狀態（「做嘅又係成日要企嘅工」）
- 說出「年紀愈大痛得愈犀利」的惡化感（製造危機感的前置）
- B-roll 必須是真實的身體特寫（赤腳特寫、腳踝內塌等）

**例子：**
```
口播：「我天生扁平足，仲有拇趾外翻。做嘅又係成日要企嘅工，行街、跳完舞，對腳板一定痛足一排。年紀愈大痛得愈犀利，最後我唯有放棄咗最鍾意嘅跳舞。」
字幕：「扁平足＋拇趾外翻＋日日企」
B-roll：赤腳特寫（腳踝內塌、拇趾外翻角度）＋舊舞鞋
```

---

### 段落 4：冤枉路（14-23s）— 你試過但沒用的方法

**功能：** 建立「我試過你試過的方法，都沒用」的共鳴，同時暗示「一般方法解決不了根本問題」

**設計原則：**
- 列出觀眾也試過的方法（換鞋、做動作、按摩等）
- 說出「有用，但斷唔到尾」的誠實感（不是「完全沒用」，而是「治標不治本」）
- 最強的冤枉路：「連我自己，都解決唔到自己對腳」（專家也搞不定自己 = 問題真的很難）

**例子：**
```
口播：「我換過好多款鞋，貴嘅平嘅都試晒，對腳一樣痛。而我自己本身就係教體態動作㗎——我知道有動作可以改善，我有做啊，但有時偷懶冇做，又打回原形。連我自己，都解決唔到自己對腳。」
字幕：「換鞋唔得 → 自己教動作都搞唔掂自己」
B-roll：鞋櫃一堆鞋、示範動作、然後攤在沙發沒做的樣子
```

---

### 段落 5：危機升級（23-30s）— 不解決會惡化到什麼程度

**功能：** 製造「如果不解決，後果很嚴重」的緊迫感

**設計原則：**
- 說出最壞的情況（放棄最愛的事、擔心將來要忍痛過日子）
- 用「我開始驚」的情緒語言（不是客觀描述，是主觀恐懼）
- 如果有真實的「最壞時刻」（例如「諗過係咪要做手術」），用真實的；如果沒有，用安全版

**例子：**
```
口播：「最後我迫住放棄咗最鍾意嘅跳舞。我想跳，但真係痛到做唔到。年紀愈大痛得愈犀利，我開始驚——係咪之後連行街、行樓梯都要忍住痛過日子？」
字幕：「唔係唔想跳，係知自己做唔到」
B-roll：望著舊舞鞋、舞蹈室門口沒進去；夜晚揼腳睡不著的樣子
```

**注意：** 如果有「諗過做手術」的真實經歷，可以換成更有力的版本；如果是虛構的，不要用（觀眾聞得出）。

---

### 段落 6：轉折（30-38s）— 發現真正有效的方法

**功能：** 引入產品/方法，但要以「誠實的低期望」開始，讓轉折更可信

**設計原則：**
- 「老實講我冇乜期望」（誠實的低期望 = 更可信的轉折）
- 「坊間大牌子我都試過」（不點名競品，讓觀眾自己腦補）— **詳見下方「不點名競品原則」**
- 用「身體感受」描述效果，不讀產品參數
- 描述「第一步就不同」的即時感受（「即刻 feel 到」）

**不點名競品原則（必讀）：**

當你提到「試過其他方法都沒用」時，絕對不能點名具體品牌。

| 做法 | 結果 |
|------|------|
| ❌ 「我試過 Dr. Scholl 的鞋墊，好左排，但問題仍然係到」 | 給競品做免費宣傳 + 顯得你在貶低別人 |
| ✅ 「坊間大牌子的鞋墊，我試過，好左排，但問題仍然係到」 | 觀眾自動代入「我試過的那些」+ 信任感更強 |
| ❌ 「我用過物理治療師推薦的矯正鞋，一樣痛」 | 容易被理解為「physio 的方法無效」 |
| ✅ 「我換過好多款鞋，貴嘅平嘅都試晒，對腳一樣痛」 | 強調「我試過很多」= 「所以這個新的才不同」 |

**三個操作原則：**
1. 用「坊間」、「大牌子」、「試過好多款」代替具體品牌名
2. 如果必須提到類別（如「鞋墊」、「鞋」），用「我試過」而非「XX 品牌試過」
3. 重點是「我試過都冇用」，不是「XX 品牌冇用」——觀眾會自動理解「所以這個新的才不同」

**為什麼這很重要：**
- **法律風險**：直接貶低競品可能被告虛假宣傳
- **品牌風險**：顯得你在打擊別人，而不是在幫助觀眾
- **轉化風險**：觀眾會覺得你「有立場」而不是「有解決方案」
- **信任風險**：不點名反而讓觀眾覺得「她真的試過很多，才找到這個」

**例子：**
```
口播：「後來有廠家搵我試一款鞋墊。老實講我冇乜期望——因為坊間大牌子嘅鞋墊我都試過，著咗好返少少，但問題根本仲喺度，叫做好過唔著咁囉。但呢次真係唔同。我單腳一試著落去，即刻 feel 到半邊身好似畀人托高咗，踩落地嗰下好似有個 cushion 承托住我，行多幾步，成個人輕盈咗，連行路都快咗。」
字幕：「試過大牌冇感覺 → 呢個第一步就唔同」
B-roll：赤腳特寫（腳踝內塌）＋舊鞋底磨到一邊歪特寫＋著鞋行幾步輕盈的樣子
```

**關鍵 B-roll：「舚鞋底粤到一邊歪」** — 這是「地基歪」理論的實物證據，比任何口播都有說服力。必拍。

**✅ 這個例子為什麼有效：**
- 「坊間大牌子」而非「Dr. Scholl」 ✓
- 「著咗好返少少，但問題根本仍係到」 = 承認有幫助但治標不治本 ✓
- 「叫做好過唔著咗囉」 = 誠實的低期望 ✓
- 「呢次真係唔同」 = 轉折張力 ✓

**禁忌検查清單（轉折段落）：**
- ❌ 點名任何具體品牌或產品型號
- ❌ 說「其他方法完全沒用」（應該說「有用但治標不治本」）
- ❌ 一開口就說「我試咗呢個，真係好好用」（缺乏低期望，不可信）
- ❌ 讀產品參數或技術術語（應該說「feel 到」「感覺」「輕盈」）
- ✅ 用「坊間大牌子」代替具體品牌名
- ✅ 用「即刻 feel 到」描述第一步的即時感受
- ✅ 保留「誠實的低期望」開場

### 段落 7：點解有效（38-46s）— 知識型補完

**功能：** 用你的專業知識解釋「為什麼有效」，建立「你是專家」的可信度

**設計原則：**
- 連接回你的 IP 主線（「痛係一條鏈」「地基撐得住，上面就唔使幫佢硬食」）
- 用「身體感受」解釋機制，不用技術術語
- 說出「連帶效果」（腳好了，膝頭腰也鬆了）

**例子：**
```
口播：「點解有效？因為佢托返起我塌咗嘅足弓，我踩落地個衝擊力唔再全部壓落腳板。我試咗兩個星期，腳痛明顯少咗好多，而且成隻腳由下到上都鬆返——連帶膝頭同腰嗰啲痛都舒緩咗。我之前同你哋講過，痛係一條鏈，地基撐得住，上面就唔使幫佢硬食。」
字幕：「托返足弓 → 卸力 → 成條鏈鬆返」
B-roll：上落樓梯輕鬆、企耐都自然的樣子
```

---

### 段落 8：情感高潮（46-53s）— 回扣 Hook

**功能：** 情緒最高點，回扣開頭的懸念，讓觀眾感受到「原來是這樣」的滿足感

**設計原則：**
- 回扣 Hook 的懸念（開頭說「重拾興趣」，這裡說「我跳返舞了」）
- 用最真實的情感語言（「我真係太懷念，可以冇腳痛咁跳舞嘅日子」）
- B-roll 必須是情緒最高點的畫面（呼應開頭的跳舞片段）

**例子：**
```
口播：「然後我做咗件一直好想做、又好驚去做嘅事——我著住佢，跳返舞。由落堂到返到屋企，對腳真係冇咗以前嗰種痛。我真係太懷念，可以冇腳痛咁跳舞嘅日子。」
字幕：「我唔係跳唔到，係從未撐穩個地基」
B-roll：你跳舞片段（呼應開頭，情緒最高點，可以剪多幾個 cut）
```

---

### 段落 9：動作補完（53-60s）— 守住 IP 專業定位

**功能：** 防止觀眾認為「有鞋墊就不需要做動作」，守住你「教動作」的 IP 專業定位

**設計原則：**
- 主動說「唔係話有咗鞋墊就唔使做動作」（主動澄清，顯得更可信）
- 說出「鞋墊 + 動作」的協同效果（兩者缺一不可）
- 這段是「主動 + 被動雙防線」框架的口播體現

**例子：**
```
口播：「但我要講清楚——唔係話有咗鞋墊就唔使做動作。而係而家個地基終於有嘢撐住，我再做返啲矯正動作，先真係 keep 得長。鞋墊撐個地基，動作練個能力——兩樣夾埋，先係長遠。」
字幕：「鞋墊撐地基，動作練能力，兩樣夾埋先長遠」
B-roll：你做矯正動作的片段（帶返你「教動作」的專業形象）
```

---

### 段落 10：軟 CTA（60-68s）— 扣金句，不講產品參數

**功能：** 引導觀眾採取行動，但以「情感金句」收尾，不以「產品廣告」收尾

**設計原則：**
- 先說「如果你也是...」（篩選有需要的人）
- 說出「留言/DM 我」的具體動作
- 最後一句必須是情感金句（不是產品參數）
- 金句原則：扣回「撐」的雙關（撐身體/撐你）

**例子：**
```
口播：「如果你都係——換過幾多對鞋都唔得、企足一日對腳就痛、試過其他鞋墊都幫唔到，真心建議你試下。喺留言打『撐』，我 DM 你我用邊款、點揀。你對腳撐咗你咁多年，係時候，有樣嘢撐返佢。」
字幕：「留言『撐』→ 我 DM 你揀返適合你嗰款」（大字幕）
```

**「你對腳撐咗你咁多年，係時候，有樣嘢撐返佢。」** — 這句金句的截圖傳播力最強，不講產品但情緒到位。

## 四、故事型 Reel 的四個不能砍的骨幹

無論片長如何壓縮，以下四個段落不能砍：

1. **Hook**（具體痛畫面 + 懸念）— 沒有 Hook 就沒有觀看
2. **冤枉路的「連我自己都搞唔掂」**（建立最強信任）
3. **情感高潮**（回扣 Hook，情緒最高點）
4. **動作補完**（守住 IP 專業定位）

## 五、B-roll 優先級排序

| 優先級 | 畫面 | 原因 |
|-------|------|------|
| ⭐⭐⭐ 必拍 | 你跳舞（動感，多角度） | Hook + 高潮都用，情緒要真 |
| ⭐⭐⭐ 必拍 | 舊鞋底磨到一邊歪 | 「地基歪」理論的實物證據，最有說服力 |
| ⭐⭐⭐ 必拍 | 赤腳特寫（腳踝內塌、拇趾外翻角度） | 你真實有，最可信 |
| ⭐⭐⭐ 必拍 | 你做矯正動作 | 守住「教動作」專業形象 |
| ⭐⭐ 重要 | 跳完舞坐低除鞋、揼腳板 | 觀眾代入的鉤 |
| ⭐⭐ 重要 | 鞋櫃一堆鞋、示範完動作攤在沙發沒做 | 「換鞋+偷懶」的冤枉路 |
| ⭐⭐ 重要 | 著鞋行路輕盈、上落樓梯 | 表達「輕鬆」，不影 logo |
| ⭐ 加分 | 望舊舞鞋、舞蹈室門口沒進去 | 加強「放棄」情緒 |
| ⭐ 加分 | 夜晚揼腳睡不著 | 加強危機感 |

## 六、口播/Bio 分工原則

**口播負責：打動**
- 身體感受（「即刻 feel 到半邊身好似畀人托高咗」）
- 情感故事（「我真係太懷念，可以冇腳痛咁跳舞嘅日子」）
- 一句帶過的信任建立（「香港團隊同物理治療師一齊研發」）

**Bio / 置頂留言 / DM 負責：成交資訊**
- 產品名稱、型號、價錢
- 技術參數（AI 分析、物料、按摩點等）
- 獎項清單（Top 10、大學合作等）
- 購買連結

**界線：** 口播講了 = 廣告；放 Bio = 資料。這個界線不能過。
